**កំពុងគិតចង់សាកល្បង pi-web មែនទេ? ធ្វើទៅ — អ្នកនឹងលង់ស្រលាញ់វា។**

pi-web គឺជា web UI និង PWA ដ៏ស្រស់ស្អាតសម្រាប់ [pi](https://pi.dev) — ភ្នាក់ងារសរសេរកូដ AI ប្រភពបើកចំហ។ វាអនុញ្ញាតឱ្យអ្នករកមើល អាន និងបន្តសម័យ pi របស់អ្នកពីកម្មវិធីរុករកណាមួយ នៅលើឧបករណ៍ណាមួយ ជាមួយនឹងមុខងារដែលគិតគូរយ៉ាងល្អិតល្អន់គ្រប់ជំហាន។

**pi-web ត្រូវបានបង្កើតឡើងសម្រាប់មនុស្សពីរប្រភេទ៖**

- 🧑‍💻 **សម្រាប់អ្នកអភិវឌ្ឍន៍** — អ្នកដែលរស់នៅក្នុង terminal ប៉ុន្តែចង់បន្តសម័យពីទូរស័ព្ទ បញ្ជូនបន្តទៅម៉ាស៊ីនមេពីចម្ងាយ ឬតាមដានកិច្ចការដែលដំណើរការយូរពីគ្រប់ទីកន្លែង។
- ✨ **សម្រាប់អ្នកមិនមែនជាអ្នកអភិវឌ្ឍន៍** — អ្នកដែលគ្រាន់តែចង់បានកម្មវិធី AI ដ៏ស្រស់ស្អាតដែលដំណើរការ។ បើកវា វាយអត្ថបទ រីករាយ។ គ្មាន terminal គ្មាន SSH គ្មានការយល់ច្រឡំ។ ដូចឧបករណ៍ AI ដែលងាយស្រួលប្រើបំផុត ប៉ុន្តែមានជម្រើសម៉ូដែល និងសេរីភាពប្រភពបើកចំហ។

## ហេតុអ្វី pi-web?

អ្នកកំពុងស្ថិតក្នុងលំហូរការងារជាមួយ pi នៅក្នុង terminal របស់អ្នក។ pi-web រក្សាសន្ទុះនោះបន្តទៅមុខនៅពេលអ្នកចាកចេញពីតុរបស់អ្នក៖

- **បន្តពីគ្រប់ទីកន្លែង** — បន្តសម័យពីទូរស័ព្ទ ថេប្លេត ឬកុំព្យូទ័រផ្សេងទៀត។ គ្មាន SSH គ្មាន Termius — គ្រាន់តែបើកកម្មវិធីរុករករបស់អ្នក។
- **ផ្ទាំងគ្រប់គ្រងច្រើនសម័យ** — ចាប់ផ្តើមការងារក្នុងសម័យមួយ ខណៈពេលមើលសម័យមួយទៀតកំពុង stream។ ស្វែងរកឆ្លងកាត់គម្រោង ត្រងតាម branch ស្វែងរកអ្វីដែលអ្នកត្រូវការយ៉ាងរហ័ស។
- **មូលដ្ឋានប្រភពបើកចំហ** — pi គឺជាប្រភពបើកចំហទាំងស្រុង និងមិនភ្ជាប់ជាមួយ provider ជាក់លាក់។ អ្នកមិនត្រូវបានចាក់សោជាមួយម៉ូដែល ឬអ្នកលក់តែមួយទេ។ pi-web ក៏ជាប្រភពបើកចំហដែរ។
- **ការចូលប្រើពីចម្ងាយដោយសុវត្ថិភាព** — ការផ្ទៀងផ្ទាត់ token ដែលភ្ជាប់មកជាមួយ ដូច្នេះអ្នកអាចបញ្ចេញវានៅលើ LAN ឬ Tailscale របស់អ្នកដោយគ្មានការព្រួយបារម្ភ។
- **ចែករំលែកការងាររបស់អ្នក** — នាំចេញសម័យជា static snapshots ឬ GitHub Gists សម្ងាត់ក្នុងមួយចុច។

## pi-web ជាកន្លែងធ្វើការ AI ផ្ទាល់ខ្លួនរបស់អ្នក 🏠

pi-web គឺជា PWA (Progressive Web App) ដូច្នេះអ្នកអាច **ដំឡើងវាដូចកម្មវិធីដើម** នៅលើកុំព្យូទ័រ desktop កុំព្យូទ័រយួរដៃ ទូរស័ព្ទ ឬថេប្លេតរបស់អ្នក — មិនចាំបាច់ប្រើ app store ទេ។ នៅលើ desktop វាបើកក្នុងផ្ទាំងផ្ទាល់ខ្លួនដោយគ្មាន browser chrome ដូច្នេះវាមើលទៅ និងមានអារម្មណ៍ដូចកម្មវិធី desktop ពិតប្រាកដ។

គិតថាវាជា **Claude Cowork ផ្ទាល់ខ្លួនរបស់អ្នក** — កន្លែងធ្វើការ AI ផ្ទាល់ខ្លួនដែលរស់នៅលើម៉ាស៊ីនរបស់អ្នក — លើកលែងតែវាជាប្រភពបើកចំហ និងមិនភ្ជាប់ជាមួយម៉ូដែលជាក់លាក់៖

- **អ្នកជាម្ចាស់ stack ទាំងមូល។** ជ្រើសរើសម៉ូដែលណាមួយ ប្តូរនៅពេលណាក៏បាន។ ដំណើរការម៉ូដែល local ហើយទិន្នន័យរបស់អ្នកមិនដែលចាកចេញពីម៉ាស៊ីនរបស់អ្នកឡើយ។
- **មនុស្សដែលមិនមានជំនាញបច្ចេកទេសក៏អាចប្រើវាបាន។** រៀបចំ pi-web នៅលើម៉ាស៊ីនរបស់ពួកគេ បង្ហាញពួកគេពីរបៀបប្រើម្តង ហើយពួកគេអាចប្រើបានភ្លាមៗ។ ឪពុកម្តាយ ដៃគូ មិត្តភក្តិដែលមិនមែនបច្ចេកទេសរបស់អ្នក — គ្មាន terminal គ្មាន SSH គ្រាន់តែចំណុចប្រទាក់ជជែកដែលធ្លាប់ស្គាល់។
- **រៀបចំម្តង អ្នកប្រើច្រើន។** ដំឡើងវានៅលើ desktop របស់អ្នក ហើយចែករំលែកអេក្រង់ ឬបញ្ចេញវានៅលើបណ្តាញផ្ទះរបស់អ្នក ហើយអនុញ្ញាតឱ្យសមាជិកគ្រួសារបើកវានៅលើឧបករណ៍ផ្ទាល់ខ្លួនរបស់ពួកគេ។

ចង់បានច្រើនជាងការសរសេរកូដទេ? ប្រែក្លាយវាទៅជា [ជំនួយការផ្ទាល់ខ្លួន](personal-assistant.md) ដែលឧទ្ទិសឡើង ដែលស្គាល់អ្នក និងរស់នៅលើម៉ាស៊ីនរបស់អ្នក — ដូច OpenClaw ឬ Hermes ផ្ទាល់ខ្លួនរបស់អ្នក។

> 💡 **គន្លឹះសម្រាប់អ្នកជំនាញ៖** ដំឡើង pi-web ជា PWA ពី Chrome/Edge (ចុចរូបតំណាងដំឡើងនៅក្នុងរបារអាសយដ្ឋាន) ឬ Safari (Share → Add to Dock)។ វាក្លាយទៅជាមិនអាចបែងចែកពីកម្មវិធីដើមបាន។
