# ផែនការអភិវឌ្ឍន៍

pi-web ត្រូវបានបង្កើតឡើងសម្រាប់អ្នកប្រើប្រាស់ពីរក្រុម៖

- **សម្រាប់អ្នកអភិវឌ្ឍ** — អ្នកដែលធ្វើការក្នុង terminal ប៉ុន្តែចង់បន្តសម័យពីទូរស័ព្ទ បញ្ជូនទៅម៉ាស៊ីនមេពីចម្ងាយ ឬតាមដានកិច្ចការដែលដំណើរការយូរពីគ្រប់ទីកន្លែង។
- **សម្រាប់អ្នកមិនមែនអ្នកអភិវឌ្ឍ** — អ្នកដែលគ្រាន់តែចង់បានកម្មវិធី AI ដ៏ស្រស់ស្អាតដែលដំណើរការ។ បើកវា វាយអត្ថបទ រីករាយ។ គ្មាន terminal គ្មាន SSH គ្មានការយល់ច្រឡំ។ ដូចកម្មវិធី AI ដែលងាយស្រួលប្រើបំផុត ប៉ុន្តែមានជម្រើសម៉ូដែល និងសេរីភាពកូដបើកចំហ។

នេះជាអ្វីដែលនឹងមកដល់។

## ចក្ខុវិស័យ

គោលដៅរយៈពេលវែង៖ pi-web គួរតែជា **ចំណុចប្រទាក់សម្រាប់ pi** — សម្រាប់មនុស្សគ្រប់គ្នា។

- **អ្នកមិនមែនអ្នកអភិវឌ្ឍ** បើកវាដូចកម្មវិធីផ្សេងទៀត។ ជ្រើសរើសម៉ូដែល។ វាយអត្ថបទ។ រួចរាល់។ មិនដែលត្រូវការ command line ឡើយ។
- **អ្នកអភិវឌ្ឍ** ទទួលបានការរួមបញ្ចូលយ៉ាងស៊ីជម្រៅ — ការបញ្ជូនពីចម្ងាយ ផ្ទាំងគ្រប់គ្រងពហុសម័យ ការរុករកដែលយល់ដឹងពី git បូតផ្ញើសារ។
- **មនុស្សគ្រប់គ្នា** ទទួលបានសេរីភាពក្នុងការជ្រើសរើសម៉ូដែល តម្លាភាពកូដបើកចំហ និង UI ដែលមានអារម្មណ៍ថាគិតគូរគ្រប់ជំហាន។
