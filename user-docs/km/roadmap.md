# ផែនការ

pi-web ត្រូវបានបង្កើតឡើងសម្រាប់អ្នកប្រើប្រាស់ពីរក្រុម៖

- **សម្រាប់អ្នកអភិវឌ្ឍន៍** — ដែលរស់នៅក្នុងស្ថានីយ ប៉ុន្តែចង់បន្តសម័យប្រជុំពីទូរស័ព្ទ ផ្ទេរបន្តទៅម៉ាស៊ីនមេពីចម្ងាយ ឬតាមដានការងារដែលដំណើរការយូរពីគ្រប់ទីកន្លែង។
- **សម្រាប់អ្នកមិនមែនជាអ្នកអភិវឌ្ឍន៍** — ដែលគ្រាន់តែចង់បានកម្មវិធី AI ដ៏ស្រស់ស្អាតដែលដំណើរការ។ បើកវា វាយអក្សរ រីករាយ។ គ្មានស្ថានីយ គ្មាន SSH គ្មានភាពច្របូកច្របល់។ ដូចឧបករណ៍ AI ដែលងាយស្រួលប្រើបំផុត ប៉ុន្តែមានជម្រើសម៉ូដែល និងសេរីភាពនៃប្រភពបើកចំហ។

នេះជាអ្វីដែលនឹងមកដល់។

## ចក្ខុវិស័យ

គោលដៅរយៈពេលវែង៖ pi-web គួរតែជា **ចំណុចប្រទាក់សម្រាប់ pi** — សម្រាប់មនុស្សគ្រប់គ្នា។

- **អ្នកមិនមែនជាអ្នកអភិវឌ្ឍន៍** បើកវាដូចកម្មវិធីផ្សេងទៀត។ ជ្រើសរើសម៉ូដែល។ វាយអក្សរ។ រួចរាល់។ មិនដែលត្រូវប្រើបន្ទាត់ពាក្យបញ្ជាឡើយ។
- **អ្នកអភិវឌ្ឍន៍** ទទួលបានការរួមបញ្ចូលយ៉ាងជ្រៅ — ការផ្ទេរពីចម្ងាយ ផ្ទាំងគ្រប់គ្រងច្រើនសម័យប្រជុំ ការរុករកដែលយល់ដឹងអំពី git និង bots ផ្ញើសារ។
- **មនុស្សគ្រប់គ្នា** ទទួលបានសេរីភាពក្នុងការជ្រើសរើសម៉ូដែល តម្លាភាពនៃប្រភពបើកចំហ និង UI ដែលមានអារម្មណ៍ថាបានគិតគូរយ៉ាងល្អគ្រប់ជំហាន។
