# pi-web ជាជំនួយការផ្ទាល់ខ្លួនរបស់អ្នក

pi-web មិនមែនសម្រាប់តែការសរសេរកូដទេ — អ្នកអាចប្រែក្លាយវាទៅជា **ជំនួយការ AI ផ្ទាល់ខ្លួន** ដែលរស់នៅលើកុំព្យូទ័ររបស់អ្នក ដូចជាមាន OpenClaw ឬ Hermes ផ្ទាល់ខ្លួនរបស់អ្នកអញ្ចឹង។

## របៀបដំណើរការ

អ្នកបង្កើតថតឯកសារមួយដាច់ដោយឡែកនៅលើម៉ាស៊ីនរបស់អ្នក — នោះជាកន្លែងដែលជំនួយការរបស់អ្នករស់នៅ។ នៅក្នុងនោះ អ្នកដាក់ឯកសារ `APPEND_SYSTEM.md` ដែលកំណត់ថាជំនួយការរបស់អ្នកជានរណា វាដឹងអ្វីខ្លះ និងរបៀបដែលវាប្រព្រឹត្ត។ pi-web ផ្តល់ឱ្យអ្នកនូវចំណុចប្រទាក់ជជែកដ៏ស្រស់ស្អាតដើម្បីនិយាយជាមួយវាពីឧបករណ៍ណាមួយ។

## ជំហានម្តងមួយៗ

### ១. បង្កើតថតជំនួយការរបស់អ្នក

ជ្រើសរើសថតឯកសារមួយនៅលើកុំព្យូទ័ររបស់អ្នក។ ឧទាហរណ៍ដូចជា៖

```
~/my-assistant/
```

### ២. កំណត់ជំនួយការរបស់អ្នក

បង្កើតឯកសារ `APPEND_SYSTEM.md` នៅក្នុងថតនោះ។ នេះជាកន្លែងដែលអ្នកប្រាប់ pi ថាជំនួយការរបស់អ្នកជានរណា៖

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi បន្ថែមវាដោយស្វ័យប្រវត្តិទៅក្នុង system prompt នៃរាល់ការសន្ទនា ដូច្នេះជំនួយការរបស់អ្នកតែងតែដឹងថាអ្នកជានរណា និងរបៀបជួយ។

### ៣. ចាប់ផ្តើមសម័យនៅក្នុងថតនោះ

នៅក្នុង pi-web បង្កើតសម័យថ្មីដែលចង្អុលទៅ `~/my-assistant/` (ឬឈ្មោះអ្វីក៏ដោយដែលអ្នកដាក់)។ នោះហើយ — អ្នកកំពុងនិយាយជាមួយជំនួយការផ្ទាល់ខ្លួនរបស់អ្នកហើយ។

### ៤. ប្រើវាពីគ្រប់ទីកន្លែង

ដំឡើង pi-web ជា PWA នៅលើទូរសព្ទ ថេប្លេត ឬកុំព្យូទ័រយួរដៃរបស់អ្នក។ ជំនួយការរបស់អ្នកតែងតែនៅទីនោះ — សួរវាអ្វីក៏បាន ពេលណាក៏បាន។

## បន្ថែមបរិបទបន្ថែម

អ្នកអាចដាក់អ្វីក៏បាននៅក្នុងថតជំនួយការរបស់អ្នកដែលជួយឱ្យ pi មានប្រយោជន៍ជាងមុន៖

- `notes/` — ឯកសារយោងដែលជំនួយការរបស់អ្នកអាចអានបាន
- `context.md` — ព័ត៌មានផ្ទៃខាងក្រោយអំពីជីវិត ឬការងាររបស់អ្នក
- `projects.md` — គម្រោងបច្ចុប្បន្ន និងស្ថានភាពរបស់ពួកវា

pi អាចអានឯកសារនៅក្នុងថតបាន ដូច្នេះបើអ្នកផ្តល់បរិបទកាន់តែច្រើន វាកាន់តែប្រសើរឡើង។
