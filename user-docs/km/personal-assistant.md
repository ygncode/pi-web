# pi-web ជាជំនួយការផ្ទាល់ខ្លួនរបស់អ្នក

pi-web មិនមែនសម្រាប់តែការសរសេរកូដប៉ុណ្ណោះទេ — អ្នកអាចប្រែក្លាយវាទៅជា **ជំនួយការ AI ផ្ទាល់ខ្លួន** ដែលរស់នៅលើកុំព្យូទ័ររបស់អ្នក ដូចជាមាន OpenClaw ឬ Hermes ផ្ទាល់ខ្លួនរបស់អ្នកដែរ។

## របៀបដែលវាដំណើរការ

អ្នកបង្កើតថតឯកសារដាច់ដោយឡែកមួយនៅលើម៉ាស៊ីនរបស់អ្នក — នោះហើយជាកន្លែងដែលជំនួយការរបស់អ្នករស់នៅ។ នៅខាងក្នុង អ្នកដាក់ឯកសារ `APPEND_SYSTEM.md` ដែលកំណត់ថាជំនួយការរបស់អ្នកជានរណា វាដឹងអ្វីខ្លះ និងវាប្រព្រឹត្តបែបណា។ pi-web ផ្ដល់ឱ្យអ្នកនូវចំណុចប្រទាក់ជជែកដ៏ស្រស់ស្អាតដើម្បីនិយាយជាមួយវាពីឧបករណ៍ណាមួយ។

## មួយជំហានម្ដងៗ

### 1. បង្កើតថតឯកសារជំនួយការរបស់អ្នក

ជ្រើសរើសថតឯកសារមួយនៅលើកុំព្យូទ័ររបស់អ្នក។ ឧទាហរណ៍៖

```
~/my-assistant/
```

### 2. កំណត់ជំនួយការរបស់អ្នក

បង្កើតឯកសារ `APPEND_SYSTEM.md` នៅក្នុងថតឯកសារនោះ។ នេះជាកន្លែងដែលអ្នកប្រាប់ pi ថាជំនួយការរបស់អ្នកជានរណា៖

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi បន្ថែមវាដោយស្វ័យប្រវត្តិទៅក្នុង system prompt នៃរាល់ការសន្ទនា ដូច្នេះជំនួយការរបស់អ្នកតែងតែដឹងថាអ្នកជានរណា និងរបៀបជួយ។

### 3. ចាប់ផ្ដើម session នៅក្នុងថតឯកសារនោះ

នៅក្នុង pi-web បង្កើត session ថ្មីមួយដែលចង្អុលទៅ `~/my-assistant/` (ឬឈ្មោះអ្វីដែលអ្នកបានដាក់)។ នោះហើយ — អ្នកកំពុងនិយាយជាមួយជំនួយការផ្ទាល់ខ្លួនរបស់អ្នក។

### 4. ប្រើវាពីគ្រប់ទីកន្លែង

ដំឡើង pi-web ជា PWA នៅលើទូរស័ព្ទ ថេប្លេត ឬកុំព្យូទ័រយួរដៃរបស់អ្នក។ ជំនួយការរបស់អ្នកតែងតែនៅទីនោះ — សួរវាអ្វីក៏បាន ពេលណាក៏បាន។

## បន្ថែមបរិបទបន្ថែមទៀត

អ្នកអាចដាក់អ្វីក៏បាននៅក្នុងថតឯកសារជំនួយការរបស់អ្នក ដែលជួយឱ្យ pi កាន់តែមានប្រយោជន៍៖

- `notes/` — ឯកសារយោងដែលជំនួយការរបស់អ្នកអាចអានបាន
- `context.md` — ព័ត៌មានផ្ទៃខាងក្រោយអំពីជីវិត ឬការងាររបស់អ្នក
- `projects.md` — គម្រោងបច្ចុប្បន្ន និងស្ថានភាពរបស់វា

pi អាចអានឯកសារនៅក្នុងថតឯកសារបាន ដូច្នេះអ្នកផ្ដល់បរិបទកាន់តែច្រើន វាកាន់តែល្អប្រសើរ។
