# ផ្លូវកាត់ក្ដារចុច

## ទំព័រលិបិក្រម (`/`)

### ការរមូរទំព័រ (រចនាប័ទ្ម vim)

ផ្លូវកាត់រចនាប័ទ្ម vim ដូចគ្នាដំណើរការលើគ្រប់ទំព័រ នៅពេលការផ្ដោត **មិន** ស្ថិតនៅក្នុងធាតុ input, textarea ឬ contenteditable។

| ផ្លូវកាត់ | សកម្មភាព |
|----------|--------|
| `j` | រមូរចុះក្រោម 300px |
| `k` | រមូរឡើងលើ 300px |
| `g g` | រមូរទៅផ្នែកខាងលើនៃទំព័រ |
| `G` (Shift+G) | រមូរទៅផ្នែកខាងក្រោមនៃទំព័រ |
| `Escape` | ធ្វើឲ្យ input ដែលកំពុងផ្ដោតបាត់ការផ្ដោត ដើម្បីឲ្យការរុករក j/k ដំណើរការ |

### ពាក្យបញ្ជាលិបិក្រម

| ផ្លូវកាត់ | បរិបទ | សកម្មភាព |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | កម្រិតទំព័រ | បើក palette ស្វែងរក/សម័យ |
| `⌘,` / `Ctrl+,` | កម្រិតទំព័រ | បើកការកំណត់ |
| `⌘⇧L` / `Ctrl+Shift+L` | កម្រិតទំព័រ | បិទ/បើករចនាប័ទ្មប្រព័ន្ធ (ភ្លឺ/ងងឹត) |
| `Escape` | កម្រិតទំព័រ | បិទ palette, ម៉ឺនុយ ឬ modal |
| `Enter` | ប្រអប់បញ្ចូលផ្លូវសម័យថ្មី | បង្កើតសម័យថ្មី |

> `⌘K` / `Ctrl+K` ក៏ជាផ្លូវកាត់ "ផ្ដោតរបារអាសយដ្ឋាន" របស់ Chrome ផងដែរ។ កម្មវិធីរុករកអាចស្ទាក់ចាប់វា លុះត្រាតែការផ្ដោតស្ថិតនៅក្នុងប្រអប់បញ្ចូលអត្ថបទ។

## ទំព័រលម្អិតសម័យ (`/session?id=...`)

### ការរមូរទំព័រ (រចនាប័ទ្ម vim)

ទាំងនេះដំណើរការលើទំព័រលិបិក្រម និងទំព័រសម័យ នៅពេលការផ្ដោត **មិន** ស្ថិតនៅក្នុងធាតុ input, textarea ឬ contenteditable។

| ផ្លូវកាត់ | សកម្មភាព |
|----------|--------|
| `j` | រមូរចុះក្រោម 300px |
| `k` | រមូរឡើងលើ 300px |
| `g g` | រមូរទៅផ្នែកខាងលើនៃទំព័រ |
| `G` (Shift+G) | រមូរទៅផ្នែកខាងក្រោមនៃទំព័រ |
| `I` (Shift+I) | ផ្ដោតលើ textarea នៃកម្មវិធីសរសេរការជជែក |
| `Escape` | ធ្វើឲ្យ input ដែលកំពុងផ្ដោតបាត់ការផ្ដោត ដើម្បីឲ្យការរុករក j/k ដំណើរការ |

### របារចំហៀង និងការរុករក

| ផ្លូវកាត់ | បរិបទ | សកម្មភាព |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | កម្រិតទំព័រ | បិទ/បើកការមើលឃើញរបារចំហៀង |
| `⌘K` / `Ctrl+K` | កម្រិតទំព័រ | បើក palette បញ្ជីសម័យ |
| `⌘T` / `Ctrl+T` | កម្រិតទំព័រ | សម័យថ្មី |
| `⌘/` / `Ctrl+/` | កម្រិតទំព័រ | បង្ហាញ modal ផ្លូវកាត់ក្ដារចុច |
| `⌘,` / `Ctrl+,` | កម្រិតទំព័រ | បើកការកំណត់ |
| `⌘⇧L` / `Ctrl+Shift+L` | កម្រិតទំព័រ | បិទ/បើករចនាប័ទ្មប្រព័ន្ធ (ភ្លឺ/ងងឹត) |
| `⌘⇧N` / `Ctrl+Shift+N` | កម្រិតទំព័រ | បិទ/បើករបារចំហៀង scratchpad / កំណត់ចំណាំ |

> `⌘K` និង `⌘T` ក៏ជាផ្លូវកាត់របស់កម្មវិធីរុករកផងដែរ (ផ្ដោតរបារអាសយដ្ឋាន / ផ្ទាំងថ្មី)។ កម្មវិធីរុករកអាចស្ទាក់ចាប់ពួកវា លុះត្រាតែការផ្ដោតស្ថិតនៅក្នុងប្រអប់បញ្ចូលអត្ថបទ។

### កម្មវិធីសរសេរការជជែក

| ផ្លូវកាត់ | បរិបទ | សកម្មភាព |
|----------|---------|--------|
| `Enter` | ប្រអប់អត្ថបទជជែក | បញ្ជូនសារ |
| `Shift+Enter` | ប្រអប់អត្ថបទជជែក | បញ្ចូលបន្ទាត់ថ្មី |
| `Shift+Tab` | ប្រអប់អត្ថបទជជែក | ប្ដូរទៅកម្រិតការគិតបន្ទាប់ (`off` → `minimal` → … → `xhigh` → `off`) |
| `Ctrl+I` / `Ctrl+L` | ប្រអប់អត្ថបទជជែក | បើកម៉ឺនុយលេចឡើងជ្រើសរើសម៉ូដែល (វាយដើម្បីត្រង, ចុច Enter ដើម្បីជ្រើសរើស, ការផ្ដោតត្រឡប់ទៅ textarea) |

### ការបិទ/បើកការមើលឃើញធាតុ

| ផ្លូវកាត់ | បរិបទ | សកម្មភាព |
|----------|---------|--------|
| `t` | នៅពេលការផ្ដោត **មិន** ស្ថិតក្នុង input/textarea | បិទ/បើកការមើលឃើញការគិត |
| `o` | នៅពេលការផ្ដោត **មិន** ស្ថិតក្នុង input/textarea | បិទ/បើកការមើលឃើញឧបករណ៍ |
| `p` | នៅពេលការផ្ដោត **មិន** ស្ថិតក្នុង input/textarea | បិទ/បើកលទ្ធផលឧបករណ៍ |

### Palettes, ម៉ឺនុយ និង sheets

| ផ្លូវកាត់ | បរិបទ | សកម្មភាព |
|----------|---------|--------|
| `Escape` | កម្រិតទំព័រ | បិទ palette, ម៉ឺនុយ ឬ sheet ណាមួយដែលបើក |
| `⌘K` / `Ctrl+K` | កម្រិតទំព័រ | បើក palette បញ្ជីសម័យ |
| `ArrowUp` / `ArrowDown` | palette បញ្ជីសម័យ | រុករកលទ្ធផលសម័យ |
| `Enter` | palette បញ្ជីសម័យ | បើកសម័យដែលបានជ្រើសរើស (ឬសម័យដំបូង) |
| `ArrowUp` / `ArrowDown` | ម៉ឺនុយលេចឡើងជ្រើសរើសម៉ូដែល | រុករកបញ្ជីម៉ូដែល |
| `Enter` | ម៉ឺនុយលេចឡើងជ្រើសរើសម៉ូដែល | ជ្រើសរើសម៉ូដែលដែលបានរំលេច |
| `ArrowUp` / `ArrowDown` | modal Fork | រុករកសារ |
| `Enter` | modal Fork | Fork ពីសារដែលបានរំលេច |
| `Tab` | sheet ពេញអេក្រង់ | ប្ដូរការផ្ដោតក្នុង sheet |
| `Escape` | sheet ពេញអេក្រង់ | បិទ sheet |
