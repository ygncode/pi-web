# Feuille de route

pi-web est conçu pour deux publics :

- **Pour les développeurs** — qui vivent dans le terminal mais souhaitent poursuivre leurs sessions depuis leur mobile, déléguer à un serveur distant ou garder un œil sur les tâches longues depuis n'importe où.
- **Pour les non-développeurs** — qui veulent simplement une belle application IA qui fonctionne. Ouvrez, tapez, profitez. Pas de terminal, pas de SSH, pas de confusion. Comme les outils IA les plus conviviaux, mais avec le choix du modèle et la liberté de l'open source.

Voici ce qui arrive.

## Vision

L'objectif à long terme : pi-web doit être **l'interface de pi** — pour tout le monde.

- **Les non-développeurs** l'ouvrent comme n'importe quelle autre app. Choisissez un modèle. Tapez. C'est fait. Jamais de ligne de commande.
- **Les développeurs** bénéficient d'une intégration profonde — délégation à distance, tableaux de bord multi-sessions, navigation consciente de Git, bots de messagerie.
- **Tout le monde** profite de la liberté de modèle, de la transparence open source et d'une interface soignée à chaque instant.
