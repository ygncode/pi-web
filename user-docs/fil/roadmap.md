# Roadmap

Ang pi-web ay ginawa para sa dalawang uri ng gumagamit:

- **Para sa mga developer** — na nakatira sa terminal ngunit gustong ipagpatuloy ang mga sesyon mula sa mobile, ipasa sa isang remote server, o bantayan ang mga matagalang gawain kahit saan.
- **Para sa mga hindi developer** — na gusto lang ng magandang AI app na gumagana. Buksan, mag-type, vibe. Walang terminal, walang SSH, walang kalituhan. Tulad ng mga pinakamadaling gamitin na AI tools, ngunit may pagpipilian ng modelo at kalayaan ng open-source.

Ito ang mga paparating.

## Bisyon

Ang pangmatagalang layunin: ang pi-web ay dapat maging **ang interface para sa pi** — para sa lahat.

- **Mga hindi developer** ay binubuksan ito tulad ng ibang app. Pumili ng modelo. Mag-type. Tapos. Walang command line kailanman.
- **Mga developer** ay nakakakuha ng malalim na integrasyon — remote handoff, multi-session dashboard, pagba-browse na may kamalayan sa git, messaging bots.
- **Lahat** ay nakakakuha ng kalayaan sa modelo, transparency ng open-source, at isang UI na maingat at pinag-isipan sa bawat aspeto.
