**Du überlegst, pi-web auszuprobieren? Nur zu — du wirst dich verlieben.**

pi-web ist eine schöne Web-UI und PWA für [pi](https://pi.dev) — den Open-Source-KI-Coding-Agenten. Damit kannst du deine pi-Sitzungen von jedem Browser, auf jedem Gerät durchstöbern, lesen und fortsetzen — mit durchdachten Funktionen an jeder Ecke.

**pi-web ist für zwei Arten von Menschen gemacht:**

- 🧑‍💻 **Für Entwickler** — die im Terminal leben, aber Sitzungen vom Handy aus fortsetzen, an einen entfernten Server übergeben oder langlaufende Aufgaben von überall überwachen möchten.
- ✨ **Für Nicht-Entwickler** — die einfach eine schöne KI-App wollen, die funktioniert. Öffnen, tippen, loslegen. Kein Terminal, kein SSH, keine Verwirrung. Wie die benutzerfreundlichsten KI-Tools, aber mit Modellwahl und Open-Source-Freiheit.

---

## Warum pi-web?

Du bist im Terminal bereits voll im Flow mit pi. pi-web erhält diese Dynamik, wenn du deinen Schreibtisch verlässt:

- **Überall fortsetzen** — führe eine Sitzung von deinem Handy, Tablet oder einem anderen Computer weiter. Kein SSH, kein Termius — öffne einfach deinen Browser.
- **Dashboard für mehrere Sitzungen** — starte Arbeit in einer Sitzung, während du eine andere beim Streamen beobachtest. Suche projektübergreifend, filtere nach Branch, finde schnell, was du brauchst.
- **Open-Source-Basis** — pi ist vollständig Open Source und anbieterunabhängig. Du bist nicht an ein einzelnes Modell oder einen Anbieter gebunden. pi-web ist ebenfalls Open Source.
- **Sicherer Fernzugriff** — eingebaute Token-Authentifizierung, damit du es in deinem LAN oder über Tailscale ohne Bedenken freigeben kannst.
- **Teile deine Arbeit** — exportiere Sitzungen als statische Snapshots oder geheime GitHub Gists mit einem Klick.

## pi-web als dein persönlicher KI-Arbeitsbereich 🏠

pi-web ist eine PWA (Progressive Web App), du kannst es also **wie eine native App installieren** — auf Desktop, Laptop, Handy oder Tablet, ganz ohne App Store. Auf dem Desktop öffnet es sich in einem eigenen Fenster ohne Browser-Chrome, sodass es wie eine echte Desktop-Anwendung aussieht und sich auch so anfühlt.

Stell es dir als **deinen eigenen Claude Cowork** vor — einen persönlichen KI-Arbeitsbereich, der auf deiner Maschine lebt — nur eben Open Source und modellunabhängig:

- **Du besitzt den Stack.** Wähle ein beliebiges Modell, wechsle wann immer du willst. Betreibe ein lokales Modell und deine Daten verlassen nie deine Maschine.
- **Auch Nicht-Techniker können es nutzen.** Richte pi-web auf ihrem Rechner ein, zeig ihnen einmal, wie es funktioniert, und schon sind sie startklar. Deine Eltern, dein Partner, deine nicht-technischen Freunde — kein Terminal, kein SSH, nur eine vertraute Chat-Oberfläche.
- **Ein Setup, viele Nutzer.** Installiere es auf deinem Desktop und teile deinen Bildschirm, oder stelle es in deinem Heimnetzwerk bereit und lass Familienmitglieder es auf ihren eigenen Geräten öffnen.

Willst du mehr als nur Coden? Mach daraus einen dedizierten [persönlichen Assistenten](personal-assistant.md), der weiß, wer du bist, und auf deiner Maschine lebt — wie dein eigener OpenClaw oder Hermes.

> 💡 **Profi-Tipp:** Installiere pi-web als PWA aus Chrome/Edge (klicke auf das Installations-Symbol in der Adressleiste) oder Safari (Teilen → Zum Dock hinzufügen). Es ist dann nicht mehr von einer nativen App zu unterscheiden.

## Was du mit pi-web machen kannst

| | |
|---|---|
| 📱 **PWA** | Installiere pi-web als Progressive Web App auf Desktop, Handy oder Tablet für ein natives Gefühl. |
| 🔄 **Sitzungen fortsetzen** | Nimm jede Unterhaltung genau dort wieder auf, wo du aufgehört hast — Text, Bilder, Modellwechsel, alles aus dem Browser. |
| 🆕 **Neue Sitzungen starten** | Erstelle neue Sitzungen für beliebige Projektpfade, direkt aus der Web-UI. |
| 📡 **Live-Streaming** | Sieh zu, wie pi-Antworten in Echtzeit mit ~ms Latenz streamen. Der Folgen-Modus hält dich am neuesten Stand. |
| 🌲 **Baumansicht** | Navigiere durch pis nativen Nachrichtenbaum — sieh die gesamte Gesprächsstruktur, springe zu jedem Branch und forke von jedem Punkt aus. |
| 🔀 **Sitzungen forken** | Forke eine Sitzung von jeder Nachricht oder sogar einem bestimmten Tool-Aufruf aus — erkunde verschiedene Richtungen, ohne deinen Platz zu verlieren. |
| 🔍 **Stöbern & Suchen** | Filtere Sitzungen projektübergreifend, suche nach Name, navigiere durch Branches — deine gesamte Sitzungshistorie auf einen Blick. |
| 🌿 **Git-Integration** | Sieh den aktuellen Branch und öffne einen GitHub-PR direkt aus dem Sitzungs-Viewer. |
| 📝 **Notizblock** | Halte Notizen, Todos oder schnelle Gedanken neben deinen Sitzungen fest, ohne die App zu wechseln. |
| 💬 **Anmerkungen** | Markiere und kommentiere beliebige Teile einer Sitzung — ideal für Code-Review, Feedback oder das Festhalten wichtiger Momente. |
| 🎨 **Themes & Anpassung** | Wechsle zwischen Dunkel- und Hellmodus, passe die UI nach deinem Geschmack an — mach pi-web zu *deinem*. |
| 🌐 **Mehrsprachig** | 14 eingebaute Sprachen (English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ភាសាខ្មែរ, ລາວ). Füge in den Einstellungen deine eigene Sprache hinzu. |
| 🐱 **Wellness & pomodoro** | Zu viel Vibe-Coding ist nicht gesund. Eingebauter pomodoro-Timer mit Katzen-Begleiter und Schlaf-Erinnerungen, damit du im Gleichgewicht bleibst. |
| 📤 **Teilen & Exportieren** | Lade JSONL herunter, exportiere statische Snapshots im nativen `pi.dev`-Look von pi oder teile sie als private GitHub Gists — alles clientseitig gerendert. |
| 🔔 **Benachrichtigungstöne** | Anpassbare Benachrichtigungsklänge für Sitzungs-Ereignisse — bleib auf dem Laufenden, auch wenn pi-web in einem anderen Tab ist. |
| ⌨️ **Tastenkürzel** | Navigation im Vim-Stil, Schnellaktionen — [vollständige Referenz →](keyboard-shortcuts.md) |
| 🤖 **Persönlicher Assistent** | Mach pi-web zu deinem eigenen KI-Assistenten, der auf deinem Computer lebt — wie OpenClaw oder Hermes. [Einrichtung →](personal-assistant.md) |
| 🗓️ **Mit Zeitplänen sprechen** | Sag in einer pi-Sitzung „Füge einen Zeitplan um 2 Uhr nachts Singapur-Zeit zu … hinzu" — `/skill:pi-web-schedule`. |
| 📝 **Mit Notizen & Einstellungen sprechen** | „Schreib das in die Notizen" (`/skill:pi-web-notes`) oder „Wechsle in den Dunkelmodus" (`/skill:pi-web-settings`). |
