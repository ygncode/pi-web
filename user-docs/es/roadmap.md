# Hoja de ruta

pi-web está construido para dos audiencias:

- **Para desarrolladores** — que viven en la terminal pero quieren continuar sesiones desde el móvil, delegar a un servidor remoto o vigilar tareas largas desde cualquier lugar.
- **Para no desarrolladores** — que solo quieren una app de IA bonita que funcione. Ábrela, escribe, disfruta. Sin terminal, sin SSH, sin confusiones. Como las herramientas de IA más intuitivas, pero con libertad de modelo y código abierto.

Esto es lo que viene.

## Visión

El objetivo a largo plazo: pi-web debería ser **la interfaz para pi** — para todos.

- **No desarrolladores** lo abren como cualquier otra app. Eligen un modelo. Escriben. Listo. Sin línea de comandos nunca.
- **Desarrolladores** obtienen integración profunda — delegación remota, paneles multi-sesión, navegación consciente de git, bots de mensajería.
- **Todos** obtienen libertad de modelo, transparencia de código abierto y una interfaz que se siente cuidada en cada detalle.
