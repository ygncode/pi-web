# ကီးဘုတ် ဖြတ်လမ်းများ

## ပင်မ စာမျက်နှာ (`/`)

### စာမျက်နှာ ရွှေ့လျားခြင်း (vim-style)

တူညီသော vim-style ဖြတ်လမ်းများသည် focus သည် input, textarea, သို့မဟုတ် contenteditable element တစ်ခုထဲတွင် **မရှိသောအခါ** စာမျက်နှာအားလုံးတွင် အလုပ်လုပ်ပါသည်။

| ဖြတ်လမ်း | လုပ်ဆောင်ချက် |
|----------|--------|
| `j` | 300px အောက်သို့ ရွှေ့ပါ |
| `k` | 300px အပေါ်သို့ ရွှေ့ပါ |
| `g g` | စာမျက်နှာ ထိပ်သို့ ရွှေ့ပါ |
| `G` (Shift+G) | စာမျက်နှာ အောက်ဆုံးသို့ ရွှေ့ပါ |
| `Escape` | j/k ရွှေ့လျားမှု အလုပ်လုပ်နိုင်ရန် active input ကို blur လုပ်ပါ |

### ပင်မ ညွှန်ကြားချက်များ

| ဖြတ်လမ်း | ဆက်စပ်အခြေအနေ | လုပ်ဆောင်ချက် |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | စာမျက်နှာ အဆင့် | ရှာဖွေမှု/စက်ရှင်များ palette ကို ဖွင့်ပါ |
| `⌘,` / `Ctrl+,` | စာမျက်နှာ အဆင့် | ဆက်တင်များကို ဖွင့်ပါ |
| `⌘⇧L` / `Ctrl+Shift+L` | စာမျက်နှာ အဆင့် | စနစ် အပြင်အဆင် (အလင်း/အမှောင်) ကို ပြောင်းပါ |
| `Escape` | စာမျက်နှာ အဆင့် | palette, menu, သို့မဟုတ် modal ကို ပိတ်ပါ |
| `Enter` | စက်ရှင်အသစ် လမ်းကြောင်း input | စက်ရှင်အသစ် ဖန်တီးပါ |

> `⌘K` / `Ctrl+K` သည် Chrome ၏ "focus address bar" ဖြတ်လမ်းလည်း ဖြစ်သည်။ focus သည် text input တစ်ခုအတွင်း မရှိပါက ဘရောက်ဆာက ၎င်းကို ကြားဖြတ်ဖမ်းယူနိုင်သည်။

## စက်ရှင် အသေးစိတ် စာမျက်နှာ (`/session?id=...`)

### စာမျက်နှာ ရွှေ့လျားခြင်း (vim-style)

၎င်းတို့သည် focus သည် input, textarea, သို့မဟုတ် contenteditable element တစ်ခုထဲတွင် **မရှိသောအခါ** ပင်မနှင့် စက်ရှင်စာမျက်နှာ နှစ်ခုစလုံးတွင် အလုပ်လုပ်ပါသည်။

| ဖြတ်လမ်း | လုပ်ဆောင်ချက် |
|----------|--------|
| `j` | 300px အောက်သို့ ရွှေ့ပါ |
| `k` | 300px အပေါ်သို့ ရွှေ့ပါ |
| `g g` | စာမျက်နှာ ထိပ်သို့ ရွှေ့ပါ |
| `G` (Shift+G) | စာမျက်နှာ အောက်ဆုံးသို့ ရွှေ့ပါ |
| `I` (Shift+I) | chat composer textarea ကို focus လုပ်ပါ |
| `Escape` | j/k ရွှေ့လျားမှု အလုပ်လုပ်နိုင်ရန် active input ကို blur လုပ်ပါ |

### Sidebar နှင့် ရွှေ့လျားမှု

| ဖြတ်လမ်း | ဆက်စပ်အခြေအနေ | လုပ်ဆောင်ချက် |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | စာမျက်နှာ အဆင့် | sidebar မြင်နိုင်မှုကို ပြောင်းပါ |
| `⌘K` / `Ctrl+K` | စာမျက်နှာ အဆင့် | စက်ရှင်စာရင်း palette ကို ဖွင့်ပါ |
| `⌘T` / `Ctrl+T` | စာမျက်နှာ အဆင့် | စက်ရှင်အသစ် |
| `⌘/` / `Ctrl+/` | စာမျက်နှာ အဆင့် | ကီးဘုတ်ဖြတ်လမ်းများ modal ကို ပြပါ |
| `⌘,` / `Ctrl+,` | စာမျက်နှာ အဆင့် | ဆက်တင်များကို ဖွင့်ပါ |
| `⌘⇧L` / `Ctrl+Shift+L` | စာမျက်နှာ အဆင့် | စနစ် အပြင်အဆင် (အလင်း/အမှောင်) ကို ပြောင်းပါ |
| `⌘⇧N` / `Ctrl+Shift+N` | စာမျက်နှာ အဆင့် | scratchpad / မှတ်စုများ sidebar ကို ပြောင်းပါ |

> `⌘K` နှင့် `⌘T` တို့သည် ဘရောက်ဆာ ဖြတ်လမ်းများ (focus address bar / tab အသစ်) လည်း ဖြစ်သည်။ focus သည် text input တစ်ခုအတွင်း မရှိပါက ဘရောက်ဆာက ၎င်းတို့ကို ကြားဖြတ်ဖမ်းယူနိုင်သည်။

### Chat composer

| ဖြတ်လမ်း | ဆက်စပ်အခြေအနေ | လုပ်ဆောင်ချက် |
|----------|---------|--------|
| `Enter` | Chat textarea | စာပို့ပါ |
| `Shift+Enter` | Chat textarea | စာကြောင်းအသစ် ထည့်ပါ |
| `Shift+Tab` | Chat textarea | နောက် thinking level သို့ လှည့်ပါ (`off` → `minimal` → … → `xhigh` → `off`) |
| `Ctrl+I` / `Ctrl+L` | Chat textarea | model selector popup ကို ဖွင့်ပါ (စာရိုက်၍ filter လုပ်ပါ၊ Enter ဖြင့် ရွေးပါ၊ focus သည် textarea သို့ ပြန်ရောက်သည်) |

| `o` | focus သည် input/textarea ထဲတွင် **မရှိသောအခါ** | tools မြင်နိုင်မှုကို ပြောင်းပါ |
| `p` | focus သည် input/textarea ထဲတွင် **မရှိသောအခါ** | tool outputs ကို ပြောင်းပါ |

### Palettes, menus နှင့် sheets

| ဖြတ်လမ်း | ဆက်စပ်အခြေအနေ | လုပ်ဆောင်ချက် |
|----------|---------|--------|
| `Escape` | စာမျက်နှာ အဆင့် | ဖွင့်ထားသော palette, menu, သို့မဟုတ် sheet မှန်သမျှကို ပိတ်ပါ |

| `ArrowUp` / `ArrowDown` | စက်ရှင်စာရင်း palette | စက်ရှင်ရလဒ်များကို ရွှေ့လျားပါ |
| `Enter` | စက်ရှင်စာရင်း palette | ရွေးထားသော (သို့မဟုတ် ပထမ) စက်ရှင်ကို ဖွင့်ပါ |
| `ArrowUp` / `ArrowDown` | Model selector popup | model စာရင်းကို ရွှေ့လျားပါ |
| `Enter` | Model selector popup | highlight လုပ်ထားသော model ကို ရွေးပါ |
| `ArrowUp` / `ArrowDown` | Fork modal | စာများကို ရွှေ့လျားပါ |
| `Enter` | Fork modal | highlight လုပ်ထားသော စာမှ fork လုပ်ပါ |
| `Tab` | Full-screen sheet | sheet အတွင်း focus ကို လှည့်ပါ |
| `Escape` | Full-screen sheet | sheet ကို ပိတ်ပါ |
