# လမ်းပြမြေပုံ

pi-web ကို ပရိသတ် နှစ်မျိုးအတွက် တည်ဆောက်ထားပါသည်:

- **Developer များအတွက်** — terminal ထဲတွင် အလုပ်လုပ်သော်လည်း မိုဘိုင်းမှ session များကို ဆက်လုပ်လိုသူများ၊ အဝေးဆာဗာသို့ လွှဲပြောင်းလိုသူများ၊ သို့မဟုတ် ကြာမြင့်စွာ လည်ပတ်နေသော လုပ်ငန်းများကို ဘယ်နေရာမှမဆို စောင့်ကြည့်လိုသူများ။
- **Developer မဟုတ်သူများအတွက်** — အလုပ်လုပ်တဲ့ လှပသော AI app တစ်ခုကိုသာ လိုချင်သူများ။ ဖွင့်လိုက်၊ ရိုက်ထည့်လိုက်၊ ခံစားလိုက်။ terminal မလို၊ SSH မလို၊ ရှုပ်ထွေးမှု မရှိ။ အသုံးပြုရ အလွယ်ဆုံး AI ကိရိယာများကဲ့သို့ပင်၊ သို့သော် model ရွေးချယ်ခွင့်နှင့် open-source လွတ်လပ်မှုတို့ ပါဝင်သည်။

လာမည့်အရာများမှာ ဤသို့ဖြစ်သည်။

---

## ယခု (ထွက်ရှိပြီး)

ယခင်က ဤလမ်းပြမြေပုံပေါ်တွင် ရှိခဲ့ပြီး ထိုအချိန်မှစ၍ ထွက်ရှိပြီးသား အင်္ဂါရပ်များ:

| အင်္ဂါရပ် | လုပ်ဆောင်ချက် |
|---|---|

| **အချိန်ဇယား** ([#44](https://github.com/ygncode/pi-web/issues/44)) | prompt များကို အလိုအလျောက် လည်ပတ်ရန် အချိန်ဇယားချထားနိုင်သည် — နေ့စဉ် standup များ၊ နံနက်ခင်း အကျဉ်းချုပ်များ၊ ပုံမှန် ထပ်တလဲလဲ လုပ်ငန်းများ — `/schedules` စာမျက်နှာမှ။ |

## ရည်မှန်းချက်

ရေရှည် ရည်မှန်းချက်: pi-web သည် လူတိုင်းအတွက် **pi ၏ interface** ဖြစ်သင့်သည်။

- **Developer မဟုတ်သူများ** သည် ၎င်းကို အခြား app တစ်ခုကဲ့သို့ ဖွင့်သည်။ model တစ်ခု ရွေးသည်။ ရိုက်ထည့်သည်။ ပြီးသည်။ command line လုံးဝ မလိုပါ။
- **Developer များ** သည် နက်ရှိုင်းသော ပေါင်းစည်းမှုကို ရရှိသည် — အဝေးမှ လွှဲပြောင်းခြင်း၊ multi-session dashboard များ၊ git-သိရှိသော ကြည့်ရှုမှု၊ messaging bots များ။
- **လူတိုင်း** သည် model လွတ်လပ်မှု၊ open-source ပွင့်လင်းမြင်သာမှုနှင့် အဆင့်တိုင်းတွင် စဉ်းစားပေးထားသော UI တစ်ခုကို ရရှိသည်။
