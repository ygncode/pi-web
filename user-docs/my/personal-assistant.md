# pi-web ကို သင့်ကိုယ်ပိုင်လက်ထောက်အဖြစ် အသုံးပြုခြင်း

pi-web သည် coding အတွက်သာမက — သင့်ကွန်ပျူတာပေါ်တွင် နေထိုင်သည့် **ကိုယ်ပိုင် AI လက်ထောက်** အဖြစ် ပြောင်းလဲနိုင်သည်၊ သင့်ကိုယ်ပိုင် OpenClaw သို့မဟုတ် Hermes ရှိသကဲ့သို့ဖြစ်သည်။

## မည်သို့အလုပ်လုပ်သည်

သင့်စက်ပေါ်တွင် သီးသန့်ဖိုင်တွဲတစ်ခု ဖန်တီးပါ — ထိုနေရာသည် သင့်လက်ထောက်နေထိုင်ရာဖြစ်သည်။ အတွင်းတွင်၊ သင့်လက်ထောက်မည်သူဖြစ်သည်၊ မည်သည့်အရာများသိသည်၊ မည်သို့ပြုမူသည်ကို သတ်မှတ်သည့် `APPEND_SYSTEM.md` ဖိုင်တစ်ခုကို ထည့်ပါ။ pi-web က သင့်အား မည်သည့်စက်မှမဆို စကားပြောရန် လှပသော chat interface တစ်ခုပေးသည်။

## တစ်ဆင့်ချင်းစီ

### ၁။ သင့်လက်ထောက်ဖိုင်တွဲကို ဖန်တီးပါ

သင့်ကွန်ပျူတာပေါ်ရှိ ဖိုင်တွဲတစ်ခုကို ရွေးပါ။ ဥပမာ-

```
~/my-assistant/
```

### ၂။ သင့်လက်ထောက်ကို သတ်မှတ်ပါ

ထိုဖိုင်တွဲအတွင်း `APPEND_SYSTEM.md` ဖိုင်တစ်ခု ဖန်တီးပါ။ ဤနေရာတွင် pi အား သင့်လက်ထောက်မည်သူဖြစ်ကြောင်း ပြောပြသည်-

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi သည် ၎င်းကို စကားပြောခန်းတိုင်း၏ system prompt သို့ အလိုအလျောက် ထည့်ပေးသဖြင့်၊ သင့်လက်ထောက်သည် သင်မည်သူဖြစ်သည်နှင့် မည်သို့ကူညီရမည်ကို အမြဲသိနေသည်။

### ၃။ ထိုဖိုင်တွဲတွင် session တစ်ခုစတင်ပါ

pi-web တွင်၊ `~/my-assistant/` (သို့မဟုတ် သင်နာမည်ပေးထားသည့်အတိုင်း) သို့ ညွှန်ပြသည့် session အသစ်တစ်ခုဖန်တီးပါ။ ဒါပါပဲ — သင်သည် သင့်ကိုယ်ပိုင်လက်ထောက်နှင့် စကားပြောနေပြီဖြစ်သည်။

### ၄။ မည်သည့်နေရာမှမဆို အသုံးပြုပါ

pi-web ကို သင့်ဖုန်း၊ တက်ဘလက် သို့မဟုတ် လက်ပ်တော့ပေါ်တွင် PWA အဖြစ် ထည့်သွင်းပါ။ သင့်လက်ထောက်သည် အမြဲရှိနေသည် — မည်သည့်အရာကိုမဆို၊ မည်သည့်အချိန်တွင်မဆို မေးမြန်းပါ။

## သင့်လက်ထောက်အတွက် စိတ်ကူးများ

| အခန်းကဏ္ဍ | APPEND_SYSTEM.md တွင် ထည့်ရမည့်အရာ |
|---|---|
| 🧠 **ဘဝနည်းပြ** | သင့်ရည်မှန်းချက်များ၊ သင်လုပ်ဆောင်နေသော အလေ့အကျင့်များ၊ ဂျာနယ်ရေးရန် အကြောင်းအရာများ |
| 🏠 **အိမ်မန်နေဂျာ** | စျေးဝယ်စာရင်းပုံစံ၊ မိသားစုဝင်များ၏ နှစ်သက်မှုများ၊ အစားအသောက်စီစဉ်ခြင်း |
| 💼 **အလုပ်ဖော်** | သင့်ရာထူး၊ လက်ရှိပရောဂျက်များ၊ အစည်းအဝေးမှတ်စုပုံစံ၊ ကုမ္ပဏီအကြောင်းအရာ |
| 📚 **စာသင်ဖော်** | သင်သင်ယူနေသည်များ၊ နှစ်သက်သော ရှင်းပြမှုပုံစံ၊ စာမေးခွန်းမေးသည့်မုဒ် |
| ✍️ **စာရေးလက်ထောက်** | သင့်စာရေးဟန်၊ လေသံနှစ်သက်မှုများ၊ သင်အသုံးပြုလေ့ရှိသော ပုံစံများ |

## အကြောင်းအရာ ပိုမိုထည့်ပါ

pi ကို ပိုမိုအသုံးဝင်စေရန် သင့်လက်ထောက်ဖိုင်တွဲတွင် မည်သည့်အရာကိုမဆို ထည့်နိုင်သည်-

- `notes/` — သင့်လက်ထောက်ဖတ်နိုင်သော ကိုးကားဖိုင်များ
- `context.md` — သင့်ဘဝ သို့မဟုတ် အလုပ်အကြောင်း နောက်ခံအချက်အလက်
- `projects.md` — လက်ရှိပရောဂျက်များနှင့် ၎င်းတို့၏အခြေအနေ

pi သည် ဖိုင်တွဲအတွင်းရှိဖိုင်များကို ဖတ်နိုင်သဖြင့်၊ အကြောင်းအရာများများပေးလေလေ ပိုကောင်းလေဖြစ်သည်။

---

> 💡 **အကြံပြုချက်:** ရိုးရိုးမှစပါ။ သင်မည်သူဖြစ်ကြောင်းနှင့် လက်ထောက်ကို မည်သို့ပြုမူစေလိုကြောင်း စာကြောင်းအနည်းငယ်သာ ရေးပါ။ မည်သည်ကအလုပ်ဖြစ်သည်ကို သိလာသည်နှင့်အမျှ အချိန်နှင့်အမျှ တိုးတက်အောင်လုပ်ပါ။
