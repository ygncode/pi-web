# pi-web ကို သင့်ကိုယ်ပိုင် အကူလက်တော်အဖြစ် အသုံးပြုခြင်း

pi-web ဟာ ကုဒ်ရေးခြင်းအတွက်ပဲ မဟုတ်ပါဘူး — သင့်ကွန်ပျူတာပေါ်မှာ နေထိုင်တဲ့ **ကိုယ်ပိုင် AI အကူ** တစ်ယောက်အဖြစ် ပြောင်းလဲနိုင်ပါတယ်၊ ကိုယ်ပိုင် OpenClaw သို့မဟုတ် Hermes ရှိသလိုမျိုးပေါ့။

## ဘယ်လို အလုပ်လုပ်သလဲ

သင့်စက်ပေါ်မှာ သီးသန့် folder တစ်ခု ဖန်တီးပါ — အဲဒီမှာ သင့်အကူ နေထိုင်ပါတယ်။ အထဲမှာ သင့်အကူက ဘယ်သူလဲ၊ ဘာတွေသိလဲ၊ ဘယ်လို ပြုမူလဲဆိုတာ သတ်မှတ်ပေးတဲ့ `APPEND_SYSTEM.md` ဖိုင်တစ်ခု ထည့်လိုက်ပါ။ pi-web က ဘယ်စက်ကနေမဆို စကားပြောနိုင်တဲ့ လှပတဲ့ chat interface တစ်ခု ပေးပါတယ်။

## တစ်ဆင့်ချင်း

### ၁. သင့်အကူရဲ့ folder ကို ဖန်တီးပါ

သင့်ကွန်ပျူတာပေါ်မှာ folder တစ်ခု ရွေးပါ။ ဥပမာအားဖြင့်:

```
~/my-assistant/
```

### ၂. သင့်အကူကို သတ်မှတ်ပါ

အဲဒီ folder ထဲမှာ `APPEND_SYSTEM.md` ဖိုင်တစ်ခု ဖန်တီးပါ။ ဒီမှာ သင့်အကူက ဘယ်သူလဲဆိုတာ pi ကို ပြောပြရပါမယ်:

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi က ဒါကို စကားဝိုင်းတိုင်းရဲ့ system prompt မှာ အလိုအလျောက် ထည့်ပေးပါတယ်၊ ဒါကြောင့် သင့်အကူက သင်ဘယ်သူလဲနဲ့ ဘယ်လို ကူညီရမယ်ဆိုတာ အမြဲ သိပါတယ်။

### ၃. အဲဒီ folder ထဲမှာ session တစ်ခု စတင်ပါ

pi-web မှာ `~/my-assistant/` (ဒါမှမဟုတ် သင်နာမည်ပေးထားတဲ့အတိုင်း) ကို ညွှန်ထားတဲ့ session အသစ်တစ်ခု ဖန်တီးပါ။ ဒါပဲ — သင့်ကိုယ်ပိုင် အကူနဲ့ စကားပြောနေပါပြီ။

### ၄. ဘယ်နေရာကနေမဆို အသုံးပြုပါ

pi-web ကို သင့်ဖုန်း၊ တက်ဘလက် သို့မဟုတ် လက်ပ်တော့ပေါ်မှာ PWA အဖြစ် Install လုပ်ပါ။ သင့်အကူက အမြဲ အဲဒီမှာ ရှိနေပါတယ် — ဘာကိုမဆို၊ ဘယ်အချိန်မဆို မေးနိုင်ပါတယ်။

## သင့်အကူအတွက် အကြံဉာဏ်များ

| အခန်းကဏ္ဍ | APPEND_SYSTEM.md မှာ ထည့်ရမယ့်အရာ |
|---|---|
| 🧠 **ဘဝနည်းပြ** | သင့်ပန်းတိုင်များ၊ လုပ်ဆောင်နေတဲ့ အလေ့အထများ၊ ဂျာနယ်ရေးဖို့ အချက်များ |
| 🏠 **အိမ်မန်နေဂျာ** | ကုန်စုံစာရင်း ပုံစံ၊ မိသားစုဝင်တွေရဲ့ ကြိုက်နှစ်သက်မှုများ၊ အစားအစာ စီစဉ်ခြင်း |
| 💼 **အလုပ်ဖော်** | သင့်ရာထူး၊ လက်ရှိ ပရောဂျက်များ၊ အစည်းအဝေး မှတ်စုပုံစံ၊ ကုမ္ပဏီအကြောင်းအရာ |
| 📚 **စာကျက်ဖော်** | သင်သင်ယူနေတဲ့အရာ၊ ကြိုက်နှစ်သက်တဲ့ ရှင်းပြပုံစံ၊ မေးခွန်းစစ်တဲ့ mode |
| ✍️ **စာရေးအကူ** | သင့်စာရေးဟန်၊ အသံနေအသံထား ကြိုက်နှစ်သက်မှုများ၊ သင်အသုံးပြုတဲ့ အသုံးများတဲ့ ပုံစံများ |

## အကြောင်းအရာ ပိုထည့်ပါ

pi ကို ပိုအသုံးဝင်စေတဲ့ ဘာကိုမဆို သင့်အကူရဲ့ folder ထဲ ထည့်နိုင်ပါတယ်:

- `notes/` — သင့်အကူ ဖတ်နိုင်တဲ့ ကိုးကားဖိုင်များ
- `context.md` — သင့်ဘဝ သို့မဟုတ် အလုပ်နဲ့ပတ်သက်တဲ့ နောက်ခံအချက်အလက်
- `projects.md` — လက်ရှိ ပရောဂျက်များနဲ့ ၎င်းတို့ရဲ့ အခြေအနေ

pi က folder ထဲက ဖိုင်တွေကို ဖတ်နိုင်ပါတယ်၊ ဒါကြောင့် အကြောင်းအရာ များများပေးလေ၊ ပိုကောင်းလေပါပဲ။

## pi-web ကို အလုပ်တွေ ခိုင်းပါ

`pi install npm:@ygncode/pi-web@beta` လုပ်ပြီးနောက်၊ session တွေက pi-web ကိုယ်တိုင်နဲ့ စကားပြောနိုင်ပါတယ်။ စမ်းကြည့်ပါ:

- "ကျွန်တော့်ရဲ့ inbox ကို အကျဉ်းချုပ်ဖို့ စင်္ကာပူအချိန် မနက် ၂ နာရီမှာ schedule တစ်ခု ထည့်ပါ"
- "ကျွန်တော့်ရဲ့ pi-web schedule တွေ စာရင်းပြပါ"
- "inbox schedule ကို ခဏရပ်ပါ"
- "ဒါကို notes ထဲ ရေးထားပါ"
- "pi-web ကို dark mode ပြောင်းပါ / auto-title ကို ပိတ်ပါ"

ပါလာတဲ့ **/skill:pi-web-schedule** skill က အဲဒါကို တကယ့် pi-web schedule အဖြစ် ပြောင်းပေးပါတယ် (`/schedules` မှာ သင်တည်းဖြတ်တဲ့ဟာတွေနဲ့ အတူတူပါပဲ)။ အကြိမ်တိုင်း စတင်တဲ့အခါ session **အသစ်** တစ်ခု စတင်ပါတယ်၊ ဒါကြောင့် ညွှန်ကြားချက်တွေက သီးခြားရပ်တည်နိုင်ရပါမယ် — "~/inbox ထဲက မဖတ်ရသေးတဲ့ မေးလ်တွေကို အကျဉ်းချုပ်ပါ" ဆိုတာ အလုပ်လုပ်ပါတယ်; "ငါတို့ လုပ်နေတာကို ဆက်လုပ်ပါ" ဆိုတာက အလုပ်မလုပ်ပါဘူး။

Schedule တွေက pi-web လည်ပတ်နေမှပဲ အလုပ်လုပ်ပါတယ်။

---

> 💡 **အကြံပြုချက်:** ရိုးရှင်းရှင်း စတင်ပါ။ သင်ဘယ်သူလဲနဲ့ အကူကို ဘယ်လို ပြုမူစေချင်လဲဆိုတဲ့ စာကြောင်းအနည်းငယ်ပဲ လုံလောက်ပါတယ်။ ဘာအလုပ်ဖြစ်တယ်ဆိုတာ သိလာတာနဲ့အမျှ အချိန်ကြာလာရင် ပြန်ပြင်ဆင်ပါ။
