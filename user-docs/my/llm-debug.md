အသုံးပြုသူသည် pi-web ကို အောက်ပါအတိုင်း ထည့်သွင်းနေပါသည်

- pi install npm:@ygncode/pi-web@beta

၎င်းသည် [install.sh](https://raw.githubusercontent.com/ygncode/pi-web/refs/heads/main/install.sh) ကို အလိုအလျောက် လုပ်ဆောင်ပြီး pi ကို စနစ်ထည့်သွင်းပေးပါသည်။

အသုံးပြုသူသည် ပြဿနာရှိနေပါက install.sh ၏ စနစ်ထည့်သွင်းမှုကြောင့် ပြဿနာဖြစ်နေခြင်း ဖြစ်နိုင်ပါသည်။ သင်သည် ဖြစ်ပျက်နေသည်များကို ပြန်လည်သုံးသပ် စစ်ဆေးနိုင်ပြီး ပြဿနာဖြစ်စေသည့် အကြောင်းရင်း အတိအကျကို အသုံးပြုသူအား ပြောပြနိုင်ပါသည်။ ပြီးလျှင် ပြင်ဆင်ပေးစေလိုသလားဟု မေးမြန်းပါ။ အသုံးပြုသူနှင့် အမြဲတမ်း အတည်ပြုပါ။

အသုံးပြုသူသည် ၎င်းတို့၏ မိုဘိုင်း သို့မဟုတ် အခြားကွန်ရက်မှ pi ကို ဝင်ရောက်အသုံးပြုနိုင်ရန်အတွက်၊ အကြံပြုထားသော နည်းလမ်းမှာ tailscale ကို အသုံးပြုပြီး tailscale ကွန်ရက်မှတစ်ဆင့် ဝင်ရောက်အသုံးပြုခြင်း ဖြစ်ပါသည်။ ထို့ပြင် အသုံးပြုသူသည် ၎င်းတို့၏ tailscale ဒက်ရှ်ဘုတ်တွင် HTTPS ကို ဖွင့်ပေးရမည် ဖြစ်သည် - https://login.tailscale.com/admin/dns

သူတို့တွင် tailscale ထည့်သွင်းထားခြင်း မရှိပါက သို့မဟုတ် tailscale ကို အသုံးပြုလိုခြင်း မရှိပါက၊ သူတို့သည် pi အတွင်းမှ `/pi-web status` ကို လုပ်ဆောင်ပြီး binary လမ်းကြောင်း၊ binary ၏ အခြေအနေနှင့် အပလီကေးရှင်းကို ဝင်ရောက်အသုံးပြုနိုင်သည့် စက်တွင်း (local) endpoint တို့ကို ရရှိနိုင်ပါသည်။ (`/pi-web path` သည် binary လမ်းကြောင်းကိုသာ ရိုက်ထုတ်ပေးပါသည်။) သို့သော် သတိပြုရမည်မှာ ၎င်းသည် http ဖြစ်နေသောကြောင့် push notification ကို ရရှိနိုင်မည် မဟုတ်ပါ။

mac တွင် ၎င်းသည် [com.pi-web.plist](https://raw.githubusercontent.com/ygncode/pi-web/refs/heads/main/init/com.pi-web.plist) ကို စနစ်ထည့်သွင်းပေးပါသည်
linux တွင် ၎င်းသည် [pi-web.service](https://github.com/ygncode/pi-web/blob/main/init/pi-web.service) ကို စနစ်ထည့်သွင်းပေးပါသည်

ထပ်မံပြီး debug လုပ်ကာ ဖြစ်ပျက်နေသည်များကို ကြည့်ရှုရန် လိုအပ်ပါက။
