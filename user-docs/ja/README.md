**pi-web を試そうか迷っていますか？ ぜひ試してみてください — きっと気に入ります。**

pi-web は、オープンソースの AI コーディングエージェントである [pi](https://pi.dev) のための美しい Web UI 兼 PWA です。どのブラウザからでも、どのデバイスからでも、pi セッションを閲覧し、読み、継続でき、随所に気の利いた機能が備わっています。

**pi-web は 2 種類の人に向けて作られています：**

- 🧑‍💻 **開発者向け** — ターミナル中心の生活を送りながら、モバイルからセッションを継続したり、リモートサーバーに引き継いだり、長時間実行するタスクをどこからでも監視したい人。
- ✨ **非開発者向け** — ただ美しく動く AI アプリを求めている人。開いて、入力して、あとはそのまま。ターミナルも SSH も不要、混乱もありません。最も使いやすい AI ツールのようでありながら、モデルの選択肢とオープンソースの自由があります。

---

## なぜ pi-web なのか？

ターミナルで pi のフローにすでにどっぷり浸かっているあなた。pi-web は、席を離れたときもその勢いを保ち続けます：

- **どこからでも再開** — スマホ、タブレット、別のパソコンからセッションを継続できます。SSH も Termius も不要 — ブラウザを開くだけ。
- **マルチセッションダッシュボード** — あるセッションで作業を開始しながら、別のセッションのストリームを眺めることができます。プロジェクトを横断して検索し、ブランチで絞り込み、必要なものをすばやく見つけられます。
- **オープンソース基盤** — pi は完全なオープンソースで、プロバイダー非依存です。単一のモデルやベンダーに縛られることはありません。pi-web もオープンソースです。
- **安全なリモートアクセス** — トークン認証が組み込まれているので、LAN や Tailscale 上に公開しても安心です。
- **作業を共有** — セッションを静的スナップショットやシークレット GitHub Gist としてワンクリックでエクスポートできます。

## パーソナル AI ワークスペースとしての pi-web 🏠

pi-web は PWA（Progressive Web App）なので、デスクトップ、ノートパソコン、スマホ、タブレットに **ネイティブアプリのようにインストール** できます — アプリストアは不要です。デスクトップではブラウザの枠なしの独自ウィンドウで開くので、本物のデスクトップアプリケーションのように見え、操作できます。

これは **自分専用の Claude Cowork** — あなたのマシン上に存在するパーソナル AI ワークスペース — と考えてください。ただし、オープンソースでモデル非依存です：

- **スタックはあなたのもの。** 好きなモデルを選び、いつでも切り替えられます。ローカルモデルを実行すれば、データがマシンの外に出ることはありません。
- **非技術者でも使えます。** 相手のマシンに pi-web をセットアップし、使い方を一度見せれば、それで完了です。両親、パートナー、非技術系の友人 — ターミナルも SSH も不要で、ただおなじみのチャットインターフェースがあるだけです。
- **一度のセットアップで多数のユーザーが利用。** デスクトップにインストールして画面を共有するか、ホームネットワーク上に公開して家族が各自のデバイスで開けるようにできます。

コーディング以上のことをしたいですか？ あなたのことを理解し、マシン上に存在する専用の [パーソナルアシスタント](personal-assistant.md) に変身させましょう — 自分専用の OpenClaw や Hermes のように。

> 💡 **プロのヒント:** Chrome/Edge（アドレスバーのインストールアイコンをクリック）または Safari（共有 → Dock に追加）から pi-web を PWA としてインストールしましょう。ネイティブアプリと見分けがつかなくなります。

## pi-web でできること

| | |
|---|---|
| 📱 **PWA** | pi-web をデスクトップ、スマホ、タブレットにプログレッシブウェブアプリとしてインストールして、ネイティブな感覚を。 |
| 🔄 **セッションの継続** | 会話を中断した場所からそのまま再開できます — テキスト、画像、モデル切り替え、すべてブラウザから。 |
| 🆕 **新しいセッションの開始** | 任意のプロジェクトパスに対して、Web UI から直接新しいセッションを作成できます。 |
| 📡 **ライブストリーミング** | pi の応答が約ミリ秒のレイテンシでリアルタイムにストリーミングされるのを見られます。フォローモードで常に最新の位置をキープ。 |
| 🌲 **ツリービュー** | pi のネイティブなメッセージツリーをナビゲート — 会話構造全体を確認し、任意のブランチにジャンプし、どこからでもフォークできます。 |
| 🔀 **セッションのフォーク** | 任意のメッセージ、あるいは特定のツール呼び出しからセッションをフォーク — 場所を見失わずに別の方向を探索できます。 |
| 🔍 **閲覧・検索** | プロジェクトを横断してセッションを絞り込み、名前で検索し、ブランチをナビゲート — 全セッション履歴をひと目で。 |
| 🌿 **Git 統合** | 現在のブランチを確認し、セッションビューアから直接 GitHub PR を開けます。 |
| 📝 **スクラッチパッド** | アプリを切り替えずに、セッションの横でメモ、TODO、ちょっとした考えを書き留められます。 |
| 💬 **注釈** | セッションの任意の部分をハイライトしてコメント — コードレビュー、フィードバック、重要な場面のブックマークに最適。 |
| 🎨 **テーマとカスタマイズ** | ダークモードとライトモードを切り替え、UI をお好みに調整 — pi-web を *自分らしく*。 |
| 🌐 **多言語** | 14 の組み込み言語（English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ភាសាខ្មែរ, ລາວ）。設定から独自のカスタム言語を追加できます。 |
| 🐱 **ウェルネスと pomodoro** | 過度のバイブコーディングは健康的ではありません。猫の相棒と睡眠リマインダー付きの組み込み pomodoro タイマーでバランスを保ちましょう。 |
| 📤 **共有とエクスポート** | JSONL をダウンロード、pi のネイティブな `pi.dev` ルックでレンダリングされた静的スナップショットをエクスポート、またはプライベート GitHub Gist として共有 — すべてクライアントサイドでレンダリングされます。 |
| 🔔 **通知音** | セッションイベントのカスタマイズ可能な通知チャイム — pi-web が別のタブにあっても状況を把握できます。 |
| ⌨️ **キーボードショートカット** | Vim スタイルのナビゲーション、クイックアクション — [全リファレンス →](keyboard-shortcuts.md) |
| 🤖 **パーソナルアシスタント** | pi-web を、コンピュータ上に存在する自分専用の AI アシスタントに変身させましょう — OpenClaw や Hermes のように。[セットアップ →](personal-assistant.md) |
| 🗓️ **スケジュールに話しかける** | pi セッションから「シンガポール時間の午前2時にスケジュールを追加して…」と言う — `/skill:pi-web-schedule`。 |
| 📝 **ノートと設定に話しかける** | 「これをノートに書いて」（`/skill:pi-web-notes`）または「ダークモードに切り替えて」（`/skill:pi-web-settings`）。 |
