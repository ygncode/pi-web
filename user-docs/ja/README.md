**pi-web を試してみようか迷っていますか？ぜひ試してみてください — きっと気に入るはずです。**

pi-web は、オープンソースの AI コーディングエージェントである [pi](https://pi.dev) のための美しい Web UI および PWA です。どのブラウザからでも、どのデバイスからでも、pi のセッションを閲覧、閲覧、そして続行できます。あらゆる場面で考え抜かれた機能を備えています。

**pi-web は2つのタイプのユーザーのために作られています：**

- 🧑‍💻 **開発者向け** — ターミナルでの作業が中心だが、モバイルからセッションを続けたり、リモートサーバーに引き継いだり、長時間実行のタスクをどこからでも監視したい人。
- ✨ **非開発者向け** — 動作する美しい AI アプリを求めているだけの人。開いて、入力して、楽しむ。ターミナルも SSH も、混乱もなし。最も使いやすい AI ツールのように、しかしモデルの選択肢とオープンソースの自由を備えています。

---

## なぜ pi-web なのか？

あなたはすでにターミナルで pi を使いこなしているでしょう。pi-web は、デスクを離れてもその勢いを保ち続けます：

- **どこからでも再開** — 携帯電話、タブレット、別のコンピューターからセッションを続行できます。SSH も Termius も不要 — ブラウザを開くだけです。
- **マルチセッションダッシュボード** — あるセッションで作業を開始しながら、別のセッションのストリーミングを監視できます。プロジェクトを横断して検索、ブランチでフィルタリング、必要なものを素早く見つけられます。
- **オープンソースの基盤** — pi は完全にオープンソースでプロバイダーに依存しません。単一のモデルやベンダーにロックインされることはありません。pi-web もまたオープンソースです。
- **安全なリモートアクセス** — 組み込みのトークン認証により、LAN や Tailscale 上で安心して公開できます。
- **作業を共有** — セッションを静的スナップショットとしてエクスポートしたり、プライベートな GitHub Gist としてワンクリックで共有できます。

## パーソナル AI ワークスペースとしての pi-web 🏠

pi-web は PWA（プログレッシブ Web アプリ）なので、デスクトップ、ラップトップ、携帯電話、タブレットに**ネイティブアプリのようにインストール**できます — アプリストアは不要です。デスクトップではブラウザの枠なしで独自のウィンドウで開くため、本物のデスクトップアプリケーションのように見え、操作できます。

**自分だけの Claude Cowork** のように考えてください — あなたのマシン上に存在するパーソナル AI ワークスペース — ただしオープンソースでモデルに依存しません：

- **スタックはあなたのもの。** 任意のモデルを選び、好きなときに切り替えられます。ローカルモデルを実行すれば、データがマシンから出ることはありません。
- **非技術者も使えます。** 彼らのマシンに pi-web をセットアップし、一度使い方を教えれば、もう大丈夫。あなたの両親、パートナー、技術に詳しくない友人 — ターミナルも SSH も不要、慣れ親しんだチャットインターフェースだけです。
- **1つのセットアップで多数のユーザー。** デスクトップにインストールして画面を共有したり、ホームネットワーク上に公開して家族が自分のデバイスで開けるようにしたりできます。

コーディング以上のことを求めていますか？あなたが誰であるかを知り、あなたのマシン上に存在する専用の[パーソナルアシスタント](personal-assistant.md)に変身させましょう — 自分だけの OpenClaw や Hermes のように。

> 💡 **プロのヒント:** Chrome/Edge（アドレスバーのインストールアイコンをクリック）または Safari（共有 → Dock に追加）から pi-web を PWA としてインストールしてください。ネイティブアプリと見分けがつかなくなります。

## pi-web でできること

| | |
|---|---|
| 📱 **PWA** | pi-web をプログレッシブ Web アプリとしてデスクトップ、携帯電話、タブレットにインストールし、ネイティブな使用感を得られます。 |
| 🔄 **セッションの続行** | テキスト、画像、モデル切り替えまで、あらゆる会話を中断したところからブラウザで再開できます。 |
| 🆕 **新規セッションの開始** | Web UI から直接、任意のプロジェクトパスに対して新しいセッションを作成できます。 |
| 📡 **ライブストリーミング** | pi の応答をミリ秒単位の遅延でリアルタイムにストリーミング視聴できます。フォローモードで最新の状態を追い続けられます。 |
| 🌲 **ツリービュー** | pi のネイティブなメッセージツリーをナビゲート — 会話構造全体を把握し、任意のブランチにジャンプし、任意のポイントから分岐できます。 |
| 🔀 **セッションの分岐** | 任意のメッセージや特定のツール呼び出しからセッションを分岐 — 現在の場所を失うことなく異なる方向性を探索できます。 |
| 🔍 **閲覧・検索** | プロジェクトを横断してセッションをフィルタリング、名前で検索、ブランチをナビゲート — セッション履歴全体を一目で把握できます。 |
| 🌿 **Git 連携** | セッションビューアから現在のブランチを確認し、GitHub PR を開くことができます。 |
| 📝 **スクラッチパッド** | アプリを切り替えることなく、セッションと並行してメモ、TODO、ちょっとした考えを書き留められます。 |
| 💬 **注釈** | セッションの任意の部分をハイライトしてコメント — コードレビュー、フィードバック、重要な瞬間のブックマークに最適です。 |
| 🎨 **テーマ・カスタマイズ** | ダークモードとライトモードを切り替え、UI をお好みに調整 — pi-web を*あなただけのもの*にしましょう。 |
| 🌐 **多言語対応** | 14の組み込み言語（English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ភាសាខ្មែរ, ລາວ）。設定から独自のカスタム言語を追加できます。 |
| 🐱 **ウェルネス & pomodoro** | バイブコーディングのしすぎは健康的ではありません。猫のコンパニオン付きの組み込み pomodoro タイマーと睡眠リマインダーでバランスを保ちましょう。 |
| 📤 **共有・エクスポート** | JSONL のダウンロード、pi ネイティブの `pi.dev` ルックでレンダリングされた静的スナップショットのエクスポート、プライベートな GitHub Gist としての共有 — すべてクライアントサイドでレンダリングされます。 |
| 🔔 **通知音** | セッションイベントのカスタマイズ可能な通知チャイム — pi-web が別のタブにあるときでも状況を把握できます。 |
| ⌨️ **キーボードショートカット** | Vim スタイルのナビゲーション、クイックアクション — [完全なリファレンス →](keyboard-shortcuts.md) |
| 🤖 **パーソナルアシスタント** | pi-web をあなたのコンピューター上に存在する AI アシスタントに変身させましょう — OpenClaw や Hermes のように。[セットアップ方法 →](personal-assistant.md) |
