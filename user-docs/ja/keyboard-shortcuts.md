# キーボードショートカット

## インデックスページ (`/`)

### ページスクロール (vim スタイル)

同じ vim スタイルのショートカットは、フォーカスが input、textarea、または contenteditable 要素に**ない**場合、すべてのページで機能します。

| ショートカット | 動作 |
|----------|--------|
| `j` | 300px 下にスクロール |
| `k` | 300px 上にスクロール |
| `g g` | ページの先頭にスクロール |
| `G` (Shift+G) | ページの末尾にスクロール |
| `Escape` | アクティブな入力からフォーカスを外し、j/k ナビゲーションを有効にする |

### インデックスコマンド

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | ページレベル | 検索/セッションパレットを開く |
| `⌘,` / `Ctrl+,` | ページレベル | 設定を開く |
| `⌘⇧L` / `Ctrl+Shift+L` | ページレベル | システムテーマ (ライト/ダーク) を切り替える |
| `Escape` | ページレベル | パレット、メニュー、またはモーダルを閉じる |
| `Enter` | 新規セッションのパス入力 | 新しいセッションを作成する |

> `⌘K` / `Ctrl+K` は Chrome の「アドレスバーにフォーカス」ショートカットでもあります。フォーカスがテキスト入力内にない限り、ブラウザがそれをインターセプトする可能性があります。

## セッション詳細ページ (`/session?id=...`)

### ページスクロール (vim スタイル)

これらは、フォーカスが input、textarea、または contenteditable 要素に**ない**場合、インデックスページとセッションページの両方で機能します。

| ショートカット | 動作 |
|----------|--------|
| `j` | 300px 下にスクロール |
| `k` | 300px 上にスクロール |
| `g g` | ページの先頭にスクロール |
| `G` (Shift+G) | ページの末尾にスクロール |
| `I` (Shift+I) | チャット入力欄のテキストエリアにフォーカスする |
| `Escape` | アクティブな入力からフォーカスを外し、j/k ナビゲーションを有効にする |

### サイドバーとナビゲーション

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | ページレベル | サイドバーの表示/非表示を切り替える |
| `⌘K` / `Ctrl+K` | ページレベル | セッションリストパレットを開く |
| `⌘T` / `Ctrl+T` | ページレベル | 新しいセッション |
| `⌘/` / `Ctrl+/` | ページレベル | キーボードショートカットのモーダルを表示する |
| `⌘,` / `Ctrl+,` | ページレベル | 設定を開く |
| `⌘⇧L` / `Ctrl+Shift+L` | ページレベル | システムテーマ (ライト/ダーク) を切り替える |
| `⌘⇧N` / `Ctrl+Shift+N` | ページレベル | スクラッチパッド / ノートサイドバーを切り替える |

> `⌘K` と `⌘T` はブラウザのショートカット (アドレスバーにフォーカス / 新しいタブ) でもあります。フォーカスがテキスト入力内にない限り、ブラウザがそれらをインターセプトする可能性があります。

### チャット入力欄

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `Enter` | チャットテキストエリア | メッセージを送信する |
| `Shift+Enter` | チャットテキストエリア | 改行を挿入する |
| `Shift+Tab` | チャットテキストエリア | 次の思考レベルに循環する (`off` → `minimal` → … → `xhigh` → `off`) |
| `Ctrl+I` / `Ctrl+L` | チャットテキストエリア | モデルセレクタポップアップを開く (入力で絞り込み、Enter で選択、フォーカスはテキストエリアに戻る) |

### エントリの表示切り替え

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `t` | フォーカスが input/textarea に**ない**とき | 思考の表示/非表示を切り替える |
| `o` | フォーカスが input/textarea に**ない**とき | ツールの表示/非表示を切り替える |
| `p` | フォーカスが input/textarea に**ない**とき | ツール出力の表示/非表示を切り替える |

### パレット、メニュー、シート

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `Escape` | ページレベル | 開いているパレット、メニュー、またはシートを閉じる |
| `⌘K` / `Ctrl+K` | ページレベル | セッションリストパレットを開く |
| `ArrowUp` / `ArrowDown` | セッションリストパレット | セッション結果を移動する |
| `Enter` | セッションリストパレット | 選択中 (または最初) のセッションを開く |
| `ArrowUp` / `ArrowDown` | モデルセレクタポップアップ | モデルリストを移動する |
| `Enter` | モデルセレクタポップアップ | ハイライトされたモデルを選択する |
| `ArrowUp` / `ArrowDown` | フォークモーダル | メッセージを移動する |
| `Enter` | フォークモーダル | ハイライトされたメッセージからフォークする |
| `Tab` | 全画面シート | シート内でフォーカスを循環させる |
| `Escape` | 全画面シート | シートを閉じる |
