# キーボードショートカット

## インデックスページ（`/`）

### ページスクロール（Vim スタイル）

同じ Vim スタイルのショートカットは、フォーカスが input、textarea、または contenteditable 要素に**ない**場合、すべてのページで機能します。

| ショートカット | 操作 |
|----------|--------|
| `j` | 300px 下にスクロール |
| `k` | 300px 上にスクロール |
| `g g` | ページの先頭にスクロール |
| `G`（Shift+G） | ページの末尾にスクロール |
| `Escape` | アクティブな入力をブラーして j/k ナビゲーションを有効にする |

### インデックスコマンド

| ショートカット | コンテキスト | 操作 |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | ページレベル | 検索/セッションパレットを開く |
| `⌘⇧L` / `Ctrl+Shift+L` | ページレベル | システムテーマを切り替え（ライト/ダーク） |
| `Escape` | ページレベル | パレット、メニュー、モーダルを閉じる |
| `Enter` | 新規セッションのパス入力 | 新規セッションを作成 |

> `⌘K` / `Ctrl+K` は Chrome の「アドレスバーにフォーカス」ショートカットでもあります。フォーカスがテキスト入力内にない場合、ブラウザがこれを横取りする可能性があります。

## セッション詳細ページ（`/session?id=...`）

### ページスクロール（Vim スタイル）

これらは、フォーカスが input、textarea、または contenteditable 要素に**ない**場合、インデックスページとセッションページの両方で機能します。

| ショートカット | 操作 |
|----------|--------|
| `j` | 300px 下にスクロール |
| `k` | 300px 上にスクロール |
| `g g` | ページの先頭にスクロール |
| `G`（Shift+G） | ページの末尾にスクロール |
| `I`（Shift+I） | チャット作成用テキストエリアにフォーカス |
| `Escape` | アクティブな入力をブラーして j/k ナビゲーションを有効にする |

### サイドバーとナビゲーション

| ショートカット | コンテキスト | 操作 |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | ページレベル | サイドバーの表示/非表示を切り替え |
| `⌘K` / `Ctrl+K` | ページレベル | セッション一覧パレットを開く |
| `⌘T` / `Ctrl+T` | ページレベル | 新規セッション |
| `⌘⇧L` / `Ctrl+Shift+L` | ページレベル | システムテーマを切り替え（ライト/ダーク） |
| `⌘⇧N` / `Ctrl+Shift+N` | ページレベル | スクラッチパッド / メモサイドバーを切り替え |

> `⌘K` と `⌘T` はブラウザのショートカット（アドレスバーにフォーカス / 新規タブ）でもあります。フォーカスがテキスト入力内にない場合、ブラウザがこれらを横取りする可能性があります。

### チャット作成

| ショートカット | コンテキスト | 操作 |
|----------|---------|--------|
| `Enter` | チャットテキストエリア | メッセージを送信 |
| `Shift+Enter` | チャットテキストエリア | 改行を挿入 |
| `Shift+Tab` | チャットテキストエリア | 次の思考レベルに切り替え（`off` → `minimal` → … → `xhigh` → `off`） |
| `Ctrl+I` / `Ctrl+L` | チャットテキストエリア | モデル選択ポップアップを開く（入力でフィルタ、Enter で選択、フォーカスはテキストエリアに戻る） |

### エントリ表示切替

| ショートカット | コンテキスト | 操作 |
|----------|---------|--------|
| `t` | フォーカスが input/textarea に**ない**場合 | 思考の表示/非表示を切り替え |
| `o` | フォーカスが input/textarea に**ない**場合 | ツールの表示/非表示を切り替え |
| `p` | フォーカスが input/textarea に**ない**場合 | ツール出力の表示/非表示を切り替え |

### パレット、メニュー、シート

| ショートカット | コンテキスト | 操作 |
|----------|---------|--------|
| `Escape` | ページレベル | 開いているパレット、メニュー、シートを閉じる |
| `⌘K` / `Ctrl+K` | ページレベル | セッション一覧パレットを開く |
| `ArrowUp` / `ArrowDown` | セッション一覧パレット | セッション結果を移動 |
| `Enter` | セッション一覧パレット | 選択中（または先頭）のセッションを開く |
| `ArrowUp` / `ArrowDown` | モデル選択ポップアップ | モデル一覧を移動 |
| `Enter` | モデル選択ポップアップ | ハイライトされたモデルを選択 |
| `ArrowUp` / `ArrowDown` | フォークモーダル | メッセージを移動 |
| `Enter` | フォークモーダル | ハイライトされたメッセージからフォーク |
| `Tab` | フルスクリーンシート | シート内でフォーカスを巡回 |
| `Escape` | フルスクリーンシート | シートを閉じる |
