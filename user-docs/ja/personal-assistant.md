# pi-web をパーソナルアシスタントとして使う

pi-web はコーディングだけのためではありません — 自分だけの OpenClaw や Hermes を持つように、あなたのコンピュータ上で動く **パーソナル AI アシスタント**に変えることができます。

## 仕組み

専用のフォルダを自分のマシン上に作成します — それがアシスタントの居場所です。その中に `APPEND_SYSTEM.md` ファイルを作成し、アシスタントが誰で、何を知っていて、どのように振る舞うかを定義します。pi-web は、どんなデバイスからでも会話できる美しいチャットインターフェースを提供します。

## ステップバイステップ

### 1. アシスタントフォルダを作成する

コンピュータ上のフォルダを選びます。例えば：

```
~/my-assistant/
```

### 2. アシスタントを定義する

そのフォルダ内に `APPEND_SYSTEM.md` ファイルを作成します。ここで pi にアシスタントが誰かを伝えます：

```markdown
# マイ・パーソナルアシスタント

あなたは Jarvis、私のパーソナル AI アシスタントです。以下のことを手伝ってください：

- 日々の計画とリマインダー
- リサーチと要約
- メールやメッセージの下書き
- アイデアのブレインストーミング
- 私が言及したことの記録

## 私について

- 私はリモート勤務のソフトウェアエンジニアです
- Pixel という名前の猫を飼っています
- 短く直接的な回答を好みます
- タイムゾーンは PST です

## ルール

- 簡潔に — 簡潔さを重視します
- 知らないことがあれば、知らないと言ってください
- 私が追跡を頼んだことについては積極的にリマインドしてください
```

pi はこれを毎回の会話のシステムプロンプトに自動的に追加するため、アシスタントは常にあなたが誰で、どのように手伝えばよいかを把握しています。

### 3. そのフォルダでセッションを開始する

pi-web で、`~/my-assistant/`（または付けた名前）を指定して新しいセッションを作成します。以上です — パーソナルアシスタントとの会話が始まります。

### 4. どこからでも使う

pi-web を PWA としてスマートフォン、タブレット、ノートパソコンにインストールします。アシスタントはいつでもそこにいます — 何でも、いつでも尋ねられます。

## アシスタントのアイデア

| 役割 | APPEND_SYSTEM.md に書くこと |
|---|---|
| 🧠 **ライフコーチ** | あなたの目標、取り組んでいる習慣、ジャーナリングのプロンプト |
| 🏠 **ホームマネージャー** | 買い物リストの形式、家族の好み、食事計画 |
| 💼 **仕事の相棒** | あなたの役割、現在のプロジェクト、会議メモの形式、会社のコンテキスト |
| 📚 **勉強パートナー** | 学んでいること、好みの説明スタイル、クイズモード |
| ✍️ **執筆アシスタント** | あなたの文体、トーンの好み、よく使う形式 |

## さらにコンテキストを追加する

pi がより役立つようになるものなら何でもアシスタントフォルダに入れられます：

- `notes/` — アシスタントが読める参照ファイル
- `context.md` — あなたの生活や仕事に関する背景情報
- `projects.md` — 現在のプロジェクトとその状況

pi はフォルダ内のファイルを読めるので、コンテキストを多く与えるほど、より良い結果が得られます。

---

> 💡 **ヒント:** シンプルに始めましょう。自分が誰で、アシスタントにどう振る舞ってほしいかを数行書くだけです。何が効果的かを学びながら、時間をかけて改善していきましょう。
