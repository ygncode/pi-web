# pi-web をあなたのパーソナルアシスタントに

pi-web はコーディング専用ではありません — あなたのコンピュータ上で動く **パーソナル AI アシスタント** に変えられます。まるで自分専用の OpenClaw や Hermes を持つようなものです。

## 仕組み

マシン上に専用フォルダを作成します — そこがアシスタントの住む場所です。その中に `APPEND_SYSTEM.md` ファイルを置き、アシスタントが誰なのか、何を知っているのか、どのように振る舞うのかを定義します。pi-web は美しいチャットインターフェースを提供し、どのデバイスからでもアシスタントと会話できます。

## ステップバイステップ

### 1. アシスタント用フォルダを作成する

コンピュータ上でフォルダを選びます。例えば：

```
~/my-assistant/
```

### 2. アシスタントを定義する

そのフォルダ内に `APPEND_SYSTEM.md` ファイルを作成します。ここで pi にあなたのアシスタントが誰なのかを伝えます：

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi はこれをすべての会話のシステムプロンプトに自動的に追加するので、アシスタントは常にあなたが誰で、どう助ければよいかを把握しています。

### 3. そのフォルダでセッションを開始する

pi-web で、`~/my-assistant/`（または付けた名前）を指す新しいセッションを作成します。それだけです — パーソナルアシスタントと会話できます。

### 4. どこからでも使う

スマートフォン、タブレット、ラップトップに pi-web を PWA としてインストールします。アシスタントはいつでもそこにいます — 何でも、いつでも質問できます。

## アシスタントのアイデア

| 役割 | APPEND_SYSTEM.md に書く内容 |
|---|---|
| 🧠 **ライフコーチ** | 目標、取り組んでいる習慣、ジャーナリングのプロンプト |
| 🏠 **ホームマネージャー** | 買い物リストの形式、家族の好み、食事の計画 |
| 💼 **仕事の相棒** | あなたの役割、現在のプロジェクト、会議メモの形式、会社のコンテキスト |
| 📚 **勉強のパートナー** | 学んでいること、好みの説明スタイル、クイズモード |
| ✍️ **ライティングアシスタント** | あなたの文体、トーンの好み、よく使う形式 |

## コンテキストをさらに追加する

アシスタントフォルダには、pi がより役立つためのものを何でも入れられます：

- `notes/` — アシスタントが読める参照ファイル
- `context.md` — あなたの生活や仕事に関する背景情報
- `projects.md` — 現在のプロジェクトとその状況

pi はフォルダ内のファイルを読めるので、与えるコンテキストが多ければ多いほど、より良くなります。

## pi-web に作業を依頼する

`pi install npm:@ygncode/pi-web@beta` の後、セッションは pi-web 自体と会話できます。
試してみてください：

- 「シンガポール時間の午前2時に受信トレイを要約するスケジュールを追加して」
- 「pi-web のスケジュールを一覧表示して」
- 「受信トレイのスケジュールを一時停止して」
- 「これをノートに書き留めて」
- 「pi-web をダークモードに切り替えて / 自動タイトルをオフにして」

同梱の **/skill:pi-web-schedule** スキルが、これを実際の pi-web のスケジュール
（`/schedules` で編集するものと同じ）に変換します。各実行は **新しい** セッションを
開始するので、指示は単独で成立する必要があります — 「~/inbox の未読メールを
要約して」は機能しますが、「前回の続きをやって」は機能しません。

スケジュールは pi-web の実行中のみ動作します。

> 💡 **ヒント:** シンプルに始めましょう。自分が誰で、アシスタントにどう振る舞ってほしいかを数行書くだけで十分です。何がうまくいくかを学びながら、時間をかけて改善していきましょう。
