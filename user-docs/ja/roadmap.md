# ロードマップ

pi-web は 2 つの対象読者のために作られています。

- **開発者向け** — ターミナルで生活しながらも、モバイルからセッションを続けたい、リモートサーバーに引き継ぎたい、長時間実行中のタスクをどこからでも見守りたい人。
- **非開発者向け** — ただ美しい AI アプリが動けばいいという人。開いて、入力して、ノリで使う。ターミナルなし、SSH なし、混乱なし。最も使いやすい AI ツールのように、でもモデルの選択肢とオープンソースの自由付き。

これから登場するものを紹介します。

---

## 現在（リリース済み）

[機能表](README.md#what-you-can-do-with-pi-web)に記載されているすべてが、今日すでに利用可能です。

かつてこのロードマップに載っていて、その後リリースされた機能:

| 機能 | 内容 |
|---|---|
| **ステアリング / キュー** ([#46](https://github.com/ygncode/pi-web/issues/46)) | pi の実行中に追加の指示を送ったり、次のターン用のメッセージをキューに入れたりします。 |
| **スケジューラー** ([#44](https://github.com/ygncode/pi-web/issues/44)) | `/schedules` ページから、プロンプトを自動実行するようスケジュールします — 毎日のスタンドアップ、朝のサマリー、繰り返しのタスクなど。 |
| **表示デフォルトの設定** ([#48](https://github.com/ygncode/pi-web/issues/48)) | すべてのセッションで、思考・ツール・ツール出力の表示/非表示の好みを設定します。 |
| **Git diff** ([#47](https://github.com/ygncode/pi-web/issues/47) の一部) | セッションの diff モーダルで、未コミットのワーキングツリーの変更をレビューコメント付きで確認します。 |

## ビジョン

長期的な目標: pi-web が **pi のためのインターフェース** になること — すべての人のために。

- **非開発者**は他のアプリと同じように開きます。モデルを選び、入力し、完了。コマンドラインは一切不要です。
- **開発者**は深い統合を得られます — リモートへの引き継ぎ、複数セッションのダッシュボード、Git を意識したブラウジング、メッセージングボット。
- **すべての人**がモデルの自由、オープンソースの透明性、そしてあらゆる場面で思慮深く感じられる UI を手に入れます。
