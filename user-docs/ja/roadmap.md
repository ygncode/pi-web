# ロードマップ

pi-webは2つのユーザー層に向けて作られています：

- **開発者向け** — ターミナルで作業しながらも、モバイルからセッションを継続したり、リモートサーバーに引き継いだり、長時間実行中のタスクをどこからでも監視したい人向け。
- **非開発者向け** — ただ動作する美しいAIアプリを求めている人向け。開いて、入力して、あとはお任せ。ターミナルもSSHも混乱も不要。最も使いやすいAIツールのように、しかしモデル選択の自由とオープンソースの透明性を備えて。

これから予定している内容です。

## ビジョン

長期的な目標：pi-webは**すべての人のためのpiのインターフェース**になることです。

- **非開発者**は他のアプリと同じように開くだけ。モデルを選び、入力し、完了。コマンドラインは一切不要。
- **開発者**は深い統合を得られます — リモート引き継ぎ、マルチセッションダッシュボード、Git対応ブラウジング、メッセージングボット。
- **すべての人**がモデルの自由、オープンソースの透明性、そしてあらゆる場面で考え抜かれたUIを手に入れられます。
