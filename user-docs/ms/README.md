**Terfikir untuk mencuba pi-web? Teruskan sahaja — anda pasti akan jatuh cinta.**

pi-web ialah UI web dan PWA yang cantik untuk [pi](https://pi.dev) — ejen pengekodan AI sumber terbuka. Ia membolehkan anda melayari, membaca dan menyambung semula sesi pi anda dari mana-mana pelayar, pada mana-mana peranti, dengan ciri-ciri yang difikirkan dengan teliti di setiap penjuru.

**pi-web dibina untuk dua jenis pengguna:**

- 🧑‍💻 **Untuk pembangun** — yang tinggal dalam terminal tetapi mahu menyambung sesi dari telefon bimbit, menyerahkannya kepada pelayan jauh, atau memantau tugasan yang berjalan lama dari mana-mana sahaja.
- ✨ **Untuk bukan pembangun** — yang hanya mahukan aplikasi AI yang cantik dan berfungsi. Buka, taip, nikmati. Tiada terminal, tiada SSH, tiada kekeliruan. Seperti alat AI yang paling mesra pengguna, tetapi dengan pilihan model dan kebebasan sumber terbuka.

---

## Mengapa pi-web?

Anda sudah pun larut dalam aliran kerja dengan pi di terminal anda. pi-web mengekalkan momentum itu apabila anda meninggalkan meja anda:

- **Sambung dari mana-mana** — sambung sesi dari telefon, tablet atau komputer lain anda. Tiada SSH, tiada Termius — hanya buka pelayar anda.
- **Papan pemuka berbilang sesi** — mulakan kerja dalam satu sesi sambil menonton sesi lain distrim. Cari merentas projek, tapis mengikut cawangan, cari apa yang anda perlukan dengan pantas.
- **Asas sumber terbuka** — pi adalah sumber terbuka sepenuhnya dan agnostik pembekal. Anda tidak terkunci kepada satu model atau vendor. pi-web juga sumber terbuka.
- **Akses jauh yang selamat** — pengesahan token terbina dalam supaya anda boleh mendedahkannya pada LAN atau Tailscale anda tanpa bimbang.
- **Kongsi kerja anda** — eksport sesi sebagai syot kilat statik atau Gist GitHub rahsia dalam satu klik.

## pi-web sebagai ruang kerja AI peribadi anda 🏠

pi-web ialah sebuah PWA (Progressive Web App), jadi anda boleh **memasangnya seperti aplikasi asli** pada desktop, komputer riba, telefon atau tablet anda — tanpa perlu kedai aplikasi. Pada desktop, ia dibuka dalam tetingkap sendiri tanpa chrome pelayar, jadi ia kelihatan dan terasa seperti aplikasi desktop yang sebenar.

Anggapkan ia sebagai **Claude Cowork anda sendiri** — ruang kerja AI peribadi yang berada pada mesin anda — cuma ia sumber terbuka dan agnostik model:

- **Anda memiliki keseluruhan susunan.** Pilih mana-mana model, tukar bila-bila masa anda suka. Jalankan model tempatan dan data anda tidak akan meninggalkan mesin anda.
- **Orang bukan teknikal boleh menggunakannya.** Sediakan pi-web pada mesin mereka, tunjukkan cara menggunakannya sekali, dan mereka boleh terus menggunakannya. Ibu bapa anda, pasangan anda, rakan-rakan bukan teknikal anda — tiada terminal, tiada SSH, hanya antara muka sembang yang biasa.
- **Satu persediaan, ramai pengguna.** Pasang pada desktop anda dan kongsi skrin anda, atau dedahkan pada rangkaian rumah anda dan biarkan ahli keluarga membukanya pada peranti mereka sendiri.

Mahukan lebih daripada pengekodan? Jadikannya [pembantu peribadi](personal-assistant.md) khusus yang mengenali siapa anda dan tinggal pada mesin anda — seperti OpenClaw atau Hermes anda sendiri.

> 💡 **Petua pro:** Pasang pi-web sebagai PWA daripada Chrome/Edge (klik ikon pasang dalam bar alamat) atau Safari (Kongsi → Tambah ke Dock). Ia menjadi tidak dapat dibezakan daripada aplikasi asli.

## Apa yang anda boleh lakukan dengan pi-web

| | |
|---|---|
| 📱 **PWA** | Pasang pi-web sebagai Progressive Web App pada desktop, telefon atau tablet untuk rasa aplikasi asli. |
| 🔄 **Sambung sesi** | Sambung mana-mana perbualan tepat di tempat anda berhenti — teks, imej, pertukaran model, semuanya dari pelayar. |
| 🆕 **Mulakan sesi baharu** | Cipta sesi baharu untuk mana-mana laluan projek, terus dari UI web. |
| 📡 **Penstriman langsung** | Tonton respons pi distrim dalam masa nyata dengan kependaman ~ms. Mod ikut memastikan anda kekal pada yang terkini. |
| 🌲 **Paparan pokok** | Navigasi pokok mesej asli pi — lihat struktur perbualan penuh, lompat ke mana-mana cawangan, dan fork dari mana-mana titik. |
| 🔀 **Fork sesi** | Fork sesi dari mana-mana mesej atau bahkan panggilan alat tertentu — teroka arah yang berbeza tanpa kehilangan tempat anda. |
| 🔍 **Layari & cari** | Tapis sesi merentas projek, cari mengikut nama, navigasi cawangan — keseluruhan sejarah sesi anda sepintas lalu. |
| 🌿 **Integrasi Git** | Lihat cawangan semasa dan buka PR GitHub terus daripada pemapar sesi. |
| 📝 **Pad conteng** | Catat nota, senarai tugasan atau fikiran pantas di samping sesi anda tanpa menukar aplikasi. |
| 💬 **Anotasi** | Serlahkan dan ulas mana-mana bahagian sesi — bagus untuk semakan kod, maklum balas atau menanda detik penting. |
| 🎨 **Tema & penyesuaian** | Tukar antara mod gelap dan terang, laraskan UI mengikut citarasa anda — jadikan pi-web terasa seperti *milik anda*. |
| 🌐 **Berbilang bahasa** | 14 bahasa terbina dalam (English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ဗာဟာခ្មែរ, ລາວ). Tambah bahasa tersuai anda sendiri daripada Tetapan. |
| 🐱 **Kesejahteraan & pomodoro** | Terlalu banyak *vibe coding* tidak sihat. Pemasa pomodoro terbina dalam dengan teman kucing dan peringatan tidur untuk memastikan anda seimbang. |
| 📤 **Kongsi & eksport** | Muat turun JSONL, eksport syot kilat statik yang dipaparkan dengan rupa asli `pi.dev` pi, atau kongsi sebagai Gist GitHub peribadi — semuanya dipaparkan di sisi klien. |
| 🔔 **Bunyi pemberitahuan** | Bunyi loceng pemberitahuan yang boleh disesuaikan untuk acara sesi — kekal dalam pengetahuan walaupun pi-web berada dalam tab lain. |
| ⌨️ **Pintasan papan kekunci** | Navigasi gaya Vim, tindakan pantas — [rujukan penuh →](keyboard-shortcuts.md) |
| 🤖 **Pembantu peribadi** | Jadikan pi-web pembantu AI anda sendiri yang tinggal pada komputer anda — seperti OpenClaw atau Hermes. [Sediakannya →](personal-assistant.md) |
| 🗓️ **Bercakap dengan jadual** | Daripada sesi pi, sebut "tambah jadual pada pukul 2 pagi waktu Singapura ke …" — `/skill:pi-web-schedule`. |
| 📝 **Bercakap dengan nota & tetapan** | "Tulis ini dalam nota" (`/skill:pi-web-notes`) atau "tukar ke mod gelap" (`/skill:pi-web-settings`). |
