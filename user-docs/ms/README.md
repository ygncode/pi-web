**Berfikir untuk mencuba pi-web? Teruskan — anda akan jatuh cinta.**

pi-web ialah UI web dan PWA yang cantik untuk [pi](https://pi.dev) — ejen pengekodan AI sumber terbuka. Ia membolehkan anda melayari, membaca, dan menyambung sesi pi anda dari mana-mana pelayar, pada mana-mana peranti, dengan ciri-ciri yang teliti di setiap langkah.

**pi-web dibina untuk dua jenis orang:**

- 🧑‍💻 **Untuk pembangun** — yang hidup dalam terminal tetapi mahu menyambung sesi dari mudah alih, serahkan ke pelayan jauh, atau memantau tugasan yang berjalan lama dari mana-mana sahaja.
- ✨ **Untuk bukan pembangun** — yang hanya mahukan aplikasi AI yang cantik dan berfungsi. Buka, taip, nikmati. Tiada terminal, tiada SSH, tiada kekeliruan. Seperti alat AI paling mesra pengguna, tetapi dengan pilihan model dan kebebasan sumber terbuka.

---

## Mengapa pi-web?

Anda sudah pun dalam aliran mendalam dengan pi di terminal anda. pi-web mengekalkan momentum itu apabila anda melangkah jauh dari meja anda:

- **Sambung dari mana-mana** — teruskan sesi dari telefon, tablet, atau komputer lain anda. Tiada SSH, tiada Termius — hanya buka pelayar anda.
- **Papan pemuka pelbagai sesi** — mulakan kerja dalam satu sesi sambil menonton aliran lain. Cari merentas projek, tapis mengikut cawangan, cari apa yang anda perlukan dengan pantas.
- **Asas sumber terbuka** — pi adalah sumber terbuka sepenuhnya dan agnostik pembekal. Anda tidak terikat dengan satu model atau vendor. pi-web juga sumber terbuka.
- **Akses jauh yang selamat** — pengesahan token terbina supaya anda boleh mendedahkannya di LAN atau Tailscale anda tanpa bimbang.
- **Kongsi kerja anda** — eksport sesi sebagai syot kilat statik atau Gist GitHub rahsia dalam satu klik.

## pi-web sebagai ruang kerja AI peribadi anda 🏠

pi-web ialah PWA (Progressive Web App), jadi anda boleh **memasangnya seperti aplikasi asli** pada desktop, komputer riba, telefon, atau tablet anda — tiada kedai aplikasi diperlukan. Pada desktop ia dibuka dalam tetingkap sendiri tanpa chrome pelayar, jadi ia kelihatan dan terasa seperti aplikasi desktop sebenar.

Anggaplah ia sebagai **Claude Cowork anda sendiri** — ruang kerja AI peribadi yang tinggal di mesin anda — kecuali ia sumber terbuka dan agnostik model:

- **Anda memiliki susunannya.** Pilih mana-mana model, tukar bila-bila masa anda suka. Jalankan yang tempatan dan data anda tidak pernah meninggalkan mesin anda.
- **Orang bukan teknikal boleh menggunakannya.** Sediakan pi-web pada mesin mereka, tunjukkan cara menggunakannya sekali, dan mereka sedia untuk pergi. Ibu bapa anda, pasangan anda, rakan bukan teknikal anda — tiada terminal, tiada SSH, hanya antara muka sembang yang biasa.
- **Satu persediaan, ramai pengguna.** Pasang pada desktop anda dan kongsi skrin anda, atau dedahkan pada rangkaian rumah anda dan biarkan ahli keluarga membukanya pada peranti mereka sendiri.

Mahukan lebih daripada pengekodan? Jadikannya sebagai [pembantu peribadi](personal-assistant.md) khusus yang mengenali siapa anda dan tinggal di mesin anda — seperti OpenClaw atau Hermes anda sendiri.

> 💡 **Petua pro:** Pasang pi-web sebagai PWA dari Chrome/Edge (klik ikon pasang dalam bar alamat) atau Safari (Kongsi → Tambah ke Dock). Ia menjadi tidak dapat dibezakan daripada aplikasi asli.

## Apa yang anda boleh lakukan dengan pi-web

| | |
|---|---|
| 📱 **PWA** | Pasang pi-web sebagai Progressive Web App pada desktop, telefon, atau tablet untuk rasa asli. |
| 🔄 **Sambung sesi** | Sambung semula sebarang perbualan tepat di mana anda berhenti — teks, imej, penukaran model, semuanya dari pelayar. |
| 🆕 **Mulakan sesi baru** | Cipta sesi baharu terhadap mana-mana laluan projek, terus dari UI web. |
| 📡 **Penstriman langsung** | Tonton respons pi distrim dalam masa nyata dengan kependaman ~ms. Mod ikut mengekalkan anda terkunci pada yang terkini. |
| 🌲 **Paparan pohon** | Navigasi pohon mesej asli pi — lihat struktur perbualan penuh, lompat ke mana-mana cawangan, dan cabang dari mana-mana titik. |
| 🔀 **Cabang sesi** | Cabang sesi dari mana-mana mesej atau panggilan alat tertentu — teroka arah berbeza tanpa kehilangan tempat anda. |
| 🔍 **Layar & cari** | Tapis sesi merentas projek, cari mengikut nama, navigasi cawangan — sejarah sesi penuh anda sepintas lalu. |
| 🌿 **Integrasi Git** | Lihat cawangan semasa dan buka PR GitHub terus dari penonton sesi. |
| 📝 **Buku contengan** | Catat nota, senarai tugasan, atau fikiran pantas bersama sesi anda tanpa menukar aplikasi. |
| 💬 **Anotasi** | Serlahkan dan komen pada mana-mana bahagian sesi — bagus untuk semakan kod, maklum balas, atau menandakan detik penting. |
| 🎨 **Tema & penyesuaian** | Tukar antara mod gelap dan cerah, ubah suai UI mengikut citarasa anda — jadikan pi-web terasa seperti *milik anda*. |
| 🌐 **Pelbagai bahasa** | 14 bahasa terbina (English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ဗាសាខ្មែរ, ລາວ). Tambah bahasa tersuai anda sendiri dari Tetapan. |
| 🐱 **Kesejahteraan & pomodoro** | Pengekodan vibe yang terlalu banyak tidak sihat. Pemasa pomodoro terbina dengan teman kucing dan peringatan tidur untuk mengekalkan keseimbangan anda. |
| 📤 **Kongsi & eksport** | Muat turun JSONL, eksport syot kilat statik yang dipaparkan dengan rupa `pi.dev` asli pi, atau kongsi sebagai Gist GitHub peribadi — semuanya dipaparkan di sisi klien. |
| 🔔 **Bunyi pemberitahuan** | Bunyi loceng pemberitahuan yang boleh disesuaikan untuk acara sesi — kekal dalam gelung walaupun pi-web berada di tab lain. |
| ⌨️ **Pintasan papan kekunci** | Navigasi gaya Vim, tindakan pantas — [rujukan penuh →](keyboard-shortcuts.md) |
| 🤖 **Pembantu peribadi** | Jadikan pi-web sebagai pembantu AI anda sendiri yang tinggal di komputer anda — seperti OpenClaw atau Hermes. [Sediakannya →](personal-assistant.md) |
