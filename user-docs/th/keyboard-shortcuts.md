# ปุ่มลัด

## หน้าดัชนี (`/`)

### การเลื่อนหน้า (แบบ vim)

ปุ่มลัดแบบ vim ใช้ได้กับทุกหน้าเมื่อโฟกัส**ไม่ได้**อยู่ใน input, textarea หรือ element แบบ contenteditable

| ปุ่มลัด | การทำงาน |
|----------|--------|
| `j` | เลื่อนลง 300px |
| `k` | เลื่อนขึ้น 300px |
| `g g` | เลื่อนไปด้านบนสุดของหน้า |
| `G` (Shift+G) | เลื่อนไปด้านล่างสุดของหน้า |
| `Escape` | ยกเลิกโฟกัส input ที่ทำงานอยู่เพื่อให้การนำทางด้วย j/k ทำงานได้ |

### คำสั่งในหน้าดัชนี

| ปุ่มลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | ระดับหน้า | เปิดชุดคำสั่งค้นหา/เซสชัน |
| `⌘⇧L` / `Ctrl+Shift+L` | ระดับหน้า | สลับธีมระบบ (สว่าง/มืด) |
| `Escape` | ระดับหน้า | ปิดชุดคำสั่ง เมนู หรือโมดัล |
| `Enter` | ช่องป้อนพาธเซสชันใหม่ | สร้างเซสชันใหม่ |

> `⌘K` / `Ctrl+K` ยังเป็นปุ่มลัด "โฟกัสแถบที่อยู่" ของ Chrome ด้วย เบราว์เซอร์อาจดักจับปุ่มนี้เว้นแต่โฟกัสจะอยู่ในช่องข้อความ

## หน้ารายละเอียดเซสชัน (`/session?id=...`)

### การเลื่อนหน้า (แบบ vim)

ปุ่มเหล่านี้ใช้ได้ทั้งในหน้าดัชนีและหน้าเซสชันเมื่อโฟกัส**ไม่ได้**อยู่ใน input, textarea หรือ element แบบ contenteditable

| ปุ่มลัด | การทำงาน |
|----------|--------|
| `j` | เลื่อนลง 300px |
| `k` | เลื่อนขึ้น 300px |
| `g g` | เลื่อนไปด้านบนสุดของหน้า |
| `G` (Shift+G) | เลื่อนไปด้านล่างสุดของหน้า |
| `I` (Shift+I) | โฟกัสที่ textarea สำหรับเขียนแชท |
| `Escape` | ยกเลิกโฟกัส input ที่ทำงานอยู่เพื่อให้การนำทางด้วย j/k ทำงานได้ |

### แถบข้างและการนำทาง

| ปุ่มลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | ระดับหน้า | สลับการแสดงแถบข้าง |
| `⌘K` / `Ctrl+K` | ระดับหน้า | เปิดชุดคำสั่งรายการเซสชัน |
| `⌘T` / `Ctrl+T` | ระดับหน้า | เซสชันใหม่ |
| `⌘⇧L` / `Ctrl+Shift+L` | ระดับหน้า | สลับธีมระบบ (สว่าง/มืด) |
| `⌘⇧N` / `Ctrl+Shift+N` | ระดับหน้า | สลับแถบข้างบันทึกย่อ / โน้ต |

> `⌘K` และ `⌘T` ยังเป็นปุ่มลัดของเบราว์เซอร์ (โฟกัสแถบที่อยู่ / แท็บใหม่) เบราว์เซอร์อาจดักจับปุ่มเหล่านี้เว้นแต่โฟกัสจะอยู่ในช่องข้อความ

### ส่วนเขียนแชท

| ปุ่มลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `Enter` | textarea แชท | ส่งข้อความ |
| `Shift+Enter` | textarea แชท | ขึ้นบรรทัดใหม่ |
| `Shift+Tab` | textarea แชท | วนไปยังระดับการคิดถัดไป (`off` → `minimal` → … → `xhigh` → `off`) |
| `Ctrl+I` / `Ctrl+L` | textarea แชท | เปิดป๊อปอัปเลือกโมเดล (พิมพ์เพื่อกรอง Enter เพื่อเลือก โฟกัสกลับไปที่ textarea) |

### การสลับการแสดงรายการ

| ปุ่มลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `t` | เมื่อโฟกัส**ไม่ได้**อยู่ใน input/textarea | สลับการแสดงการคิด |
| `o` | เมื่อโฟกัส**ไม่ได้**อยู่ใน input/textarea | สลับการแสดงเครื่องมือ |
| `p` | เมื่อโฟกัส**ไม่ได้**อยู่ใน input/textarea | สลับการแสดงผลลัพธ์ของเครื่องมือ |

### ชุดคำสั่ง เมนู และแผง

| ปุ่มลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `Escape` | ระดับหน้า | ปิดชุดคำสั่ง เมนู หรือแผงที่เปิดอยู่ |
| `⌘K` / `Ctrl+K` | ระดับหน้า | เปิดชุดคำสั่งรายการเซสชัน |
| `ArrowUp` / `ArrowDown` | ชุดคำสั่งรายการเซสชัน | นำทางผลลัพธ์เซสชัน |
| `Enter` | ชุดคำสั่งรายการเซสชัน | เปิดเซสชันที่เลือก (หรือเซสชันแรก) |
| `ArrowUp` / `ArrowDown` | ป๊อปอัปเลือกโมเดล | นำทางรายการโมเดล |
| `Enter` | ป๊อปอัปเลือกโมเดล | เลือกโมเดลที่ไฮไลท์ |
| `ArrowUp` / `ArrowDown` | โมดัลแยก | นำทางข้อความ |
| `Enter` | โมดัลแยก | แยกจากข้อความที่ไฮไลท์ |
| `Tab` | แผงเต็มหน้าจอ | วนโฟกัสภายในแผง |
| `Escape` | แผงเต็มหน้าจอ | ปิดแผง |
