# แป้นพิมพ์ลัด

## หน้าดัชนี (`/`)

### การเลื่อนหน้า (สไตล์ vim)

แป้นพิมพ์ลัดสไตล์ vim ชุดเดียวกันนี้ใช้ได้กับทุกหน้า เมื่อโฟกัส**ไม่ได้**อยู่ในช่อง input, textarea หรือ element แบบ contenteditable

| แป้นพิมพ์ลัด | การทำงาน |
|----------|--------|
| `j` | เลื่อนลง 300px |
| `k` | เลื่อนขึ้น 300px |
| `g g` | เลื่อนไปด้านบนสุดของหน้า |
| `G` (Shift+G) | เลื่อนไปด้านล่างสุดของหน้า |
| `Escape` | ปลดโฟกัสช่อง input ที่กำลังใช้งานอยู่ เพื่อให้การนำทางด้วย j/k ทำงานได้ |

### คำสั่งของหน้าดัชนี

| แป้นพิมพ์ลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | ระดับหน้า | เปิดพาเล็ตค้นหา/เซสชัน |
| `⌘,` / `Ctrl+,` | ระดับหน้า | เปิดการตั้งค่า |
| `⌘⇧L` / `Ctrl+Shift+L` | ระดับหน้า | สลับธีมของระบบ (สว่าง/มืด) |
| `Escape` | ระดับหน้า | ปิดพาเล็ต เมนู หรือโมดัล |
| `Enter` | ช่องป้อนพาธของเซสชันใหม่ | สร้างเซสชันใหม่ |

> `⌘K` / `Ctrl+K` ยังเป็นแป้นพิมพ์ลัด "โฟกัสแถบที่อยู่" ของ Chrome ด้วย เบราว์เซอร์อาจดักจับมันไว้ เว้นแต่โฟกัสจะอยู่ในช่องป้อนข้อความ

## หน้ารายละเอียดเซสชัน (`/session?id=...`)

### การเลื่อนหน้า (สไตล์ vim)

แป้นพิมพ์ลัดเหล่านี้ใช้ได้ทั้งหน้าดัชนีและหน้าเซสชัน เมื่อโฟกัส**ไม่ได้**อยู่ในช่อง input, textarea หรือ element แบบ contenteditable

| แป้นพิมพ์ลัด | การทำงาน |
|----------|--------|
| `j` | เลื่อนลง 300px |
| `k` | เลื่อนขึ้น 300px |
| `g g` | เลื่อนไปด้านบนสุดของหน้า |
| `G` (Shift+G) | เลื่อนไปด้านล่างสุดของหน้า |
| `I` (Shift+I) | โฟกัสที่ textarea ของช่องเขียนแชท |
| `Escape` | ปลดโฟกัสช่อง input ที่กำลังใช้งานอยู่ เพื่อให้การนำทางด้วย j/k ทำงานได้ |

### แถบข้างและการนำทาง

| แป้นพิมพ์ลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | ระดับหน้า | สลับการแสดงแถบข้าง |
| `⌘K` / `Ctrl+K` | ระดับหน้า | เปิดพาเล็ตรายการเซสชัน |
| `⌘T` / `Ctrl+T` | ระดับหน้า | เซสชันใหม่ |
| `⌘/` / `Ctrl+/` | ระดับหน้า | แสดงโมดัลแป้นพิมพ์ลัด |
| `⌘,` / `Ctrl+,` | ระดับหน้า | เปิดการตั้งค่า |
| `⌘⇧L` / `Ctrl+Shift+L` | ระดับหน้า | สลับธีมของระบบ (สว่าง/มืด) |
| `⌘⇧N` / `Ctrl+Shift+N` | ระดับหน้า | สลับแถบข้าง scratchpad / บันทึกย่อ |

> `⌘K` และ `⌘T` ยังเป็นแป้นพิมพ์ลัดของเบราว์เซอร์ด้วย (โฟกัสแถบที่อยู่ / แท็บใหม่) เบราว์เซอร์อาจดักจับมันไว้ เว้นแต่โฟกัสจะอยู่ในช่องป้อนข้อความ

### ช่องเขียนแชท

| แป้นพิมพ์ลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `Enter` | textarea แชท | ส่งข้อความ |
| `Shift+Enter` | textarea แชท | ขึ้นบรรทัดใหม่ |
| `Shift+Tab` | textarea แชท | วนไปยังระดับ thinking ถัดไป (`off` → `minimal` → … → `xhigh` → `off`) |
| `Ctrl+I` / `Ctrl+L` | textarea แชท | เปิดป๊อปอัปเลือกโมเดล (พิมพ์เพื่อกรอง, Enter เพื่อเลือก, โฟกัสกลับไปที่ textarea) |

### การสลับการมองเห็นของรายการ

| แป้นพิมพ์ลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `t` | เมื่อโฟกัส**ไม่ได้**อยู่ใน input/textarea | สลับการแสดง thinking |
| `o` | เมื่อโฟกัส**ไม่ได้**อยู่ใน input/textarea | สลับการแสดงเครื่องมือ |
| `p` | เมื่อโฟกัส**ไม่ได้**อยู่ใน input/textarea | สลับการแสดงผลลัพธ์ของเครื่องมือ |

### พาเล็ต เมนู และชีต

| แป้นพิมพ์ลัด | บริบท | การทำงาน |
|----------|---------|--------|
| `Escape` | ระดับหน้า | ปิดพาเล็ต เมนู หรือชีตที่เปิดอยู่ |
| `⌘K` / `Ctrl+K` | ระดับหน้า | เปิดพาเล็ตรายการเซสชัน |
| `ArrowUp` / `ArrowDown` | พาเล็ตรายการเซสชัน | นำทางผลลัพธ์เซสชัน |
| `Enter` | พาเล็ตรายการเซสชัน | เปิดเซสชันที่เลือก (หรือรายการแรก) |
| `ArrowUp` / `ArrowDown` | ป๊อปอัปเลือกโมเดล | นำทางรายการโมเดล |
| `Enter` | ป๊อปอัปเลือกโมเดล | เลือกโมเดลที่ไฮไลต์ |
| `ArrowUp` / `ArrowDown` | โมดัล Fork | นำทางข้อความ |
| `Enter` | โมดัล Fork | Fork จากข้อความที่ไฮไลต์ |
| `Tab` | ชีตแบบเต็มจอ | วนโฟกัสภายในชีต |
| `Escape` | ชีตแบบเต็มจอ | ปิดชีต |
