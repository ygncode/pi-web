# แผนงาน

pi-web ถูกสร้างขึ้นมาสำหรับผู้ใช้สองกลุ่ม:

- **สำหรับนักพัฒนา** — ผู้ที่ใช้ชีวิตอยู่ในเทอร์มินัลแต่ต้องการสนทนาต่อจากมือถือ ส่งต่องานไปยังเซิร์ฟเวอร์ระยะไกล หรือคอยติดตามงานที่ใช้เวลานานจากที่ไหนก็ได้
- **สำหรับผู้ที่ไม่ใช่นักพัฒนา** — ผู้ที่แค่อยากได้แอป AI ที่สวยงามและใช้งานได้จริง เปิดขึ้นมา พิมพ์ แล้วก็ได้เลย ไม่มีเทอร์มินัล ไม่มี SSH ไม่สับสน เหมือนเครื่องมือ AI ที่เป็นมิตรกับผู้ใช้ที่สุด แต่มาพร้อมตัวเลือกโมเดลและอิสระแบบโอเพนซอร์ส

นี่คือสิ่งที่จะตามมา

## ตอนนี้ (เปิดตัวแล้ว)

ทุกอย่างที่ระบุไว้ใน [ตารางฟีเจอร์](README.md#what-you-can-do-with-pi-web) พร้อมใช้งานแล้ววันนี้

ฟีเจอร์ที่เคยอยู่ในแผนงานนี้และได้เปิดตัวไปแล้ว:

| ฟีเจอร์ | รายละเอียด |
|---|---|
| **การควบคุม / คิว** ([#46](https://github.com/ygncode/pi-web/issues/46)) | ส่งคำสั่งติดตามผลระหว่างที่ pi ยังทำงานอยู่ หรือจัดคิวข้อความสำหรับเทิร์นถัดไป |
| **ตัวกำหนดเวลา** ([#44](https://github.com/ygncode/pi-web/issues/44)) | กำหนดเวลาให้พรอมป์ทำงานอัตโนมัติ — การประชุมสั้นประจำวัน สรุปตอนเช้า งานที่ทำซ้ำ — จากหน้า `/schedules` |
| **ค่าเริ่มต้นการแสดงผลที่ปรับแต่งได้** ([#48](https://github.com/ygncode/pi-web/issues/48)) | ตั้งค่าการแสดงผลที่ต้องการสำหรับการคิด เครื่องมือ และผลลัพธ์ของเครื่องมือ ในทุกเซสชัน |
| **Git diff** (ส่วนหนึ่งของ [#47](https://github.com/ygncode/pi-web/issues/47)) | ดูการเปลี่ยนแปลงของ working tree ที่ยังไม่ได้คอมมิตในหน้าต่าง diff ของเซสชัน พร้อมคอมเมนต์รีวิว |

## วิสัยทัศน์

เป้าหมายระยะยาว: pi-web ควรเป็น **อินเทอร์เฟซสำหรับ pi** — สำหรับทุกคน

- **ผู้ที่ไม่ใช่นักพัฒนา** เปิดมันเหมือนแอปอื่นทั่วไป เลือกโมเดล พิมพ์ เสร็จ ไม่ต้องแตะ command line เลย
- **นักพัฒนา** ได้การผสานรวมเชิงลึก — การส่งต่องานระยะไกล แดชบอร์ดหลายเซสชัน การเรียกดูแบบ git-aware บอตส่งข้อความ
- **ทุกคน** ได้อิสระในการเลือกโมเดล ความโปร่งใสแบบโอเพนซอร์ส และ UI ที่ใส่ใจในทุกรายละเอียด
