**กำลังคิดจะลองใช้ pi-web อยู่เหรอ? ลองเลย — คุณจะหลงรักมัน**

pi-web เป็นเว็บ UI และ PWA ที่สวยงามสำหรับ [pi](https://pi.dev) — เอเจนต์เขียนโค้ด AI แบบโอเพนซอร์ส ช่วยให้คุณเรียกดู อ่าน และต่อเซสชัน pi ของคุณจากเบราว์เซอร์ใดก็ได้ บนอุปกรณ์ใดก็ได้ พร้อมฟีเจอร์ที่ใส่ใจในทุกรายละเอียด

**pi-web ถูกสร้างมาเพื่อคนสองประเภท:**

- 🧑‍💻 **สำหรับนักพัฒนา** — คนที่ใช้ชีวิตในเทอร์มินัลแต่อยากต่อเซสชันจากมือถือ ส่งต่องานให้เซิร์ฟเวอร์ระยะไกล หรือเฝ้าดูงานที่รันนานจากที่ไหนก็ได้
- ✨ **สำหรับคนทั่วไป (ที่ไม่ใช่นักพัฒนา)** — คนที่แค่อยากได้แอป AI สวย ๆ ที่ใช้งานได้จริง เปิดขึ้นมา พิมพ์ แล้วลื่นไหลไปเลย ไม่มีเทอร์มินัล ไม่มี SSH ไม่ต้องงง เหมือนเครื่องมือ AI ที่เป็นมิตรกับผู้ใช้ที่สุด แต่มีอิสระในการเลือกโมเดลและความเป็นโอเพนซอร์ส

## ทำไมต้อง pi-web?

คุณกำลังอินกับโฟลว์การทำงานกับ pi ในเทอร์มินัลอยู่แล้ว pi-web ช่วยให้โมเมนตัมนั้นต่อเนื่องแม้เมื่อคุณลุกออกจากโต๊ะ:

- **กลับมาทำต่อจากที่ไหนก็ได้** — ต่อเซสชันจากโทรศัพท์ แท็บเล็ต หรือคอมพิวเตอร์เครื่องอื่น ไม่ต้องใช้ SSH ไม่ต้องใช้ Termius — แค่เปิดเบราว์เซอร์
- **แดชบอร์ดหลายเซสชัน** — เริ่มงานในเซสชันหนึ่งไปพร้อมกับเฝ้าดูอีกเซสชันที่กำลังสตรีม ค้นหาข้ามโปรเจกต์ กรองตามแบรนช์ เจอสิ่งที่ต้องการได้รวดเร็ว
- **รากฐานโอเพนซอร์ส** — pi เป็นโอเพนซอร์สเต็มรูปแบบและไม่ผูกติดกับผู้ให้บริการรายใด คุณไม่ถูกล็อกกับโมเดลหรือผู้ให้บริการเพียงรายเดียว pi-web ก็เป็นโอเพนซอร์สเช่นกัน
- **การเข้าถึงระยะไกลที่ปลอดภัย** — มีการยืนยันตัวตนด้วยโทเคนในตัว จึงเปิดใช้บน LAN หรือ Tailscale ได้โดยไม่ต้องกังวล
- **แชร์ผลงานของคุณ** — ส่งออกเซสชันเป็นสแนปช็อตแบบสแตติกหรือ GitHub Gists แบบลับได้ในคลิกเดียว

## pi-web เป็นพื้นที่ทำงาน AI ส่วนตัวของคุณ 🏠

pi-web เป็น PWA (Progressive Web App) จึงสามารถ **ติดตั้งเหมือนแอปเนทีฟ** บนเดสก์ท็อป แล็ปท็อป โทรศัพท์ หรือแท็บเล็ต — ไม่ต้องใช้แอปสโตร์ บนเดสก์ท็อปจะเปิดในหน้าต่างของตัวเองโดยไม่มีขอบเบราว์เซอร์ จึงดูและรู้สึกเหมือนแอปพลิเคชันเดสก์ท็อปจริง ๆ

คิดว่ามันคือ **Claude Cowork ของคุณเอง** — พื้นที่ทำงาน AI ส่วนตัวที่อยู่บนเครื่องของคุณ — แต่เป็นโอเพนซอร์สและไม่ยึดติดกับโมเดล:

- **คุณเป็นเจ้าของสแต็ก.** เลือกโมเดลใดก็ได้ สลับเมื่อไหร่ก็ได้ตามใจ รันโมเดลโลคอลแล้วข้อมูลของคุณจะไม่หลุดออกจากเครื่องเลย
- **คนที่ไม่สายเทคนิคก็ใช้ได้.** ตั้งค่า pi-web บนเครื่องของพวกเขา สอนวิธีใช้ครั้งเดียว ก็ใช้ได้เลย พ่อแม่ แฟน เพื่อนที่ไม่สายเทคนิค — ไม่มีเทอร์มินัล ไม่มี SSH แค่อินเทอร์เฟซแชทที่คุ้นเคย
- **ตั้งค่าครั้งเดียว หลายคนใช้.** ติดตั้งบนเดสก์ท็อปแล้วแชร์หน้าจอ หรือเปิดใช้บนเครือข่ายบ้านแล้วให้คนในครอบครัวเปิดบนอุปกรณ์ของตัวเอง

อยากได้มากกว่าแค่เขียนโค้ดเหรอ? เปลี่ยนมันให้เป็น [ผู้ช่วยส่วนตัว](personal-assistant.md) ที่รู้จักคุณและอยู่บนเครื่องของคุณ — เหมือน OpenClaw หรือ Hermes ของคุณเอง

> 💡 **เคล็ดลับเด็ด:** ติดตั้ง pi-web เป็น PWA จาก Chrome/Edge (คลิกไอคอนติดตั้งในแถบที่อยู่) หรือ Safari (แชร์ → เพิ่มลง Dock) มันจะแยกไม่ออกเลยจากแอปเนทีฟ

## สิ่งที่คุณทำได้กับ pi-web

| | |
|---|---|
| 📱 **PWA** | ติดตั้ง pi-web เป็น Progressive Web App บนเดสก์ท็อป โทรศัพท์ หรือแท็บเล็ตเพื่อความรู้สึกแบบแอปเนทีฟ |
| 🔄 **ต่อเซสชัน** | กลับมาเริ่มบทสนทนาใดก็ได้จากจุดที่ค้างไว้ — ข้อความ รูปภาพ การสลับโมเดล ทั้งหมดจากเบราว์เซอร์ |
| 🆕 **เริ่มเซสชันใหม่** | สร้างเซสชันใหม่กับพาธโปรเจกต์ใดก็ได้ จากเว็บ UI ได้โดยตรง |
| 📡 **สตรีมสด** | ดูการตอบกลับของ pi สตรีมแบบเรียลไทม์ด้วยความหน่วงระดับ ~มิลลิวินาที โหมด Follow ช่วยให้คุณอยู่กับข้อความล่าสุดเสมอ |
| 🌲 **มุมมองแบบต้นไม้** | นำทางแผนผังข้อความดั้งเดิมของ pi — เห็นโครงสร้างบทสนทนาทั้งหมด กระโดดไปยังแบรนช์ใดก็ได้ และแยกออกจากจุดใดก็ได้ |
| 🔀 **แยกเซสชัน** | แยกเซสชันจากข้อความใดก็ได้ หรือแม้แต่การเรียกใช้เครื่องมือเฉพาะ — สำรวจทิศทางต่าง ๆ โดยไม่เสียจุดที่อยู่ |
| 🔍 **เรียกดูและค้นหา** | กรองเซสชันข้ามโปรเจกต์ ค้นหาด้วยชื่อ นำทางแบรนช์ — ประวัติเซสชันทั้งหมดของคุณในพริบตาเดียว |
| 🌿 **ผสานรวม Git** | เห็นแบรนช์ปัจจุบันและเปิด GitHub PR ได้จากหน้าดูเซสชันเลย |
| 📝 **สมุดโน้ต** | จดบันทึก รายการสิ่งที่ต้องทำ หรือความคิดสั้น ๆ ไว้ข้างเซสชันโดยไม่ต้องสลับแอป |
| 💬 **คำอธิบายประกอบ** | ไฮไลต์และคอมเมนต์ส่วนใดก็ได้ของเซสชัน — เหมาะกับการรีวิวโค้ด ให้ฟีดแบ็ก หรือบุ๊กมาร์กช่วงเวลาสำคัญ |
| 🎨 **ธีมและการปรับแต่ง** | สลับระหว่างโหมดมืดและโหมดสว่าง ปรับ UI ตามใจคุณ — ทำให้ pi-web รู้สึกเหมือนเป็น *ของคุณ* |
| 🌐 **หลายภาษา** | มี 14 ภาษาในตัว (English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ភាសាខ្មែរ, ລາວ) เพิ่มภาษาที่กำหนดเองได้จาก Settings |
| 🐱 **สุขภาพและ pomodoro** | การเขียนโค้ดแบบ vibe coding มากเกินไปไม่ดีต่อสุขภาพ มีตัวจับเวลา pomodoro ในตัวพร้อมเพื่อนแมวและการแจ้งเตือนเวลานอนเพื่อให้คุณสมดุล |
| 📤 **แชร์และส่งออก** | ดาวน์โหลด JSONL ส่งออกสแนปช็อตแบบสแตติกที่เรนเดอร์ด้วยลุค `pi.dev` ดั้งเดิมของ pi หรือแชร์เป็น GitHub Gists แบบส่วนตัว — ทั้งหมดเรนเดอร์ฝั่งไคลเอนต์ |
| 🔔 **เสียงแจ้งเตือน** | เสียงแจ้งเตือนที่ปรับแต่งได้สำหรับเหตุการณ์ในเซสชัน — ยังรับรู้ความเคลื่อนไหวแม้ pi-web อยู่ในแท็บอื่น |
| ⌨️ **คีย์ลัด** | การนำทางแบบ Vim, แอ็กชันด่วน — [อ่านอ้างอิงฉบับเต็ม →](keyboard-shortcuts.md) |
| 🤖 **ผู้ช่วยส่วนตัว** | เปลี่ยน pi-web ให้เป็นผู้ช่วย AI ส่วนตัวของคุณที่อยู่บนคอมพิวเตอร์ — เหมือน OpenClaw หรือ Hermes [ตั้งค่าเลย →](personal-assistant.md) |
| 🗓️ **คุยกับตารางนัดหมาย** | จากเซสชัน pi ให้พูดว่า “add a schedule at 2am Singapore time to …” — `/skill:pi-web-schedule` |
| 📝 **คุยกับโน้ตและการตั้งค่า** | “Write this in the notes” (`/skill:pi-web-notes`) หรือ “switch to dark mode” (`/skill:pi-web-settings`) |

## 💛 สนับสนุน
