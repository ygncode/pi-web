# pi-web ในฐานะผู้ช่วยส่วนตัวของคุณ

pi-web ไม่ได้ใช้แค่เขียนโค้ดเท่านั้น — คุณเปลี่ยนมันให้เป็น **ผู้ช่วย AI ส่วนตัว** ที่อาศัยอยู่ในคอมพิวเตอร์ของคุณ เหมือนมี OpenClaw หรือ Hermes ของคุณเอง

## มันทำงานอย่างไร

คุณสร้างโฟลเดอร์เฉพาะบนเครื่องของคุณ — นั่นคือที่ที่ผู้ช่วยของคุณอาศัยอยู่ ภายในนั้น คุณใส่ไฟล์ `APPEND_SYSTEM.md` ที่กำหนดว่าผู้ช่วยของคุณคือใคร รู้อะไรบ้าง และทำงานอย่างไร pi-web มอบอินเทอร์เฟซแชทที่สวยงามให้คุณพูดคุยกับมันได้จากทุกอุปกรณ์

## ทีละขั้นตอน

### 1. สร้างโฟลเดอร์ผู้ช่วยของคุณ

เลือกโฟลเดอร์ในคอมพิวเตอร์ของคุณ เช่น:

```
~/my-assistant/
```

### 2. กำหนดผู้ช่วยของคุณ

สร้างไฟล์ `APPEND_SYSTEM.md` ภายในโฟลเดอร์นั้น นี่คือที่ที่คุณบอก pi ว่าผู้ช่วยของคุณคือใคร:

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi จะผนวกสิ่งนี้เข้ากับ system prompt ของทุกการสนทนาโดยอัตโนมัติ ดังนั้นผู้ช่วยของคุณจะรู้เสมอว่าคุณคือใครและจะช่วยอย่างไร

### 3. เริ่มเซสชันในโฟลเดอร์นั้น

ใน pi-web สร้างเซสชันใหม่ที่ชี้ไปยัง `~/my-assistant/` (หรือชื่ออะไรก็ตามที่คุณตั้ง) แค่นั้น — คุณกำลังพูดคุยกับผู้ช่วยส่วนตัวของคุณแล้ว

### 4. ใช้งานจากทุกที่

ติดตั้ง pi-web เป็น PWA บนโทรศัพท์ แท็บเล็ต หรือแล็ปท็อปของคุณ ผู้ช่วยของคุณอยู่ตรงนั้นเสมอ — ถามอะไรก็ได้ ทุกเมื่อ

## ไอเดียสำหรับผู้ช่วยของคุณ

| บทบาท | สิ่งที่ควรใส่ใน APPEND_SYSTEM.md |
|---|---|
| 🧠 **โค้ชชีวิต** | เป้าหมายของคุณ นิสัยที่คุณกำลังฝึก บันทึกประจำวัน |
| 🏠 **ผู้จัดการบ้าน** | รูปแบบรายการซื้อของ ความชอบของสมาชิกครอบครัว การวางแผนมื้ออาหาร |
| 💼 **เพื่อนคู่คิดในงาน** | บทบาทของคุณ โปรเจกต์ปัจจุบัน รูปแบบบันทึกการประชุม บริบทบริษัท |
| 📚 **เพื่อนเรียน** | สิ่งที่คุณกำลังเรียน รูปแบบการอธิบายที่ชอบ โหมดถามตอบ |
| ✍️ **ผู้ช่วยเขียน** | สไตล์การเขียนของคุณ โทนที่ชอบ รูปแบบที่คุณใช้บ่อย |

## เพิ่มบริบทเพิ่มเติม

คุณสามารถใส่สิ่งใดก็ได้ในโฟลเดอร์ผู้ช่วยของคุณที่ช่วยให้ pi มีประโยชน์มากขึ้น:

- `notes/` — ไฟล์อ้างอิงที่ผู้ช่วยของคุณสามารถอ่านได้
- `context.md` — ข้อมูลพื้นฐานเกี่ยวกับชีวิตหรืองานของคุณ
- `projects.md` — โปรเจกต์ปัจจุบันและสถานะของมัน

pi สามารถอ่านไฟล์ในโฟลเดอร์ได้ ดังนั้นยิ่งคุณให้บริบทมากเท่าไหร่ มันก็ยิ่งเก่งขึ้นเท่านั้น
