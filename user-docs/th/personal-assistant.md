# pi-web ในฐานะผู้ช่วยส่วนตัวของคุณ

pi-web ไม่ได้มีไว้แค่สำหรับเขียนโค้ด — คุณสามารถเปลี่ยนมันให้เป็น **ผู้ช่วย AI ส่วนตัว** ที่อยู่บนคอมพิวเตอร์ของคุณ เหมือนมี OpenClaw หรือ Hermes เป็นของตัวเอง

## วิธีการทำงาน

คุณสร้างโฟลเดอร์เฉพาะบนเครื่องของคุณ — นั่นคือที่อยู่ของผู้ช่วยของคุณ ภายในนั้น คุณใส่ไฟล์ `APPEND_SYSTEM.md` ที่กำหนดว่าผู้ช่วยของคุณคือใคร รู้อะไรบ้าง และควรมีพฤติกรรมอย่างไร pi-web มอบอินเทอร์เฟซแชทที่สวยงามให้คุณใช้คุยกับมันจากอุปกรณ์ใดก็ได้

## ทีละขั้นตอน

### 1. สร้างโฟลเดอร์ผู้ช่วยของคุณ

เลือกโฟลเดอร์บนคอมพิวเตอร์ของคุณ เช่น:

```
~/my-assistant/
```

### 2. กำหนดผู้ช่วยของคุณ

สร้างไฟล์ `APPEND_SYSTEM.md` ภายในโฟลเดอร์นั้น นี่คือที่ที่คุณบอก pi ว่าผู้ช่วยของคุณคือใคร:

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi จะผนวกสิ่งนี้เข้ากับ system prompt ของทุกบทสนทนาโดยอัตโนมัติ ผู้ช่วยของคุณจึงรู้เสมอว่าคุณคือใครและจะช่วยคุณอย่างไร

### 3. เริ่มเซสชันในโฟลเดอร์นั้น

ใน pi-web ให้สร้างเซสชันใหม่ที่ชี้ไปยัง `~/my-assistant/` (หรือชื่อที่คุณตั้งไว้) แค่นั้นเอง — คุณก็กำลังคุยกับผู้ช่วยส่วนตัวของคุณแล้ว

### 4. ใช้ได้จากทุกที่

ติดตั้ง pi-web เป็น PWA บนโทรศัพท์ แท็บเล็ต หรือแล็ปท็อปของคุณ ผู้ช่วยของคุณอยู่ตรงนั้นเสมอ — ถามอะไรก็ได้ ทุกเวลา

## ไอเดียสำหรับผู้ช่วยของคุณ

| บทบาท | สิ่งที่ใส่ใน APPEND_SYSTEM.md |
|---|---|
| 🧠 **โค้ชชีวิต** | เป้าหมายของคุณ นิสัยที่คุณกำลังฝึก หัวข้อสำหรับเขียนบันทึก |
| 🏠 **ผู้จัดการบ้าน** | รูปแบบรายการซื้อของชำ ความชอบของสมาชิกในครอบครัว การวางแผนมื้ออาหาร |
| 💼 **คู่หูทำงาน** | บทบาทของคุณ โปรเจกต์ปัจจุบัน รูปแบบบันทึกการประชุม บริบทของบริษัท |
| 📚 **คู่เรียน** | สิ่งที่คุณกำลังเรียน สไตล์การอธิบายที่ชอบ โหมดทดสอบฉัน |
| ✍️ **ผู้ช่วยเขียน** | สไตล์การเขียนของคุณ ความชอบด้านโทนเสียง รูปแบบที่คุณใช้บ่อย |

## เพิ่มบริบทมากขึ้น

คุณสามารถใส่อะไรก็ได้ในโฟลเดอร์ผู้ช่วยของคุณที่ช่วยให้ pi มีประโยชน์มากขึ้น:

- `notes/` — ไฟล์อ้างอิงที่ผู้ช่วยของคุณอ่านได้
- `context.md` — ข้อมูลเบื้องหลังเกี่ยวกับชีวิตหรือการทำงานของคุณ
- `projects.md` — โปรเจกต์ปัจจุบันและสถานะของโปรเจกต์

pi อ่านไฟล์ในโฟลเดอร์ได้ ดังนั้นยิ่งให้บริบทมากเท่าไหร่ มันก็ยิ่งเก่งขึ้นเท่านั้น

## สั่งให้ pi-web ทำสิ่งต่างๆ

หลังจาก `pi install npm:@ygncode/pi-web@beta` เซสชันต่างๆ จะคุยกับ pi-web เองได้
ลอง:

- “เพิ่มตารางเวลาเวลา 02:00 น. ตามเวลาสิงคโปร์เพื่อสรุปกล่องจดหมายของฉัน”
- “แสดงรายการตารางเวลาของ pi-web”
- “หยุดตารางเวลากล่องจดหมายชั่วคราว”
- “จดสิ่งนี้ลงในโน้ต”
- “สลับ pi-web เป็นโหมดมืด / ปิดการตั้งชื่ออัตโนมัติ”

สกิล **/skill:pi-web-schedule** ที่รวมมาด้วยจะเปลี่ยนสิ่งนั้นให้เป็นตารางเวลาจริงของ pi-web (อันเดียวกับที่คุณแก้ไขที่ `/schedules`) การเรียกใช้แต่ละครั้งจะเริ่มเซสชัน **ใหม่** ดังนั้นคำสั่งต้องสมบูรณ์ในตัวเอง — “สรุปอีเมลที่ยังไม่ได้อ่านใน ~/inbox” ใช้ได้ แต่ “ทำต่อจากที่เราค้างไว้” ใช้ไม่ได้

ตารางเวลาจะทำงานเฉพาะตอนที่ pi-web กำลังทำงานอยู่เท่านั้น
