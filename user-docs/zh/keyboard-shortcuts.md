# 键盘快捷键

## 首页（`/`）

### 页面滚动（Vim 风格）

当焦点**不在** input、textarea 或 contenteditable 元素内时，相同的 Vim 风格快捷键在所有页面上均有效。

| 快捷键 | 操作 |
|--------|------|
| `j` | 向下滚动 300px |
| `k` | 向上滚动 300px |
| `g g` | 滚动到页面顶部 |
| `G` (Shift+G) | 滚动到页面底部 |
| `Escape` | 取消聚焦当前输入框，以便 j/k 导航生效 |

### 首页命令

| 快捷键 | 上下文 | 操作 |
|--------|--------|------|
| `⌘K` / `Ctrl+K` | 页面级 | 打开搜索/会话面板 |
| `⌘⇧L` / `Ctrl+Shift+L` | 页面级 | 切换系统主题（浅色/深色） |
| `Escape` | 页面级 | 关闭面板、菜单或模态框 |
| `Enter` | 新会话路径输入框 | 创建新会话 |

> `⌘K` / `Ctrl+K` 同时也是 Chrome 的"聚焦地址栏"快捷键。除非焦点在文本输入框内，否则浏览器可能会拦截此快捷键。

## 会话详情页（`/session?id=...`）

### 页面滚动（Vim 风格）

这些快捷键在首页和会话页上均有效，前提是焦点**不在** input、textarea 或 contenteditable 元素内。

| 快捷键 | 操作 |
|--------|------|
| `j` | 向下滚动 300px |
| `k` | 向上滚动 300px |
| `g g` | 滚动到页面顶部 |
| `G` (Shift+G) | 滚动到页面底部 |
| `I` (Shift+I) | 聚焦聊天输入框 |
| `Escape` | 取消聚焦当前输入框，以便 j/k 导航生效 |

### 侧边栏与导航

| 快捷键 | 上下文 | 操作 |
|--------|--------|------|
| `⌘B` / `Ctrl+B` | 页面级 | 切换侧边栏显示/隐藏 |
| `⌘K` / `Ctrl+K` | 页面级 | 打开会话列表面板 |
| `⌘T` / `Ctrl+T` | 页面级 | 新建会话 |
| `⌘⇧L` / `Ctrl+Shift+L` | 页面级 | 切换系统主题（浅色/深色） |
| `⌘⇧N` / `Ctrl+Shift+N` | 页面级 | 切换草稿板 / 笔记侧边栏 |

> `⌘K` 和 `⌘T` 同时也是浏览器快捷键（聚焦地址栏 / 新建标签页）。除非焦点在文本输入框内，否则浏览器可能会拦截这些快捷键。

### 聊天输入框

| 快捷键 | 上下文 | 操作 |
|--------|--------|------|
| `Enter` | 聊天输入区域 | 提交消息 |
| `Shift+Enter` | 聊天输入区域 | 插入换行 |
| `Shift+Tab` | 聊天输入区域 | 切换到下一个思考级别（`off` → `minimal` → … → `xhigh` → `off`） |
| `Ctrl+I` / `Ctrl+L` | 聊天输入区域 | 打开模型选择弹窗（输入筛选，Enter 选择，焦点返回输入框） |

### 条目可见性切换

| 快捷键 | 上下文 | 操作 |
|--------|--------|------|
| `t` | 焦点**不在** input/textarea 内时 | 切换思考内容可见性 |
| `o` | 焦点**不在** input/textarea 内时 | 切换工具调用可见性 |
| `p` | 焦点**不在** input/textarea 内时 | 切换工具输出可见性 |

### 面板、菜单与弹出层

| 快捷键 | 上下文 | 操作 |
|--------|--------|------|
| `Escape` | 页面级 | 关闭任何打开的面板、菜单或弹出层 |
| `⌘K` / `Ctrl+K` | 页面级 | 打开会话列表面板 |
| `ArrowUp` / `ArrowDown` | 会话列表面板 | 浏览会话结果 |
| `Enter` | 会话列表面板 | 打开选中（或第一个）会话 |
| `ArrowUp` / `ArrowDown` | 模型选择弹窗 | 浏览模型列表 |
| `Enter` | 模型选择弹窗 | 选择高亮的模型 |
| `ArrowUp` / `ArrowDown` | Fork 模态框 | 浏览消息 |
| `Enter` | Fork 模态框 | 从高亮消息处 Fork |
| `Tab` | 全屏弹出层 | 在弹出层内循环切换焦点 |
| `Escape` | 全屏弹出层 | 关闭弹出层 |
