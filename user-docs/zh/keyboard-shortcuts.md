# 键盘快捷键

## 首页（`/`）

### 页面滚动（vim 风格）

当焦点**不**在 input、textarea 或 contenteditable 元素中时，相同的 vim 风格快捷键在所有页面上都可用。

| 快捷键 | 操作 |
|----------|--------|
| `j` | 向下滚动 300px |
| `k` | 向上滚动 300px |
| `g g` | 滚动到页面顶部 |
| `G` (Shift+G) | 滚动到页面底部 |
| `Escape` | 让当前输入框失焦，以便 j/k 导航生效 |

### 首页命令

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | 页面级 | 打开搜索/会话面板 |
| `⌘,` / `Ctrl+,` | 页面级 | 打开设置 |
| `⌘⇧L` / `Ctrl+Shift+L` | 页面级 | 切换系统主题（浅色/深色） |
| `Escape` | 页面级 | 关闭面板、菜单或模态框 |
| `Enter` | 新建会话路径输入框 | 创建新会话 |

> `⌘K` / `Ctrl+K` 同时也是 Chrome 的“聚焦地址栏”快捷键。除非焦点位于文本输入框内，否则浏览器可能会拦截它。

## 会话详情页（`/session?id=...`）

### 页面滚动（vim 风格）

当焦点**不**在 input、textarea 或 contenteditable 元素中时，这些快捷键在首页和会话页上均可用。

| 快捷键 | 操作 |
|----------|--------|
| `j` | 向下滚动 300px |
| `k` | 向上滚动 300px |
| `g g` | 滚动到页面顶部 |
| `G` (Shift+G) | 滚动到页面底部 |
| `I` (Shift+I) | 聚焦聊天输入框 textarea |
| `Escape` | 让当前输入框失焦，以便 j/k 导航生效 |

### 侧边栏与导航

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | 页面级 | 切换侧边栏显示/隐藏 |
| `⌘K` / `Ctrl+K` | 页面级 | 打开会话列表面板 |
| `⌘T` / `Ctrl+T` | 页面级 | 新建会话 |
| `⌘/` / `Ctrl+/` | 页面级 | 显示键盘快捷键模态框 |
| `⌘,` / `Ctrl+,` | 页面级 | 打开设置 |
| `⌘⇧L` / `Ctrl+Shift+L` | 页面级 | 切换系统主题（浅色/深色） |
| `⌘⇧N` / `Ctrl+Shift+N` | 页面级 | 切换草稿板 / 笔记侧边栏 |

> `⌘K` 和 `⌘T` 同时也是浏览器快捷键（聚焦地址栏 / 新建标签页）。除非焦点位于文本输入框内，否则浏览器可能会拦截它们。

### 聊天输入框

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `Enter` | 聊天 textarea | 发送消息 |
| `Shift+Enter` | 聊天 textarea | 插入换行 |
| `Shift+Tab` | 聊天 textarea | 循环到下一个思考级别（`off` → `minimal` → … → `xhigh` → `off`） |
| `Ctrl+I` / `Ctrl+L` | 聊天 textarea | 打开模型选择器弹窗（输入以筛选，按 Enter 选择，焦点返回 textarea） |

### 条目可见性开关

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `t` | 当焦点**不**在 input/textarea 中时 | 切换思考可见性 |
| `o` | 当焦点**不**在 input/textarea 中时 | 切换工具可见性 |
| `p` | 当焦点**不**在 input/textarea 中时 | 切换工具输出显示 |

### 面板、菜单与抽屉

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `Escape` | 页面级 | 关闭任何打开的面板、菜单或抽屉 |
| `⌘K` / `Ctrl+K` | 页面级 | 打开会话列表面板 |
| `ArrowUp` / `ArrowDown` | 会话列表面板 | 在会话结果间导航 |
| `Enter` | 会话列表面板 | 打开选中的（或第一个）会话 |
| `ArrowUp` / `ArrowDown` | 模型选择器弹窗 | 在模型列表中导航 |
| `Enter` | 模型选择器弹窗 | 选中高亮的模型 |
| `ArrowUp` / `ArrowDown` | Fork 模态框 | 在消息间导航 |
| `Enter` | Fork 模态框 | 从高亮的消息派生 |
| `Tab` | 全屏抽屉 | 在抽屉内循环切换焦点 |
| `Escape` | 全屏抽屉 | 关闭抽屉 |
