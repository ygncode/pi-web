**想试试 pi-web？放手去用吧——你会爱上它的。**

pi-web 是一款精美的 Web UI 和 PWA，专为 [pi](https://pi.dev)——开源 AI 编程助手打造。它让你可以在任何浏览器、任何设备上浏览、阅读和继续你的 pi 会话，处处都有贴心的功能设计。

**pi-web 为两类人群而生：**

- 🧑‍💻 **面向开发者**——他们离不开终端，但也想从手机上继续会话、交给远程服务器处理，或者随时监控长时间运行的任务。
- ✨ **面向非开发者**——他们只想要一个好用的精美 AI 应用。打开、输入、享受。无需终端，无需 SSH，没有困惑。就像最好用的 AI 工具一样，但拥有模型选择和开源自由。

---

## 为什么选择 pi-web？

你已经在终端里与 pi 深度协作，进入心流状态。pi-web 让你离开工位后仍能保持这种势头：

- **随时随地继续**——从手机、平板或另一台电脑继续会话。无需 SSH，无需 Termius——打开浏览器即可。
- **多会话控制台**——在一个会话中启动工作，同时监控另一个会话的实时输出。跨项目搜索，按分支筛选，快速找到所需内容。
- **开源基石**——pi 完全开源且不绑定任何模型供应商。你不会被锁定在某个模型或厂商上。pi-web 同样是开源的。
- **安全的远程访问**——内置 Token 认证，让你可以放心地在局域网或 Tailscale 上暴露服务。
- **分享你的工作**——将会话导出为静态快照或一键分享为私密 GitHub Gist。

## pi-web 作为你的个人 AI 工作空间 🏠

pi-web 是一个 PWA（渐进式 Web 应用），因此你可以**像安装原生应用一样安装它**到桌面、笔记本、手机或平板上——无需应用商店。在桌面上，它在独立窗口中打开，没有任何浏览器边框，看起来和用起来都像一个真正的桌面应用。

把它看作**你自己的 Claude Cowork**——一个运行在你机器上的个人 AI 工作空间——只不过它开源且不绑定特定模型：

- **你掌控整个技术栈。** 选择任何模型，随时切换。运行本地模型，你的数据永远不会离开你的机器。
- **非技术人员也能用。** 在他们的机器上设置好 pi-web，演示一次怎么用，他们就能轻松上手。你的父母、伴侣、不懂技术的朋友——无需终端，无需 SSH，只有一个熟悉的聊天界面。
- **一次配置，多人使用。** 安装在你的桌面上并共享屏幕，或在家中局域网上暴露服务，让家人在自己的设备上打开使用。

不止于编程？把它变成专属的[个人助手](personal-assistant.md)，让它了解你是谁并运行在你的机器上——就像你自己的 OpenClaw 或 Hermes。

> 💡 **专业提示：** 从 Chrome/Edge（点击地址栏中的安装图标）或 Safari（分享 → 添加到 Dock）将 pi-web 安装为 PWA。它将与原生应用难以区分。

## pi-web 能做什么

| | |
|---|---|
| 📱 **PWA** | 将 pi-web 安装为渐进式 Web 应用，在桌面、手机或平板上获得原生体验。 |
| 🔄 **继续会话** | 从上次中断的地方继续任何对话——文本、图片、模型切换，一切都在浏览器中完成。 |
| 🆕 **开始新会话** | 直接从 Web UI 针对任意项目路径创建全新会话。 |
| 📡 **实时流式输出** | 实时观看 pi 的响应以毫秒级延迟流入。跟随模式让你始终锁定最新内容。 |
| 🌲 **树状视图** | 浏览 pi 原生的消息树——查看完整的对话结构，跳转到任意分支，从任意节点分叉。 |
| 🔀 **分叉会话** | 从任意消息甚至特定工具调用处分叉会话——在不丢失原有进度的前提下探索不同方向。 |
| 🔍 **浏览与搜索** | 跨项目筛选会话，按名称搜索，浏览分支——你的完整会话历史一览无余。 |
| 🌿 **Git 集成** | 查看当前分支，直接通过会话查看器打开 GitHub PR。 |
| 📝 **便签本** | 在会话旁边随手记下笔记、待办事项或快速想法，无需切换应用。 |
| 💬 **批注** | 对会话的任意部分高亮并添加批注——非常适合代码审查、反馈或标记关键时刻。 |
| 🎨 **主题与定制** | 在暗色和亮色模式之间切换，调整 UI 以适应你的喜好——让 pi-web 让你感觉*就是你的*。 |
| 🌐 **多语言** | 内置 14 种语言（English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ភាសាខ្មែរ, ລາວ）。在设置中添加你自己的自定义语言。 |
| 🐱 **健康与 pomodoro** | 过度 vibe coding 不利于健康。内置 pomodoro 计时器，配有猫咪伙伴和睡眠提醒，帮你保持平衡。 |
| 📤 **分享与导出** | 下载 JSONL，导出以 pi 原生 `pi.dev` 风格渲染的静态快照，或分享为私密 GitHub Gist——全部在客户端渲染。 |
| 🔔 **通知声音** | 可自定义的会话事件通知提示音——即使 pi-web 在另一个标签页中，也能让你掌握动态。 |
| ⌨️ **键盘快捷键** | Vim 风格导航，快速操作——[完整参考 →](keyboard-shortcuts.md) |
| 🤖 **个人助手** | 将 pi-web 变成运行在你电脑上的专属 AI 助手——就像 OpenClaw 或 Hermes。[设置指南 →](personal-assistant.md) |
