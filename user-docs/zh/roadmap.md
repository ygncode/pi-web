# 路线图

pi-web 为两类用户打造：

- **面向开发者**——他们生活在终端中，但希望从移动端继续会话、将会话移交到远程服务器，或随时随地关注长时间运行的任务。
- **面向非开发者**——他们只想要一个美观且好用的 AI 应用。打开，输入，享受。无需终端，无需 SSH，无需困惑。就像最友好的 AI 工具一样，但拥有模型选择和开源自由。

以下是即将推出的功能。

## 愿景

长期目标：pi-web 应该成为 **pi 的界面**——面向所有人。

- **非开发者**像打开任何其他应用一样打开它。选择模型，输入，完成。无需命令行。
- **开发者**获得深度集成——远程移交、多会话仪表板、git 感知的浏览、消息机器人。
- **每个人**都能享受模型自由、开源透明，以及处处用心的 UI。
