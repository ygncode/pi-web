# pi-web 作为你的个人助手

pi-web 不只是用来写代码的 — 你可以把它变成一个**个人 AI 助手**，运行在你的电脑上，就像拥有你自己的 OpenClaw 或 Hermes。

## 工作原理

你在电脑上创建一个专用的文件夹 — 那就是你的助手所在之处。在文件夹里，放入一个 `APPEND_SYSTEM.md` 文件，用来定义你的助手是谁、它知道什么，以及它的行为方式。pi-web 为你提供一个美观的聊天界面，让你可以从任何设备与它对话。

## 一步步来

### 1. 创建你的助手文件夹

在你的电脑上选择一个文件夹。例如：

```
~/my-assistant/
```

### 2. 定义你的助手

在该文件夹中创建一个 `APPEND_SYSTEM.md` 文件。在这里你可以告诉 pi 你的助手是谁：

```markdown
# 我的个人助手

你是 Jarvis，我的个人 AI 助手。你帮我处理以下事务：

- 日常规划与提醒
- 调研与摘要
- 起草邮件和消息
- 头脑风暴创意
- 跟踪我提到的事情

## 关于我

- 我是一名远程工作的软件工程师
- 我有一只叫 Pixel 的猫
- 我喜欢简短、直接的回答
- 我的时区是 PST

## 规则

- 要简洁 — 我重视精炼
- 如果你不知道某事，就直接说
- 主动提醒我让你跟踪的事情
```

pi 会自动将这段内容附加到每次对话的系统提示中，这样你的助手始终知道你是谁以及如何帮助你。

### 3. 在该文件夹中启动会话

在 pi-web 中，创建一个指向 `~/my-assistant/`（或你命名的其他路径）的新会话。就这样 — 你已经在和你的个人助手对话了。

### 4. 随时随地使用

将 pi-web 作为 PWA 安装到你的手机、平板或笔记本电脑上。你的助手随时在线 — 随时随地都可以向它提问。

## 助手的创意

| 角色 | 在 APPEND_SYSTEM.md 中放什么 |
|---|---|
| 🧠 **人生教练** | 你的目标、正在养成的习惯、日记提示 |
| 🏠 **家庭管家** | 购物清单格式、家人的偏好、膳食计划 |
| 💼 **工作伙伴** | 你的职位、当前项目、会议记录格式、公司背景 |
| 📚 **学习伙伴** | 你在学什么、偏好的解释风格、测验模式 |
| ✍️ **写作助手** | 你的写作风格、语气偏好、你常用的格式 |

## 添加更多上下文

你可以在助手文件夹中放入任何有助于 pi 变得更有用的内容：

- `notes/` — 助手可以读取的参考文件
- `context.md` — 关于你的生活或工作的背景信息
- `projects.md` — 当前项目及其状态

pi 可以读取文件夹中的文件，所以你提供的上下文越多，它的表现就越好。

---

> 💡 **小贴士：** 从简单开始。只需几行说明你是谁以及你希望助手如何表现。随着你逐渐了解什么方式有效，再慢慢迭代改进。
