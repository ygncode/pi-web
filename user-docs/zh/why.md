# 为什么是 pi-web？

我有点沉迷于 Claude Code。我一直在用它。不坐在电脑前的时候，我就在想它。我感觉自己烧的 token 还不够多。那是 Claude Code 的早期阶段。我当时在想，为什么我不能从手机上继续呢？我配置了 Termius，但不太喜欢。

我开始自己做一个，但当 Claude 推出他们的 Claude Code 移动应用后，我就停下了。

然后我得了椎间盘突出，几乎什么也做不了。时间流逝，我感觉恢复了一些，想继续我的 Claude Code web/pwa 项目。

然后 Claude Code 开始禁止在其自有框架之外使用。我觉得这不值得了。

然后我发现了 pi.dev，稍微了解了一下，但还没有真正深入。我阅读了相关资料，看了视频，决定好好试一下，现在完全迷上了 pi。

因为它是开源的，我觉得值得为它构建。我还能选择不同的提供商。我也觉得只依赖一个提供商/模型（比如 Anthropic/Claude）是不可持续的。

所以我在这里构建它。
