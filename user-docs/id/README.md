**Berpikir untuk mencoba pi-web? Silakan saja — Anda akan jatuh cinta.**

pi-web adalah antarmuka web dan PWA yang indah untuk [pi](https://pi.dev) — agen coding AI bersumber terbuka. pi-web memungkinkan Anda menjelajah, membaca, dan melanjutkan sesi pi dari browser mana pun, di perangkat apa pun, dengan fitur-fitur yang dirancang penuh pertimbangan di setiap sudutnya.

**pi-web dibuat untuk dua jenis orang:**

- 🧑‍💻 **Untuk developer** — yang hidup di terminal tetapi ingin melanjutkan sesi dari ponsel, menyerahkan ke server jarak jauh, atau memantau tugas yang berjalan lama dari mana saja.
- ✨ **Untuk non-developer** — yang hanya menginginkan aplikasi AI yang indah dan berfungsi. Buka, ketik, nikmati. Tanpa terminal, tanpa SSH, tanpa kebingungan. Seperti alat AI yang paling ramah pengguna, tetapi dengan kebebasan memilih model dan kebebasan open source.

---

## Mengapa pi-web?

Anda sudah larut dalam alur kerja dengan pi di terminal. pi-web menjaga momentum itu tetap berjalan saat Anda meninggalkan meja kerja:

- **Lanjutkan dari mana saja** — lanjutkan sesi dari ponsel, tablet, atau komputer lain. Tanpa SSH, tanpa Termius — cukup buka browser Anda.
- **Dasbor multi-sesi** — mulai pekerjaan di satu sesi sambil memantau sesi lain yang sedang streaming. Cari di seluruh proyek, filter berdasarkan branch, temukan yang Anda butuhkan dengan cepat.
- **Fondasi open source** — pi sepenuhnya open source dan netral terhadap penyedia. Anda tidak terkunci pada satu model atau vendor. pi-web juga open source.
- **Akses jarak jauh yang aman** — autentikasi token bawaan sehingga Anda dapat mengeksposnya di LAN atau Tailscale tanpa khawatir.
- **Bagikan pekerjaan Anda** — ekspor sesi sebagai snapshot statis atau GitHub Gist rahasia dalam satu klik.

## pi-web sebagai ruang kerja AI pribadi Anda 🏠

pi-web adalah PWA (Progressive Web App), jadi Anda bisa **menginstalnya seperti aplikasi native** di desktop, laptop, ponsel, atau tablet — tanpa perlu app store. Di desktop, pi-web terbuka di jendelanya sendiri tanpa chrome browser, sehingga terlihat dan terasa seperti aplikasi desktop sungguhan.

Anggap saja ini sebagai **Claude Cowork milik Anda sendiri** — ruang kerja AI pribadi yang tinggal di mesin Anda — bedanya pi-web open source dan netral terhadap model:

- **Anda memiliki seluruh stack-nya.** Pilih model apa pun, ganti kapan pun Anda mau. Jalankan model lokal dan data Anda tidak pernah meninggalkan mesin Anda.
- **Orang non-teknis bisa menggunakannya.** Siapkan pi-web di mesin mereka, ajari cara memakainya sekali, dan mereka siap berangkat. Orang tua Anda, pasangan Anda, teman-teman non-teknis Anda — tanpa terminal, tanpa SSH, cukup antarmuka chat yang familiar.
- **Satu pengaturan, banyak pengguna.** Instal di desktop Anda dan bagikan layar Anda, atau ekspos di jaringan rumah dan biarkan anggota keluarga membukanya di perangkat mereka masing-masing.

Ingin lebih dari sekadar coding? Ubah menjadi [asisten pribadi](personal-assistant.md) khusus yang mengenal siapa Anda dan tinggal di mesin Anda — seperti OpenClaw atau Hermes milik Anda sendiri.

> 💡 **Kiat pro:** Instal pi-web sebagai PWA dari Chrome/Edge (klik ikon instal di bilah alamat) atau Safari (Bagikan → Tambah ke Dock). Hasilnya tidak bisa dibedakan dari aplikasi native.

## Yang bisa Anda lakukan dengan pi-web

| | |
|---|---|
| 📱 **PWA** | Instal pi-web sebagai Progressive Web App di desktop, ponsel, atau tablet untuk nuansa native. |
| 🔄 **Lanjutkan sesi** | Lanjutkan percakapan apa pun tepat dari tempat Anda berhenti — teks, gambar, pergantian model, semuanya dari browser. |
| 🆕 **Mulai sesi baru** | Buat sesi baru untuk jalur proyek mana pun, langsung dari antarmuka web. |
| 📡 **Streaming langsung** | Saksikan respons pi mengalir secara real time dengan latensi ~ms. Mode ikuti membuat Anda terkunci pada yang terbaru. |
| 🌲 **Tampilan pohon** | Jelajahi pohon pesan native pi — lihat struktur percakapan penuh, lompat ke branch mana pun, dan fork dari titik mana pun. |
| 🔀 **Fork sesi** | Fork sesi dari pesan mana pun atau bahkan panggilan tool tertentu — jelajahi arah yang berbeda tanpa kehilangan posisi Anda. |
| 🔍 **Jelajah & cari** | Filter sesi di seluruh proyek, cari berdasarkan nama, navigasi branch — seluruh riwayat sesi Anda dalam sekejap. |
| 🌿 **Integrasi Git** | Lihat branch saat ini dan buka GitHub PR langsung dari penampil sesi. |
| 📝 **Scratchpad** | Catat note, todo, atau pikiran cepat di samping sesi Anda tanpa berpindah aplikasi. |
| 💬 **Anotasi** | Sorot dan beri komentar pada bagian mana pun dari sesi — bagus untuk review kode, umpan balik, atau menandai momen penting. |
| 🎨 **Tema & kustomisasi** | Beralih antara mode gelap dan terang, sesuaikan antarmuka sesuai selera — buat pi-web terasa seperti *milik Anda*. |
| 🌐 **Multi-bahasa** | 14 bahasa bawaan (English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ភាសាខ្មែរ, ລາວ). Tambahkan bahasa kustom Anda sendiri dari Pengaturan. |
| 🐱 **Wellness & pomodoro** | Terlalu banyak vibe coding tidaklah sehat. Timer pomodoro bawaan dengan teman kucing dan pengingat tidur untuk menjaga keseimbangan Anda. |
| 📤 **Bagikan & ekspor** | Unduh JSONL, ekspor snapshot statis yang dirender dengan tampilan native `pi.dev` milik pi, atau bagikan sebagai GitHub Gist pribadi — semuanya dirender di sisi klien. |
| 🔔 **Suara notifikasi** | Bunyi notifikasi yang dapat disesuaikan untuk peristiwa sesi — tetap terhubung bahkan saat pi-web berada di tab lain. |
| ⌨️ **Pintasan keyboard** | Navigasi ala Vim, tindakan cepat — [referensi lengkap →](keyboard-shortcuts.md) |
| 🤖 **Asisten pribadi** | Ubah pi-web menjadi asisten AI Anda sendiri yang tinggal di komputer Anda — seperti OpenClaw atau Hermes. [Atur sekarang →](personal-assistant.md) |
| 🗓️ **Bicara ke jadwal** | Dari sesi pi, ucapkan "add a schedule at 2am Singapore time to …" — `/skill:pi-web-schedule`. |
| 📝 **Bicara ke note & pengaturan** | "Write this in the notes" (`/skill:pi-web-notes`) atau "switch to dark mode" (`/skill:pi-web-settings`). |
