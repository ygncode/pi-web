# ແຜນການພັດທະນາ

pi-web ຖືກສ້າງຂຶ້ນສຳລັບຜູ້ໃຊ້ສອງກຸ່ມ:

- **ສຳລັບນັກພັດທະນາ** — ຜູ້ທີ່ໃຊ້ຊີວິດຢູ່ໃນ terminal ແຕ່ຕ້ອງການສືບຕໍ່ sessions ຈາກມືຖື, ສົ່ງຕໍ່ໄປຍັງ server ທີ່ຢູ່ໄກ, ຫຼືຕິດຕາມວຽກທີ່ໃຊ້ເວລາດົນຈາກທຸກບ່ອນ.
- **ສຳລັບຜູ້ບໍ່ແມ່ນນັກພັດທະນາ** — ຜູ້ທີ່ພຽງແຕ່ຕ້ອງການແອັບ AI ທີ່ສວຍງາມທີ່ໃຊ້ງານໄດ້. ເປີດມັນ, ພິມ, ສະບາຍໆ. ບໍ່ມີ terminal, ບໍ່ມີ SSH, ບໍ່ສັບສົນ. ຄືກັບເຄື່ອງມື AI ທີ່ໃຊ້ງ່າຍທີ່ສຸດ, ແຕ່ມີການເລືອກ model ແລະ ເສລີພາບແບບ open-source.

ນີ້ແມ່ນສິ່ງທີ່ກຳລັງຈະມາ.

---

## ຕອນນີ້ (ເປີດໃຊ້ແລ້ວ)

ທຸກສິ່ງທີ່ລະບຸໄວ້ໃນ [ຕາຕະລາງຄຸນສົມບັດ](README.md#what-you-can-do-with-pi-web) ໃຊ້ງານໄດ້ແລ້ວໃນມື້ນີ້.

ຄຸນສົມບັດທີ່ເຄີຍຢູ່ໃນແຜນການນີ້ ແລະ ໄດ້ເປີດໃຊ້ແລ້ວ:

| ຄຸນສົມບັດ | ສິ່ງທີ່ມັນເຮັດ |
|---|---|
| **Steering / queue** ([#46](https://github.com/ygncode/pi-web/issues/46)) | ສົ່ງຄຳແນະນຳຕິດຕາມໃນຂະນະທີ່ pi ຍັງເຮັດວຽກຢູ່, ຫຼືຈັດຄິວຂໍ້ຄວາມສຳລັບຮອບຕໍ່ໄປ. |
| **Scheduler** ([#44](https://github.com/ygncode/pi-web/issues/44)) | ຕັ້ງເວລາໃຫ້ prompts ເຮັດວຽກອັດຕະໂນມັດ — ການປະຊຸມປະຈຳວັນ (standups), ສະຫຼຸບຕອນເຊົ້າ, ວຽກທີ່ເກີດຂຶ້ນຊ້ຳໆ — ຈາກໜ້າ `/schedules`. |
| **ຄ່າເລີ່ມຕົ້ນການສະແດງຜົນທີ່ປັບແຕ່ງໄດ້** ([#48](https://github.com/ygncode/pi-web/issues/48)) | ຕັ້ງຄ່າການເບິ່ງເຫັນທີ່ຕ້ອງການສຳລັບການຄິດ (thinking), ເຄື່ອງມື (tools), ແລະ ຜົນລັບຂອງເຄື່ອງມື ໃນທຸກ sessions. |
| **Git diff** (ສ່ວນໜຶ່ງຂອງ [#47](https://github.com/ygncode/pi-web/issues/47)) | ເບິ່ງການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ commit ໃນ working-tree ຜ່ານ modal diff ຂອງ session, ພ້ອມກັບຄຳເຫັນທົບທວນ. |

## ວິໄສທັດ

ເປົ້າໝາຍໄລຍະຍາວ: pi-web ຄວນເປັນ **ສ່ວນຕິດຕໍ່ (interface) ຂອງ pi** — ສຳລັບທຸກຄົນ.

- **ຜູ້ບໍ່ແມ່ນ dev** ເປີດມັນຄືກັບແອັບອື່ນໆ. ເລືອກ model. ພິມ. ຈົບ. ບໍ່ຕ້ອງໃຊ້ command line ເລີຍ.
- **Devs** ໄດ້ຮັບການຜະສົມຜະສານທີ່ເລິກເຊິ່ງ — ການສົ່ງຕໍ່ໄລຍະໄກ, dashboards ຫຼາຍ sessions, ການເບິ່ງທີ່ຮັບຮູ້ git, bots ສົ່ງຂໍ້ຄວາມ.
- **ທຸກຄົນ** ໄດ້ຮັບເສລີພາບໃນການເລືອກ model, ຄວາມໂປ່ງໃສແບບ open-source, ແລະ UI ທີ່ຮູ້ສຶກຄິດຮອບຄອບໃນທຸກຈຸດ.
