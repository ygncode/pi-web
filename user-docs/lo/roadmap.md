# ແຜນທີ່ນຳທາງ

pi-web ຖືກສ້າງຂຶ້ນສຳລັບສອງກຸ່ມຜູ້ໃຊ້:

- **ສຳລັບນັກພັດທະນາ** — ຜູ້ທີ່ເຮັດວຽກໃນ terminal ແຕ່ຕ້ອງການເຊດຊັນຕໍ່ເນື່ອງຈາກມືຖື, ສົ່ງຕໍ່ໄປຍັງເຊີບເວີຣ໌ທີ່ຢູ່ໄກ, ຫຼື ຕິດຕາມວຽກທີ່ໃຊ້ເວລາດົນຈາກທຸກທີ່.
- **ສຳລັບຜູ້ໃຊ້ທົ່ວໄປ** — ຜູ້ທີ່ຕ້ອງການແອັບ AI ທີ່ສວຍງາມ ແລະ ໃຊ້ງານໄດ້. ເປີດ, ພິມ, ສະບາຍ. ບໍ່ມີ terminal, ບໍ່ມີ SSH, ບໍ່ມີຄວາມສັບສົນ. ຄືກັບເຄື່ອງມື AI ທີ່ເປັນມິດກັບຜູ້ໃຊ້ທີ່ສຸດ, ແຕ່ມີຕົວເລືອກໂມເດວ ແລະ ອິດສະລະແບບໂອເພນຊອດ.

ນີ້ແມ່ນສິ່ງທີ່ກຳລັງຈະມາ.

## ວິໄສທັດ

ເປົ້າໝາຍໄລຍະຍາວ: pi-web ຄວນເປັນ **ອິນເຕີເຟດສຳລັບ pi** — ສຳລັບທຸກຄົນ.

- **ຜູ້ໃຊ້ທົ່ວໄປ** ເປີດມັນຄືກັບແອັບອື່ນໆ. ເລືອກໂມເດວ. ພິມ. ສຳເລັດ. ບໍ່ມີ command line ເລີຍ.
- **ນັກພັດທະນາ** ໄດ້ຮັບການເຊື່ອມໂຍງຢ່າງເລິກເຊິ່ງ — ສົ່ງຕໍ່ໄລຍະໄກ, ແດສບອດຫຼາຍເຊດຊັນ, ການສຳຫຼວດທີ່ຮູ້ຈັກ git, ບັອດສົ່ງຂໍ້ຄວາມ.
- **ທຸກຄົນ** ໄດ້ຮັບອິດສະລະໃນການເລືອກໂມເດວ, ຄວາມໂປ່ງໃສແບບໂອເພນຊອດ, ແລະ UI ທີ່ຮູ້ສຶກຄິດມາເປັນຢ່າງດີໃນທຸກຈຸດ.
