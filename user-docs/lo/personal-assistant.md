# pi-web ເປັນຜູ້ຊ່ວຍສ່ວນຕົວຂອງທ່ານ

pi-web ບໍ່ແມ່ນພຽງແຕ່ສຳລັບການຂຽນໂຄ້ດເທົ່ານັ້ນ — ທ່ານສາມາດປ່ຽນມັນໃຫ້ເປັນ **ຜູ້ຊ່ວຍ AI ສ່ວນຕົວ** ທີ່ອາໄສຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ, ຄືກັບມີ OpenClaw ຫຼື Hermes ຂອງທ່ານເອງ.

## ວິທີການເຮັດວຽກ

ທ່ານສ້າງໂຟນເດີທີ່ອຸທິດຕົນໃສ່ເຄື່ອງຂອງທ່ານ — ນັ້ນຄືບ່ອນທີ່ຜູ້ຊ່ວຍຂອງທ່ານອາໄສຢູ່. ພາຍໃນ, ທ່ານໃສ່ໄຟລ໌ `APPEND_SYSTEM.md` ທີ່ກຳນົດວ່າຜູ້ຊ່ວຍຂອງທ່ານແມ່ນໃຜ, ຮູ້ຫຍັງແດ່, ແລະ ປະພຶດຕົວແນວໃດ. pi-web ມອບອິນເຕີເຟດສົນທະນາທີ່ສວຍງາມໃຫ້ທ່ານສົນທະນາຈາກອຸປະກອນໃດກໍໄດ້.

## ຂັ້ນຕອນ

### 1. ສ້າງໂຟນເດີຜູ້ຊ່ວຍຂອງທ່ານ

ເລືອກໂຟນເດີໃນຄອມພິວເຕີຂອງທ່ານ. ບາງຢ່າງເຊັ່ນ:

```
~/my-assistant/
```

### 2. ກຳນົດຜູ້ຊ່ວຍຂອງທ່ານ

ສ້າງໄຟລ໌ `APPEND_SYSTEM.md` ພາຍໃນໂຟນເດີນັ້ນ. ນີ້ແມ່ນບ່ອນທີ່ທ່ານບອກ pi ວ່າຜູ້ຊ່ວຍຂອງທ່ານແມ່ນໃຜ:

```markdown
# ຜູ້ຊ່ວຍສ່ວນຕົວຂອງຂ້ອຍ

ເຈົ້າແມ່ນ Jarvis, ຜູ້ຊ່ວຍ AI ສ່ວນຕົວຂອງຂ້ອຍ. ເຈົ້າຊ່ວຍຂ້ອຍກັບ:

- ການວາງແຜນປະຈຳວັນ ແລະ ການເຕືອນ
- ການຄົ້ນຄວ້າ ແລະ ສະຫຼຸບ
- ການຮ່າງອີເມລ ແລະ ຂໍ້ຄວາມ
- ການລະດົມຄວາມຄິດ
- ຕິດຕາມສິ່ງທີ່ຂ້ອຍເວົ້າເຖິງ

## ກ່ຽວກັບຂ້ອຍ

- ຂ້ອຍເປັນວິສະວະກອນຊອບແວທີ່ເຮັດວຽກທາງໄກ
- ຂ້ອຍມີແມວຊື່ Pixel
- ຂ້ອຍມັກຄຳຕອບທີ່ສັ້ນ ແລະ ກົງໄປກົງມາ
- ເຂດເວລາຂອງຂ້ອຍແມ່ນ PST

## ກົດລະບຽບ

- ກະທັດຮັດ — ຂ້ອຍໃຫ້ຄຸນຄ່າກັບຄວາມສັ້ນກະທັດຮັດ
- ຖ້າເຈົ້າບໍ່ຮູ້ບາງສິ່ງ, ບອກເລີຍ
- ເຕືອນຂ້ອຍລ່ວງໜ້າກ່ຽວກັບສິ່ງທີ່ຂ້ອຍຂໍໃຫ້ຕິດຕາມ
```

pi ຈະເພີ່ມສິ່ງນີ້ໃສ່ system prompt ຂອງທຸກໆການສົນທະນາໂດຍອັດຕະໂນມັດ, ດັ່ງນັ້ນຜູ້ຊ່ວຍຂອງທ່ານຈະຮູ້ສະເໝີວ່າທ່ານແມ່ນໃຜ ແລະ ຊ່ວຍແນວໃດ.

### 3. ເລີ່ມ session ໃນໂຟນເດີນັ້ນ

ໃນ pi-web, ສ້າງ session ໃໝ່ທີ່ຊີ້ໄປທີ່ `~/my-assistant/` (ຫຼືຊື່ໃດກໍຕາມທີ່ທ່ານຕັ້ງ). ແຄ່ນັ້ນ — ທ່ານກຳລັງລົມກັບຜູ້ຊ່ວຍສ່ວນຕົວຂອງທ່ານແລ້ວ.

### 4. ໃຊ້ຈາກທຸກທີ່

ຕິດຕັ້ງ pi-web ເປັນ PWA ໃນໂທລະສັບ, ແທັບເລັດ, ຫຼື ແລັບທັອບຂອງທ່ານ. ຜູ້ຊ່ວຍຂອງທ່ານຢູ່ທີ່ນັ້ນສະເໝີ — ຖາມມັນທຸກຢ່າງ, ທຸກເວລາ.

## ແນວຄວາມຄິດສຳລັບຜູ້ຊ່ວຍຂອງທ່ານ

| ບົດບາດ | ສິ່ງທີ່ຄວນໃສ່ໃນ APPEND_SYSTEM.md |
|---|---|
| 🧠 **ໂຄ້ຊຊີວິດ** | ເປົ້າໝາຍຂອງທ່ານ, ນິໄສທີ່ກຳລັງຝຶກ, ຄຳແນະນຳການຂຽນບັນທຶກ |
| 🏠 **ຜູ້ຈັດການບ້ານ** | ຮູບແບບລາຍການຊື້ເຄື່ອງ, ຄວາມມັກຂອງສະມາຊິກຄອບຄົວ, ການວາງແຜນອາຫານ |
| 💼 **ເພື່ອນຮ່ວມງານ** | ບົດບາດຂອງທ່ານ, ໂຄງການປັດຈຸບັນ, ຮູບແບບບັນທຶກການປະຊຸມ, ບໍລິບົດບໍລິສັດ |
| 📚 **ຄູ່ຮຽນ** | ສິ່ງທີ່ທ່ານກຳລັງຮຽນ, ຮູບແບບການອະທິບາຍທີ່ມັກ, ໂໝດທົດສອບ |
| ✍️ **ຜູ້ຊ່ວຍການຂຽນ** | ສະໄຕລ໌ການຂຽນຂອງທ່ານ, ຄວາມມັກດ້ານນ້ຳສຽງ, ຮູບແບບທົ່ວໄປທີ່ທ່ານໃຊ້ |

## ເພີ່ມບໍລິບົດເພີ່ມເຕີມ

ທ່ານສາມາດໃສ່ທຸກຢ່າງໃນໂຟນເດີຜູ້ຊ່ວຍຂອງທ່ານທີ່ຊ່ວຍໃຫ້ pi ມີປະໂຫຍດຫຼາຍຂຶ້ນ:

- `notes/` — ໄຟລ໌ອ້າງອີງທີ່ຜູ້ຊ່ວຍຂອງທ່ານສາມາດອ່ານໄດ້
- `context.md` — ຂໍ້ມູນພື້ນຖານກ່ຽວກັບຊີວິດ ຫຼື ວຽກຂອງທ່ານ
- `projects.md` — ໂຄງການປັດຈຸບັນ ແລະ ສະຖານະຂອງພວກມັນ

pi ສາມາດອ່ານໄຟລ໌ໃນໂຟນເດີ, ດັ່ງນັ້ນຍິ່ງທ່ານໃຫ້ບໍລິບົດຫຼາຍເທົ່າໃດ, ມັນກໍຍິ່ງດີຂຶ້ນເທົ່ານັ້ນ.
