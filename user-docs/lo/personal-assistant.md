# pi-web ເປັນຜູ້ຊ່ວຍສ່ວນຕົວຂອງທ່ານ

pi-web ບໍ່ໄດ້ມີໄວ້ສຳລັບການຂຽນໂຄ້ດເທົ່ານັ້ນ — ທ່ານສາມາດເຮັດໃຫ້ມັນກາຍເປັນ **ຜູ້ຊ່ວຍ AI ສ່ວນຕົວ** ທີ່ອາໄສຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ, ຄືກັບມີ OpenClaw ຫຼື Hermes ເປັນຂອງຕົວເອງ.

## ມັນເຮັດວຽກແນວໃດ

ທ່ານສ້າງໂຟນເດີສະເພາະໜຶ່ງຢູ່ໃນເຄື່ອງຂອງທ່ານ — ນັ້ນແມ່ນບ່ອນທີ່ຜູ້ຊ່ວຍຂອງທ່ານອາໄສຢູ່. ພາຍໃນ, ທ່ານໃສ່ໄຟລ໌ `APPEND_SYSTEM.md` ທີ່ກຳນົດວ່າຜູ້ຊ່ວຍຂອງທ່ານແມ່ນໃຜ, ມັນຮູ້ຫຍັງແດ່, ແລະ ມັນປະພຶດຕົວແນວໃດ. pi-web ມອບສ່ວນຕິດຕໍ່ສົນທະນາທີ່ສວຍງາມໃຫ້ທ່ານໄດ້ລົມກັບມັນຈາກອຸປະກອນໃດກໍໄດ້.

## ເທື່ອລະຂັ້ນຕອນ

### 1. ສ້າງໂຟນເດີຜູ້ຊ່ວຍຂອງທ່ານ

ເລືອກໂຟນເດີໜຶ່ງໃນຄອມພິວເຕີຂອງທ່ານ. ປະມານນີ້:

```
~/my-assistant/
```

### 2. ກຳນົດຜູ້ຊ່ວຍຂອງທ່ານ

ສ້າງໄຟລ໌ `APPEND_SYSTEM.md` ພາຍໃນໂຟນເດີນັ້ນ. ນີ້ແມ່ນບ່ອນທີ່ທ່ານບອກ pi ວ່າຜູ້ຊ່ວຍຂອງທ່ານແມ່ນໃຜ:

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi ຈະເພີ່ມສິ່ງນີ້ເຂົ້າໃນ system prompt ຂອງທຸກໆການສົນທະນາໂດຍອັດຕະໂນມັດ, ດັ່ງນັ້ນຜູ້ຊ່ວຍຂອງທ່ານຈຶ່ງຮູ້ສະເໝີວ່າທ່ານແມ່ນໃຜ ແລະ ຈະຊ່ວຍແນວໃດ.

### 3. ເລີ່ມ session ໃນໂຟນເດີນັ້ນ

ໃນ pi-web, ສ້າງ session ໃໝ່ທີ່ຊີ້ໄປທີ່ `~/my-assistant/` (ຫຼືຊື່ໃດກໍຕາມທີ່ທ່ານຕັ້ງ). ພຽງເທົ່ານີ້ — ທ່ານກໍກຳລັງລົມກັບຜູ້ຊ່ວຍສ່ວນຕົວຂອງທ່ານແລ້ວ.

### 4. ໃຊ້ມັນຈາກທຸກບ່ອນ

ຕິດຕັ້ງ pi-web ເປັນ PWA ໃນໂທລະສັບ, ແທັບເລັດ, ຫຼື ແລັບທັອບຂອງທ່ານ. ຜູ້ຊ່ວຍຂອງທ່ານຈະຢູ່ທີ່ນັ້ນສະເໝີ — ຖາມມັນໄດ້ທຸກເລື່ອງ, ທຸກເວລາ.

## ແນວຄວາມຄິດສຳລັບຜູ້ຊ່ວຍຂອງທ່ານ

| ບົດບາດ | ສິ່ງທີ່ຄວນໃສ່ໃນ APPEND_SYSTEM.md |
|---|---|
| 🧠 **ໂຄ້ຊຊີວິດ** | ເປົ້າໝາຍຂອງທ່ານ, ນິໄສທີ່ທ່ານກຳລັງຝຶກ, ຄຳແນະນຳການຂຽນບັນທຶກປະຈຳວັນ |
| 🏠 **ຜູ້ຈັດການບ້ານ** | ຮູບແບບລາຍການຊື້ເຄື່ອງ, ຄວາມມັກຂອງສະມາຊິກໃນຄອບຄົວ, ການວາງແຜນອາຫານ |
| 💼 **ຄູ່ຫູເຮັດວຽກ** | ບົດບາດຂອງທ່ານ, ໂຄງການປັດຈຸບັນ, ຮູບແບບບັນທຶກການປະຊຸມ, ບໍລິບົດຂອງບໍລິສັດ |
| 📚 **ຄູ່ຮ່ວມຮຽນ** | ສິ່ງທີ່ທ່ານກຳລັງຮຽນ, ຮູບແບບການອະທິບາຍທີ່ມັກ, ໂໝດຖາມຄຳຖາມໃຫ້ຕອບ |
| ✍️ **ຜູ້ຊ່ວຍຂຽນ** | ສະໄຕລ໌ການຂຽນຂອງທ່ານ, ຄວາມມັກດ້ານໂທນສຽງ, ຮູບແບບທົ່ວໄປທີ່ທ່ານໃຊ້ |

## ເພີ່ມບໍລິບົດຕື່ມ

ທ່ານສາມາດໃສ່ຫຍັງກໍໄດ້ໃນໂຟນເດີຜູ້ຊ່ວຍຂອງທ່ານທີ່ຊ່ວຍໃຫ້ pi ມີປະໂຫຍດຫຼາຍຂຶ້ນ:

- `notes/` — ໄຟລ໌ອ້າງອີງທີ່ຜູ້ຊ່ວຍຂອງທ່ານສາມາດອ່ານໄດ້
- `context.md` — ຂໍ້ມູນພື້ນຖານກ່ຽວກັບຊີວິດ ຫຼື ວຽກຂອງທ່ານ
- `projects.md` — ໂຄງການປັດຈຸບັນ ແລະ ສະຖານະຂອງພວກມັນ

pi ສາມາດອ່ານໄຟລ໌ໃນໂຟນເດີໄດ້, ດັ່ງນັ້ນຍິ່ງທ່ານໃຫ້ບໍລິບົດຫຼາຍເທົ່າໃດ, ມັນກໍຍິ່ງເກັ່ງຂຶ້ນເທົ່ານັ້ນ.

## ໃຫ້ pi-web ເຮັດສິ່ງຕ່າງໆ

ຫຼັງຈາກ `pi install npm:@ygncode/pi-web@beta`, sessions ສາມາດລົມກັບຕົວ pi-web ເອງໄດ້.
ລອງບອກວ່າ:

- "Add a schedule at 2am Singapore time to summarize my inbox"
- "List my pi-web schedules"
- "Pause the inbox schedule"
- "Write this down in the notes"
- "Switch pi-web to dark mode / turn auto-title off"

skill **/skill:pi-web-schedule** ທີ່ມາພ້ອມກັນ ປ່ຽນສິ່ງນັ້ນໃຫ້ກາຍເປັນ schedule
ຂອງ pi-web ແທ້ໆ (ອັນດຽວກັນກັບທີ່ທ່ານແກ້ໄຂຢູ່ `/schedules`). ທຸກຄັ້ງທີ່ມັນເຮັດວຽກຈະເລີ່ມ session
**ໃໝ່**, ດັ່ງນັ້ນຄຳສັ່ງຕ້ອງຢືນຢູ່ດ້ວຍຕົວມັນເອງ — "summarize unread mail in
~/inbox" ໃຊ້ໄດ້; "continue what we were doing" ໃຊ້ບໍ່ໄດ້.

Schedules ຈະເຮັດວຽກພຽງແຕ່ເມື່ອ pi-web ກຳລັງເຮັດວຽກຢູ່ເທົ່ານັ້ນ.
