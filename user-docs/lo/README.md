**ກຳລັງຄິດຢາກລອງໃຊ້ pi-web ບໍ? ລອງເລີຍ — ເຈົ້າຈະຫຼົງຮັກມັນ.**

pi-web ເປັນ web UI ແລະ PWA ທີ່ສວຍງາມສຳລັບ [pi](https://pi.dev) — AI coding agent ແບບ open source. ມັນຊ່ວຍໃຫ້ເຈົ້າເບິ່ງ, ອ່ານ ແລະ ສືບຕໍ່ session ຂອງ pi ຈາກ browser ໃດກໍໄດ້, ໃນອຸປະກອນໃດກໍໄດ້, ພ້ອມດ້ວຍຟີເຈີທີ່ຄິດມາຢ່າງດີໃນທຸກຈຸດ.

**pi-web ຖືກສ້າງຂຶ້ນສຳລັບຄົນສອງປະເພດ:**

- 🧑‍💻 **ສຳລັບນັກພັດທະນາ** — ຄົນທີ່ຢູ່ກັບ terminal ແຕ່ຢາກສືບຕໍ່ session ຈາກມືຖື, ສົ່ງຕໍ່ໄປຍັງ server ໄລຍະໄກ, ຫຼື ຕິດຕາມວຽກທີ່ແລ່ນດົນໆ ຈາກທຸກບ່ອນ.
- ✨ **ສຳລັບຄົນທີ່ບໍ່ແມ່ນນັກພັດທະນາ** — ຄົນທີ່ພຽງແຕ່ຢາກໄດ້ແອັບ AI ທີ່ສວຍງາມແລະໃຊ້ງານໄດ້. ເປີດມັນ, ພິມ, ຕາມສະບາຍ. ບໍ່ມີ terminal, ບໍ່ມີ SSH, ບໍ່ມີຄວາມສັບສົນ. ຄືກັບເຄື່ອງມື AI ທີ່ໃຊ້ງ່າຍທີ່ສຸດ, ແຕ່ມີທາງເລືອກ model ແລະ ອິດສະລະພາບແບບ open source.

## ເປັນຫຍັງຕ້ອງ pi-web?

ເຈົ້າກຳລັງຢູ່ໃນຈັງຫວະການເຮັດວຽກກັບ pi ໃນ terminal ຂອງເຈົ້າແລ້ວ. pi-web ຊ່ວຍໃຫ້ຈັງຫວະນັ້ນສືບຕໍ່ໄປເມື່ອເຈົ້າກ້າວອອກຈາກໂຕະ:

- **ສືບຕໍ່ຈາກທຸກບ່ອນ** — ສືບຕໍ່ session ຈາກໂທລະສັບ, ແທັບເລັດ, ຫຼື ຄອມພິວເຕີເຄື່ອງອື່ນ. ບໍ່ຕ້ອງ SSH, ບໍ່ຕ້ອງ Termius — ແຄ່ເປີດ browser ຂອງເຈົ້າ.
- **ໜ້າຈໍຫຼາຍ session** — ເລີ່ມວຽກໃນ session ໜຶ່ງ ໃນຂະນະທີ່ເບິ່ງອີກ session ໜຶ່ງ streaming. ຄົ້ນຫາຂ້າມ projects, ກັ່ນກອງຕາມ branch, ຊອກຫາສິ່ງທີ່ຕ້ອງການໄດ້ໄວ.
- **ພື້ນຖານ open source** — pi ເປັນ open source ເຕັມຮູບແບບ ແລະ ບໍ່ຂຶ້ນກັບ provider ໃດໜຶ່ງ. ເຈົ້າບໍ່ຖືກລັອກໄວ້ກັບ model ຫຼື vendor ດຽວ. pi-web ກໍເປັນ open source ຄືກັນ.
- **ການເຂົ້າເຖິງໄລຍະໄກທີ່ປອດໄພ** — ມີ token auth ໃນຕົວ ເພື່ອໃຫ້ເຈົ້າສາມາດເປີດເຜີຍມັນໃນ LAN ຫຼື Tailscale ໄດ້ໂດຍບໍ່ຕ້ອງກັງວົນ.
- **ແບ່ງປັນວຽກຂອງເຈົ້າ** — export session ເປັນ snapshot ແບບ static ຫຼື GitHub Gists ແບບລັບ ໄດ້ໃນຄລິກດຽວ.

## pi-web ເປັນ workspace AI ສ່ວນຕົວຂອງເຈົ້າ 🏠

pi-web ເປັນ PWA (Progressive Web App), ດັ່ງນັ້ນເຈົ້າສາມາດ **ຕິດຕັ້ງມັນຄືກັບແອັບພື້ນເມືອງ** ໃນ desktop, laptop, ໂທລະສັບ, ຫຼື ແທັບເລັດ — ບໍ່ຕ້ອງໃຊ້ app store. ໃນ desktop ມັນເປີດໃນ window ຂອງຕົວເອງໂດຍບໍ່ມີ browser chrome, ຈຶ່ງເບິ່ງແລະຮູ້ສຶກຄືກັບແອັບພລິເຄຊັນ desktop ແທ້ໆ.

ຄິດວ່າມັນເປັນ **Claude Cowork ຂອງເຈົ້າເອງ** — workspace AI ສ່ວນຕົວທີ່ຢູ່ໃນເຄື່ອງຂອງເຈົ້າ — ແຕ່ມັນເປັນ open source ແລະ ບໍ່ຂຶ້ນກັບ model ໃດໜຶ່ງ:

- **ເຈົ້າເປັນເຈົ້າຂອງ stack.** ເລືອກ model ໃດກໍໄດ້, ສະຫຼັບຕອນໃດກໍໄດ້. ແລ່ນ model ແບບ local ແລ້ວຂໍ້ມູນຂອງເຈົ້າຈະບໍ່ອອກຈາກເຄື່ອງຂອງເຈົ້າເລີຍ.
- **ຄົນທີ່ບໍ່ມີພື້ນຖານເຕັກນິກກໍໃຊ້ໄດ້.** ຕັ້ງ pi-web ໃນເຄື່ອງຂອງເຂົາເຈົ້າ, ສອນວິທີໃຊ້ເທື່ອດຽວ, ແລ້ວກໍໃຊ້ໄດ້ເລີຍ. ພໍ່ແມ່, ຄູ່ຮັກ, ໝູ່ທີ່ບໍ່ເກັ່ງເຕັກ — ບໍ່ມີ terminal, ບໍ່ມີ SSH, ແຄ່ມີ chat interface ທີ່ຄຸ້ນເຄີຍ.
- **ຕັ້ງເທື່ອດຽວ, ໃຊ້ໄດ້ຫຼາຍຄົນ.** ຕິດຕັ້ງໃນ desktop ຂອງເຈົ້າແລະແບ່ງໜ້າຈໍ, ຫຼື ເປີດເຜີຍໃນເຄືອຂ່າຍບ້ານ ແລະ ໃຫ້ສະມາຊິກຄອບຄົວເປີດໃນອຸປະກອນຂອງເຂົາເຈົ້າເອງ.

ຢາກໄດ້ຫຼາຍກວ່າການຂຽນໂຄດບໍ? ປ່ຽນມັນໃຫ້ເປັນ [ຜູ້ຊ່ວຍສ່ວນຕົວ](personal-assistant.md) ທີ່ຮູ້ຈັກເຈົ້າ ແລະ ຢູ່ໃນເຄື່ອງຂອງເຈົ້າ — ຄືກັບ OpenClaw ຫຼື Hermes ຂອງເຈົ້າເອງ.

> 💡 **ເຄັດລັບ:** ຕິດຕັ້ງ pi-web ເປັນ PWA ຈາກ Chrome/Edge (ຄລິກໄອຄອນຕິດຕັ້ງໃນແຖບທີ່ຢູ່) ຫຼື Safari (Share → Add to Dock). ມັນຈະກາຍເປັນສິ່ງທີ່ແຍກບໍ່ອອກຈາກແອັບພື້ນເມືອງ.
