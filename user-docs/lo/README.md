**ກຳລັງຄິດຢາກລອງໃຊ້ pi-web ບໍ? ລອງເລີຍ — ເຈົ້າຈະຕົກຫລຸມຮັກມັນແນ່ນອນ.**

pi-web ແມ່ນ UI ເວັບທີ່ສວຍງາມ ແລະ PWA ສຳລັບ [pi](https://pi.dev) — ໂປຣແກຣມ AI ຊ່ວຍຂຽນໂຄ້ດແບບ open-source. ມັນຊ່ວຍໃຫ້ເຈົ້າສາມາດເບິ່ງ, ອ່ານ, ແລະ ສືບຕໍ່ session pi ຂອງເຈົ້າໄດ້ຈາກທຸກ browser, ໃນທຸກອຸປະກອນ, ພ້ອມດ້ວຍຟີເຈີທີ່ຄິດມາໃຫ້ຢ່າງດີໃນທຸກຈຸດ.

**pi-web ຖືກສ້າງຂຶ້ນສຳລັບຄົນສອງປະເພດ:**

- 🧑‍💻 **ສຳລັບນັກພັດທະນາ** — ຜູ້ທີ່ໃຊ້ຊີວິດຢູ່ໃນ terminal ແຕ່ຢາກສືບຕໍ່ session ຈາກມືຖື, ສົ່ງຕໍ່ໄປຍັງ server ໄລຍະໄກ, ຫຼື ຕິດຕາມວຽກທີ່ເຮັດດົນໆໄດ້ຈາກທຸກບ່ອນ.
- ✨ **ສຳລັບຜູ້ທີ່ບໍ່ແມ່ນນັກພັດທະນາ** — ຜູ້ທີ່ພຽງແຕ່ຢາກໄດ້ແອັບ AI ທີ່ສວຍງາມທີ່ໃຊ້ງານໄດ້. ເປີດມັນ, ພິມ, ລື່ນໄຫຼ. ບໍ່ມີ terminal, ບໍ່ມີ SSH, ບໍ່ສັບສົນ. ຄືກັບເຄື່ອງມື AI ທີ່ໃຊ້ງ່າຍທີ່ສຸດ, ແຕ່ມີທາງເລືອກໂມເດວ ແລະ ອິດສະລະພາບແບບ open-source.

## ເປັນຫຍັງຕ້ອງ pi-web?

ເຈົ້າກຳລັງລື່ນໄຫຼກັບ pi ຢູ່ໃນ terminal ຂອງເຈົ້າຢູ່ແລ້ວ. pi-web ຊ່ວຍຮັກສາຈັງຫວະນັ້ນໄວ້ຕອນທີ່ເຈົ້າຍ່າງອອກຈາກໂຕະ:

- **ສືບຕໍ່ໄດ້ຈາກທຸກບ່ອນ** — ສືບຕໍ່ session ຈາກໂທລະສັບ, ແທັບເລັດ, ຫຼື ຄອມພິວເຕີເຄື່ອງອື່ນ. ບໍ່ຕ້ອງ SSH, ບໍ່ຕ້ອງ Termius — ພຽງແຕ່ເປີດ browser ຂອງເຈົ້າ.
- **ໜ້າປັດຫລາຍ session** — ເລີ່ມວຽກໃນ session ໜຶ່ງ ພ້ອມກັບເບິ່ງອີກ session ໜຶ່ງທີ່ກຳລັງ stream ຢູ່. ຄົ້ນຫາຂ້າມໂປຣເຈັກ, ກັ່ນຕອງຕາມ branch, ຊອກຫາສິ່ງທີ່ຕ້ອງການໄດ້ໄວ.
- **ພື້ນຖານ open-source** — pi ແມ່ນ open-source ເຕັມຮູບແບບ ແລະ ບໍ່ຂຶ້ນກັບ provider ໃດໜຶ່ງ. ເຈົ້າບໍ່ຖືກລັອກໃສ່ໂມເດວດຽວ ຫຼື ຜູ້ຂາຍດຽວ. pi-web ກໍ່ເປັນ open-source ເຊັ່ນກັນ.
- **ການເຂົ້າເຖິງທາງໄກທີ່ປອດໄພ** — ມີ token auth ໃນຕົວ ເພື່ອໃຫ້ເຈົ້າສາມາດເປີດເຜີຍມັນຢູ່ໃນ LAN ຫຼື Tailscale ຂອງເຈົ້າໄດ້ໂດຍບໍ່ຕ້ອງກັງວົນ.
- **ແບ່ງປັນວຽກຂອງເຈົ້າ** — export session ເປັນ snapshot ແບບ static ຫຼື GitHub Gist ແບບລັບໄດ້ໃນຄລິກດຽວ.

## pi-web ເປັນພື້ນທີ່ເຮັດວຽກ AI ສ່ວນຕົວຂອງເຈົ້າ 🏠

pi-web ແມ່ນ PWA (Progressive Web App), ດັ່ງນັ້ນເຈົ້າສາມາດ **ຕິດຕັ້ງມັນຄືກັບແອັບ native** ໃນ desktop, ແລັບທັອບ, ໂທລະສັບ, ຫຼື ແທັບເລັດຂອງເຈົ້າ — ບໍ່ຕ້ອງໃຊ້ app store. ໃນ desktop ມັນເປີດຢູ່ໃນໜ້າຕ່າງຂອງຕົວມັນເອງ ບໍ່ມີ chrome ຂອງ browser, ດັ່ງນັ້ນມັນເບິ່ງ ແລະ ຮູ້ສຶກຄືກັບແອັບ desktop ແທ້ໆ.

ຄິດວ່າມັນເປັນ **Claude Cowork ຂອງເຈົ້າເອງ** — ພື້ນທີ່ເຮັດວຽກ AI ສ່ວນຕົວທີ່ຢູ່ໃນເຄື່ອງຂອງເຈົ້າ — ແຕ່ມັນເປັນ open-source ແລະ ບໍ່ຂຶ້ນກັບໂມເດວໃດໜຶ່ງ:

- **ເຈົ້າເປັນເຈົ້າຂອງ stack.** ເລືອກໂມເດວໃດກໍ່ໄດ້, ປ່ຽນໄດ້ຕະຫລອດເວລາ. ລັນແບບ local ແລະ ຂໍ້ມູນຂອງເຈົ້າຈະບໍ່ອອກຈາກເຄື່ອງຂອງເຈົ້າເລີຍ.
- **ຄົນທີ່ບໍ່ມີຄວາມຮູ້ດ້ານເຕັກນິກກໍ່ໃຊ້ໄດ້.** ຕັ້ງ pi-web ໃສ່ເຄື່ອງຂອງພວກເຂົາ, ສອນວິທີໃຊ້ໃຫ້ເທື່ອດຽວ, ແລ້ວພວກເຂົາກໍ່ໃຊ້ໄດ້ເລີຍ. ພໍ່ແມ່ຂອງເຈົ້າ, ຄູ່ຮັກຂອງເຈົ້າ, ໝູ່ທີ່ບໍ່ຊ່ຽວຊານດ້ານເຕັກ — ບໍ່ມີ terminal, ບໍ່ມີ SSH, ພຽງແຕ່ໜ້າຕ່າງແຊັດທີ່ຄຸ້ນເຄີຍ.
- **ຕິດຕັ້ງເທື່ອດຽວ, ຫລາຍຄົນໃຊ້.** ຕິດຕັ້ງມັນໃນ desktop ຂອງເຈົ້າ ແລະ ແຊຣ໌ໜ້າຈໍ, ຫຼື ເປີດເຜີຍມັນໃນເຄືອຂ່າຍບ້ານຂອງເຈົ້າ ແລະ ໃຫ້ສະມາຊິກໃນຄອບຄົວເປີດມັນໃນອຸປະກອນຂອງພວກເຂົາເອງ.

ຢາກໄດ້ຫລາຍກວ່າການຂຽນໂຄ້ດບໍ? ປ່ຽນມັນໃຫ້ເປັນ [ຜູ້ຊ່ວຍສ່ວນຕົວ](personal-assistant.md) ແບບສະເພາະທີ່ຮູ້ຈັກວ່າເຈົ້າແມ່ນໃຜ ແລະ ຢູ່ໃນເຄື່ອງຂອງເຈົ້າ — ຄືກັບ OpenClaw ຫຼື Hermes ຂອງເຈົ້າເອງ.

> 💡 **ເຄັດລັບມືອາຊີບ:** ຕິດຕັ້ງ pi-web ເປັນ PWA ຈາກ Chrome/Edge (ກົດໄອຄອນຕິດຕັ້ງໃນແຖບທີ່ຢູ່) ຫຼື Safari (Share → Add to Dock). ມັນຈະບໍ່ສາມາດແຍກອອກຈາກແອັບ native ໄດ້ເລີຍ.
