# ທາງລັດແປ້ນພິມ

## ໜ້າຫຼັກ (`/`)

### ການເລື່ອນໜ້າ (ແບບ vim)

ທາງລັດແບບ vim ດຽວກັນໃຊ້ໄດ້ໃນທຸກໜ້າ ເມື່ອໂຟກັສ **ບໍ່ໄດ້** ຢູ່ໃນ input, textarea, ຫຼື contenteditable element.

| ທາງລັດ | ການກະທຳ |
|----------|--------|
| `j` | ເລື່ອນລົງ 300px |
| `k` | ເລື່ອນຂຶ້ນ 300px |
| `g g` | ເລື່ອນໄປເທິງສຸດຂອງໜ້າ |
| `G` (Shift+G) | ເລື່ອນໄປລຸ່ມສຸດຂອງໜ້າ |
| `Escape` | ເອົາໂຟກັສອອກຈາກ input ທີ່ໃຊ້ງານຢູ່ ເພື່ອໃຫ້ການນຳທາງ j/k ໃຊ້ໄດ້ |

### ຄຳສັ່ງຂອງໜ້າຫຼັກ

| ທາງລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | ລະດັບໜ້າ | ເປີດ palette ຄົ້ນຫາ/ເຊດຊັນ |
| `⌘,` / `Ctrl+,` | ລະດັບໜ້າ | ເປີດການຕັ້ງຄ່າ |
| `⌘⇧L` / `Ctrl+Shift+L` | ລະດັບໜ້າ | ສະຫຼັບຮູບແບບລະບົບ (ສະຫວ່າງ/ມືດ) |
| `Escape` | ລະດັບໜ້າ | ປິດ palette, ເມນູ, ຫຼື modal |
| `Enter` | input ເສັ້ນທາງເຊດຊັນໃໝ່ | ສ້າງເຊດຊັນໃໝ່ |

> `⌘K` / `Ctrl+K` ຍັງເປັນທາງລັດ "ໂຟກັສແຖບທີ່ຢູ່" ຂອງ Chrome ນຳອີກ. ບຣາວເຊີອາດດັກຈັບມັນໄດ້ ເວັ້ນເສຍແຕ່ໂຟກັສຢູ່ໃນ text input.

## ໜ້າລາຍລະອຽດເຊດຊັນ (`/session?id=...`)

### ການເລື່ອນໜ້າ (ແບບ vim)

ສິ່ງເຫຼົ່ານີ້ໃຊ້ໄດ້ທັງໜ້າຫຼັກ ແລະ ໜ້າເຊດຊັນ ເມື່ອໂຟກັສ **ບໍ່ໄດ້** ຢູ່ໃນ input, textarea, ຫຼື contenteditable element.

| ທາງລັດ | ການກະທຳ |
|----------|--------|
| `j` | ເລື່ອນລົງ 300px |
| `k` | ເລື່ອນຂຶ້ນ 300px |
| `g g` | ເລື່ອນໄປເທິງສຸດຂອງໜ້າ |
| `G` (Shift+G) | ເລື່ອນໄປລຸ່ມສຸດຂອງໜ້າ |
| `I` (Shift+I) | ໂຟກັສ textarea ຂອງຊ່ອງພິມແຊັດ |
| `Escape` | ເອົາໂຟກັສອອກຈາກ input ທີ່ໃຊ້ງານຢູ່ ເພື່ອໃຫ້ການນຳທາງ j/k ໃຊ້ໄດ້ |

### ແຖບຂ້າງ ແລະ ການນຳທາງ

| ທາງລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | ລະດັບໜ້າ | ສະຫຼັບການສະແດງແຖບຂ້າງ |
| `⌘K` / `Ctrl+K` | ລະດັບໜ້າ | ເປີດ palette ລາຍຊື່ເຊດຊັນ |
| `⌘T` / `Ctrl+T` | ລະດັບໜ້າ | ເຊດຊັນໃໝ່ |
| `⌘/` / `Ctrl+/` | ລະດັບໜ້າ | ສະແດງ modal ທາງລັດແປ້ນພິມ |
| `⌘,` / `Ctrl+,` | ລະດັບໜ້າ | ເປີດການຕັ້ງຄ່າ |
| `⌘⇧L` / `Ctrl+Shift+L` | ລະດັບໜ້າ | ສະຫຼັບຮູບແບບລະບົບ (ສະຫວ່າງ/ມືດ) |
| `⌘⇧N` / `Ctrl+Shift+N` | ລະດັບໜ້າ | ສະຫຼັບແຖບຂ້າງ scratchpad / ບັນທຶກ |

> `⌘K` ແລະ `⌘T` ຍັງເປັນທາງລັດຂອງບຣາວເຊີ (ໂຟກັສແຖບທີ່ຢູ່ / ແທັບໃໝ່). ບຣາວເຊີອາດດັກຈັບພວກມັນໄດ້ ເວັ້ນເສຍແຕ່ໂຟກັສຢູ່ໃນ text input.

### ຊ່ອງພິມແຊັດ

| ທາງລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `Enter` | textarea ແຊັດ | ສົ່ງຂໍ້ຄວາມ |
| `Shift+Enter` | textarea ແຊັດ | ໃສ່ບັນທັດໃໝ່ |
| `Shift+Tab` | textarea ແຊັດ | ວຽນໄປລະດັບການຄິດຖັດໄປ (`off` → `minimal` → … → `xhigh` → `off`) |
| `Ctrl+I` / `Ctrl+L` | textarea ແຊັດ | ເປີດ popup ເລືອກໂມເດວ (ພິມເພື່ອກັ່ນຕອງ, Enter ເພື່ອເລືອກ, ໂຟກັສກັບໄປ textarea) |

### ການສະຫຼັບການສະແດງຂອງ entry

| ທາງລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `t` | ເມື່ອໂຟກັສ **ບໍ່ໄດ້** ຢູ່ໃນ input/textarea | ສະຫຼັບການສະແດງການຄິດ |
| `o` | ເມື່ອໂຟກັສ **ບໍ່ໄດ້** ຢູ່ໃນ input/textarea | ສະຫຼັບການສະແດງເຄື່ອງມື |
| `p` | ເມື່ອໂຟກັສ **ບໍ່ໄດ້** ຢູ່ໃນ input/textarea | ສະຫຼັບຜົນລັບຂອງເຄື່ອງມື |

### Palette, ເມນູ ແລະ sheet

| ທາງລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `Escape` | ລະດັບໜ້າ | ປິດ palette, ເມນູ, ຫຼື sheet ທີ່ເປີດຢູ່ |
| `⌘K` / `Ctrl+K` | ລະດັບໜ້າ | ເປີດ palette ລາຍຊື່ເຊດຊັນ |
| `ArrowUp` / `ArrowDown` | palette ລາຍຊື່ເຊດຊັນ | ນຳທາງຜົນການຄົ້ນຫາເຊດຊັນ |
| `Enter` | palette ລາຍຊື່ເຊດຊັນ | ເປີດເຊດຊັນທີ່ເລືອກໄວ້ (ຫຼື ອັນທຳອິດ) |
| `ArrowUp` / `ArrowDown` | popup ເລືອກໂມເດວ | ນຳທາງລາຍຊື່ໂມເດວ |
| `Enter` | popup ເລືອກໂມເດວ | ເລືອກໂມເດວທີ່ເນັ້ນໄວ້ |
| `ArrowUp` / `ArrowDown` | modal Fork | ນຳທາງຂໍ້ຄວາມ |
| `Enter` | modal Fork | Fork ຈາກຂໍ້ຄວາມທີ່ເນັ້ນໄວ້ |
| `Tab` | sheet ເຕັມຈໍ | ວຽນໂຟກັສພາຍໃນ sheet |
| `Escape` | sheet ເຕັມຈໍ | ປິດ sheet |
