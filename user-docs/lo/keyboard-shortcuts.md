# ປຸ່ມລັດແປ້ນພິມ

## ໜ້າດັດສະນີ (`/`)

### ການເລື່ອນໜ້າ (ແບບ vim)

ປຸ່ມລັດແບບ vim ດຽວກັນນີ້ໃຊ້ງານໄດ້ທຸກໜ້າ ເມື່ອໂຟກັສ **ບໍ່** ຢູ່ໃນຊ່ອງປ້ອນຂໍ້ມູນ, ພື້ນທີ່ຂໍ້ຄວາມ, ຫຼື ອົງປະກອບ contenteditable.

| ປຸ່ມລັດ | ການກະທຳ |
|----------|--------|
| `j` | ເລື່ອນລົງ 300px |
| `k` | ເລື່ອນຂຶ້ນ 300px |
| `g g` | ເລື່ອນໄປເທິງສຸດຂອງໜ້າ |
| `G` (Shift+G) | ເລື່ອນໄປລຸ່ມສຸດຂອງໜ້າ |
| `Escape` | ຍົກເລີກໂຟກັສຈາກຊ່ອງປ້ອນຂໍ້ມູນທີ່ເປີດຢູ່ ເພື່ອໃຫ້ການນຳທາງ j/k ເຮັດວຽກໄດ້ |

### ຄຳສັ່ງໜ້າດັດສະນີ

| ປຸ່ມລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | ລະດັບໜ້າ | ເປີດພາເລັດຄົ້ນຫາ/ເຊດຊັນ |
| `⌘⇧L` / `Ctrl+Shift+L` | ລະດັບໜ້າ | ສະຫຼັບຮູບແບບລະບົບ (ສະຫວ່າງ/ມືດ) |
| `Escape` | ລະດັບໜ້າ | ປິດພາເລັດ, ເມນູ, ຫຼື ໂມດອນ |
| `Enter` | ຊ່ອງປ້ອນເສັ້ນທາງສຳລັບເຊດຊັນໃໝ່ | ສ້າງເຊດຊັນໃໝ່ |

> `⌘K` / `Ctrl+K` ຍັງເປັນປຸ່ມລັດ "ໂຟກັສແຖບທີ່ຢູ່" ຂອງ Chrome. ເບຣົາເຊີອາດຈະດັກຈັບມັນໄວ້ ນອກຈາກວ່າໂຟກັສຈະຢູ່ໃນຊ່ອງປ້ອນຂໍ້ມູນ.

## ໜ້າລາຍລະອຽດເຊດຊັນ (`/session?id=...`)

### ການເລື່ອນໜ້າ (ແບບ vim)

ສິ່ງເຫຼົ່ານີ້ໃຊ້ງານໄດ້ທັງໜ້າດັດສະນີ ແລະ ໜ້າເຊດຊັນ ເມື່ອໂຟກັສ **ບໍ່** ຢູ່ໃນຊ່ອງປ້ອນຂໍ້ມູນ, ພື້ນທີ່ຂໍ້ຄວາມ, ຫຼື ອົງປະກອບ contenteditable.

| ປຸ່ມລັດ | ການກະທຳ |
|----------|--------|
| `j` | ເລື່ອນລົງ 300px |
| `k` | ເລື່ອນຂຶ້ນ 300px |
| `g g` | ເລື່ອນໄປເທິງສຸດຂອງໜ້າ |
| `G` (Shift+G) | ເລື່ອນໄປລຸ່ມສຸດຂອງໜ້າ |
| `I` (Shift+I) | ໂຟກັສພື້ນທີ່ຂໍ້ຄວາມຂຽນແຊັດ |
| `Escape` | ຍົກເລີກໂຟກັສຈາກຊ່ອງປ້ອນຂໍ້ມູນທີ່ເປີດຢູ່ ເພື່ອໃຫ້ການນຳທາງ j/k ເຮັດວຽກໄດ້ |

### ແຖບຂ້າງ ແລະ ການນຳທາງ

| ປຸ່ມລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | ລະດັບໜ້າ | ສະຫຼັບການເບິ່ງເຫັນແຖບຂ້າງ |
| `⌘K` / `Ctrl+K` | ລະດັບໜ້າ | ເປີດພາເລັດລາຍການເຊດຊັນ |
| `⌘T` / `Ctrl+T` | ລະດັບໜ້າ | ເຊດຊັນໃໝ່ |
| `⌘⇧L` / `Ctrl+Shift+L` | ລະດັບໜ້າ | ສະຫຼັບຮູບແບບລະບົບ (ສະຫວ່າງ/ມືດ) |
| `⌘⇧N` / `Ctrl+Shift+N` | ລະດັບໜ້າ | ສະຫຼັບແຖບຂ້າງບັນທຶກສ່ວນຕົວ / ໝາຍເຫດ |

> `⌘K` ແລະ `⌘T` ຍັງເປັນປຸ່ມລັດຂອງເບຣົາເຊີ (ໂຟກັສແຖບທີ່ຢູ່ / ແທັບໃໝ່). ເບຣົາເຊີອາດຈະດັກຈັບມັນໄວ້ ນອກຈາກວ່າໂຟກັສຈະຢູ່ໃນຊ່ອງປ້ອນຂໍ້ມູນ.

### ຕົວຂຽນແຊັດ

| ປຸ່ມລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `Enter` | ພື້ນທີ່ຂໍ້ຄວາມແຊັດ | ສົ່ງຂໍ້ຄວາມ |
| `Shift+Enter` | ພື້ນທີ່ຂໍ້ຄວາມແຊັດ | ແຊກຂຶ້ນແຖວໃໝ່ |
| `Shift+Tab` | ພື້ນທີ່ຂໍ້ຄວາມແຊັດ | ວຽນໄປລະດັບການຄິດຖັດໄປ (`off` → `minimal` → … → `xhigh` → `off`) |
| `Ctrl+I` / `Ctrl+L` | ພື້ນທີ່ຂໍ້ຄວາມແຊັດ | ເປີດປ໋ອບອັບເລືອກໂມເດວ (ພິມເພື່ອກັ່ນຕອງ, Enter ເພື່ອເລືອກ, ໂຟກັສຈະກັບຄືນໄປພື້ນທີ່ຂໍ້ຄວາມ) |

### ປຸ່ມສະຫຼັບການເບິ່ງເຫັນລາຍການ

| ປຸ່ມລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `t` | ເມື່ອໂຟກັສ **ບໍ່** ຢູ່ໃນຊ່ອງປ້ອນຂໍ້ມູນ/ພື້ນທີ່ຂໍ້ຄວາມ | ສະຫຼັບການເບິ່ງເຫັນການຄິດ |
| `o` | ເມື່ອໂຟກັສ **ບໍ່** ຢູ່ໃນຊ່ອງປ້ອນຂໍ້ມູນ/ພື້ນທີ່ຂໍ້ຄວາມ | ສະຫຼັບການເບິ່ງເຫັນເຄື່ອງມື |
| `p` | ເມື່ອໂຟກັສ **ບໍ່** ຢູ່ໃນຊ່ອງປ້ອນຂໍ້ມູນ/ພື້ນທີ່ຂໍ້ຄວາມ | ສະຫຼັບຜົນລັບຂອງເຄື່ອງມື |

### ພາເລັດ, ເມນູ ແລະ ຊີດ

| ປຸ່ມລັດ | ບໍລິບົດ | ການກະທຳ |
|----------|---------|--------|
| `Escape` | ລະດັບໜ້າ | ປິດພາເລັດ, ເມນູ, ຫຼື ຊີດ ທີ່ເປີດຢູ່ |
| `⌘K` / `Ctrl+K` | ລະດັບໜ້າ | ເປີດພາເລັດລາຍການເຊດຊັນ |
| `ArrowUp` / `ArrowDown` | ພາເລັດລາຍການເຊດຊັນ | ນຳທາງຜົນການຄົ້ນຫາເຊດຊັນ |
| `Enter` | ພາເລັດລາຍການເຊດຊັນ | ເປີດເຊດຊັນທີ່ຖືກເລືອກ (ຫຼື ອັນທຳອິດ) |
| `ArrowUp` / `ArrowDown` | ປ໋ອບອັບເລືອກໂມເດວ | ນຳທາງລາຍການໂມເດວ |
| `Enter` | ປ໋ອບອັບເລືອກໂມເດວ | ເລືອກໂມເດວທີ່ຖືກໄຮໄລ້ |
| `ArrowUp` / `ArrowDown` | ໂມດອນຟອກ | ນຳທາງຂໍ້ຄວາມ |
| `Enter` | ໂມດອນຟອກ | ຟອກຈາກຂໍ້ຄວາມທີ່ຖືກໄຮໄລ້ |
| `Tab` | ຊີດເຕັມໜ້າຈໍ | ວຽນໂຟກັສພາຍໃນຊີດ |
| `Escape` | ຊີດເຕັມໜ້າຈໍ | ປິດຊີດ |
